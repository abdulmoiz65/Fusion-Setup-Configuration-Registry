# Organization Structures Dependency Readiness

Verify dependencies by a resolvable business name or code. Do not request internal IDs unless an authoritative task contract requires them.

## Dependency Classification

| Task Code | Task Name | Result Category | When Used | Can Run Lookup/Create? |
|---|---|---|---|---|
| FUN_MANAGE_BUSINESS_UNIT | Manage Business Unit | Blocked | The Default Set is absent/ambiguous, Create New has not re-resolved, or the existing-BU state is Existing-Different or Ambiguous | No; request a corrected value, approved set creation, explicit update decision, or disambiguation |
| FUN_ASSIGN_BUSINESS_UNIT_BUSINESS_FUNCTION | Assign Business Unit Business Function | Blocked | A required financial function has no verified compatible primary ledger and legal entity | No; request named dependencies that resolve to the selected BU foundation |
| FUN_MANAGE_SERVICE_PROVIDER_RELATIONSHIPS | Manage Service Provider Relationships | Blocked | Client/provider/function cannot be uniquely identified, roles are missing, the directed pair is absent, or its policy is unresolved | No; request clarification, function assignments, or the actual pair-policy evidence |
| FUN_MANAGE_BUSINESS_UNIT_SET_ASSIGNMENT | Manage Business Unit Set Assignment | Blocked | Business Unit or set code cannot be uniquely identified | No; request clarification |

## Chronological Stage Readiness

| Task Code | Task Name | Dependency | Required Evidence | Next Action |
|---|---|---|---|---|
| FUN_MANAGE_BUSINESS_UNIT | Manage Business Unit | Default set | Exact existing set, or native setIdSets receipt followed by exact code/name re-lookup | Prepare the New BU template path; no HCM setup-task skill required |
| FUN_ASSIGN_BUSINESS_UNIT_BUSINESS_FUNCTION | Assign Business Unit Business Function | Saved BU | Existing exact active BU, or successful creation log plus fresh exact-name lookup; current foundation and eligible BUF_FSM_ADD_FUNCTION_V1 business context, or operation-specific current evidence outside it | Select the additive profile first; no blanket generated-key/date/ConfigurationStatus prerequisite; financial functions still require compatible ledger and LE |
| FUN_MANAGE_BUSINESS_UNIT_SET_ASSIGNMENT | Manage Business Unit Set Assignment | Saved BU and requested groups | Fresh verified BU/set/group/assignment reads and eligibility for BUSA_FSM_ADD_OVERRIDE_V1, otherwise exact current parent evidence for BUSA_FSM_PARENT_KEY_V1 | Prepare only requested override deltas; do not demand maintenance-only keys/dates inside the eligible additive profile |
| FUN_MANAGE_SERVICE_PROVIDER_RELATIONSHIPS | Manage Service Provider Relationships | Saved parties and required provider role | Fresh verified parties/roles, controlled pair and SPR_FSM_ADD_RELATIONSHIP_V1 first-submission assurance, otherwise supported current relationship evidence | Prepare only eligible requested link after actual prerequisites; independent saved-row read limits do not block qualified first submission |

This table records handoff evidence, not cross-task registry edges. The parent skill sequences a combined request and each task-local graph validates its own request. A later standalone assignment prompt may begin from an already verified existing BU. Carry verified stage receipts within the current workflow; re-resolve current identities and attributes required by a later import. Do not treat initiation or a previous chat statement as persisted success.
