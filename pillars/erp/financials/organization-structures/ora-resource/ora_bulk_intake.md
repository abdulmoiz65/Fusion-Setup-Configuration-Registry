# Organization Structures Bulk Intake

The local setup-task catalog marks CSV export/import support as Y for all four tasks. Catalog support alone does not establish a CSV file layout, package, or field contract. A freshly completed template/spec export of the same task from the target environment establishes package structure when its metadata descriptor and emitted headers are inspected and preserved. It contains no saved-state evidence. Use declared GETs, verified current-workflow evidence or a named genuinely scoped source only when needed to preserve or compare an existing configuration. Full populated exports are prohibited; local filtering cannot qualify one as scoped. Do not encode sample values, project artifacts, process identifiers, package names, or emitted filenames in these rules.
