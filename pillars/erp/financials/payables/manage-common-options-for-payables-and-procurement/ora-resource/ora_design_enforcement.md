# Manage Common Options for Payables and Procurement Design Enforcement

The supplemental REST availability exception in ora_reference_lookups.md
permits preparation and preview with disclosed UNVERIFIED_API_UNAVAILABLE
warnings. Apply it to set, bill-to location, conversion-rate type and VAT checks
before evaluating missing-receipt blockers below. Confirmed invalid or
ambiguous results still block; required CSV inputs, local rules, BU/ledger
identity, SOAP validation and Data Loader approval are not covered.

Enforce the exact package shape and the product-backed and approved local rules below. Apply transport checks from `ora_input_validation.md`; any later import uses the governed `core/data-loader` route.

## Design Rules

| Applies When | Severity | Required Lookup | Blocking Condition | Recommendation | Fix Allowed? |
|---|---|---|---|---|---|
| Any package | Blocker | | Header order, field count, or metadata node differs from the exact template | Rebuild from the template; package shape is a local adapter check. | No automatic repair. |
| Any row | Blocker | resolve_bu_context_from_name | EnterpriseId remains unresolved after the precedence rules, or the ERP BU/ledger result is unavailable, ambiguous, or inconsistent | Ask for EnterpriseId only when unresolved; obtain missing BU/ledger evidence separately. | Honor explicit EnterpriseId; do not override ERP-derived SOBName or bypass exact-target checks. |
| SetCode supplied | Blocker | resolve_reference_set | Set resolves null or its bound receipt is missing/mismatched; a bound UNVERIFIED_API_UNAVAILABLE warning permits continuation under the reference availability policy | Supply a resolvable set or remove the field. | User correction only. |
| Bill-to Location name supplied; or InternalLocationCode explicitly supplied after HCM error | Blocker | resolve_bill_to_location | The HCM name has no exact active, bill-to-enabled, effective record; or the post-error FSCM code, set, and effective-date composite has no exact eligible record; a bound UNVERIFIED_API_UNAVAILABLE warning permits continuation under the reference availability policy | Correct or disambiguate the name. After an HCM error, ask for the exact internal code before using FSCM. | Only the same-record mapping in the resolver. |
| User conversion-rate field supplied | Blocker | resolve_conversion_rate_type | No exact current rate type is returned; a bound UNVERIFIED_API_UNAVAILABLE warning permits continuation under the reference availability policy | Supply a resolvable rate type or remove it. | User correction only. |
| ExpenseAccrualCode supplied | Blocker | validate_approved_option_choices | Supplied value is blank or outside the user-approved list | Choose a listed label or exact code from ora_reference_lookups.md; do not require a live lookup. | Approved label/code normalization only. |
| LiabilityPostLookupCode supplied | Blocker | validate_approved_option_choices | Supplied value is blank or outside the user-approved list | Choose a listed label or exact code from ora_reference_lookups.md; do not require a live lookup or submit derived automatic-offset fields. | Approved label/code normalization only. |
| VatCountryCode supplied | Blocker | resolve_vat_country | Territory is missing, non-exact, disabled, or obsolete; a bound UNVERIFIED_API_UNAVAILABLE warning permits continuation under the reference availability policy | Correct or remove the field. | User correction only. |
| GaplessInvNumFlag or MakeRateMandatoryFlag supplied | Blocker | | Value is not exactly Y or N after the declared normalization | Supply an allowed value; fixed flag validation is a local adapter check. | Declared label/code normalization only. |
| BuyingCompanyIdentifier or GaplessInvNumFlag supplied | Blocker | validate_gapless_identifier_dependency | A supplied or retained nonblank identifier requires effective GaplessInvNumFlag=Y; N, blank, missing, and unknown flags block it. | Supply Yes explicitly or confirm Y in the fresh current export, or explicitly clear the identifier. Never automatically enable gapless numbering. | No automatic enabling or clearing. |
| Derived automatic-offset field supplied | Blocker | | Caller provides AutomaticOffsetsFlag or AutomaticOffsetsChangeFlag | Remove the derived field. | User correction only. |
| Any account-segment field supplied | Blocker | validate_account_segments_read_only | Exact DynamicInsertion=No receipt is missing or invalid | Correct the combination or obtain the required read-only receipt. | No automatic account creation. |
| Future mutation | Blocker | | Immutable preview or contextual approval missing/stale | Complete the governed core/data-loader route. | No approval bypass. |

When changing Gapless Invoice Numbering or Buying Company Identifier, a nonblank
identifier requires gapless numbering to be Yes. Confirm Yes from the requested
value or a fresh export.

The identifier is optional when gapless numbering is Yes. When changing gapless
numbering to No, explicitly clear any existing identifier or verify that it is
already blank.

Changes to unrelated settings do not trigger this check.

## Design Lookup Requirements

| Resolver | When Required | Values Needed | Source File |
|---|---|---|---|
| resolve_bu_context_from_name | Every candidate row | EnterpriseId selected by the defaulting precedence, fresh export, exact BU, and matching primary ledger. | ora_reference_lookups.md |
| resolve_reference_set | SetCode supplied | SetCode -> non-null SetId and bound current receipt. | ora_reference_lookups.md |
| resolve_bill_to_location | Bill-to Location name supplied; or InternalLocationCode explicitly supplied after HCM error | Same-record eligible location and resolved InternalLocationCode, SetCode, dates, LocationId, and SetId. | ora_reference_lookups.md |
| resolve_conversion_rate_type | Either user rate-type field supplied | User rate type -> internal rate type. | ora_reference_lookups.md |
| resolve_vat_country | VatCountryCode supplied | Exact enabled, non-obsolete territory code and bound current receipt. | ora_reference_lookups.md |
| validate_account_segments_read_only | Any account segment supplied | Exact ledger, segment string, and valid no-create response. | ora_reference_lookups.md |
| validate_approved_option_choices | ExpenseAccrualCode or LiabilityPostLookupCode supplied | Canonical code from the user-approved fixed choices; no live receipt. | ora_reference_lookups.md |
| validate_gapless_identifier_dependency | BuyingCompanyIdentifier or GaplessInvNumFlag supplied | Effective flag from the request or fresh target row and any supplied/retained identifier. | ora_reference_lookups.md |
