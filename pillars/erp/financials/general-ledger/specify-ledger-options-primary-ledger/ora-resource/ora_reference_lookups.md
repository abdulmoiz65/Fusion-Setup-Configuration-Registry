## Lookup Execution Rules

| Situation | What Happens |
|---|---|
| Exact-match request | Encode or bind values without changing case, punctuation, or internal whitespace; follow every page until hasMore is false before counting matches |
| Describe-backed q attributes | Use Name or LedgerId for ledgers, StructureInstanceNumber or Name for charts, PeriodSetNameId for periods, LanguageTag, LanguageCode, or Description for languages, and _CHART_OF_ACCOUNTS_ID or _CODE_COMBINATION_ID for account combinations. Do not invent display aliases as q fields. |
| Account-combination q contract | Use q only with documented queryable fixed attributes. For retained earnings, bind _CHART_OF_ACCOUNTS_ID to the resolved StructureInstanceNumber. Do not put display labels or SEGMENTn predicates into q unless the live resource contract explicitly exposes them as queryable. |
| Page size and completeness | limit=500 is a page size, not proof of completeness. Advance offset by the returned count or limit until hasMore is false, then perform the exact ordered-segment comparison locally. |
| Retained-earnings lookup source | Do not trigger GL_MANAGE_CHART_OF_ACCOUNTS_VALUE_SETS or any other export for retained-earnings existence. Reuse the already-resolved COA segment order and physical-column mapping, then query accountCombinationsLOV directly. |
| accountCombinationsLOV fixed fields | Treat _CODE_COMBINATION_ID as the CCID and _CHART_OF_ACCOUNTS_ID as the COA structure number. The fixed schema exposes EnabledFlag, StartDateActive, EndDateActive, AccountType, DetailPostingAllowedFlag, SummaryFlag, FinancialCategory, JgzzReconFlag, DetailBudgetingAllowedFlag, Reference3, Reference4, and Reference5. It does not expose ConcatenatedSegments, BalanceEnabledFlag, or fixed SEGMENT1 through SEGMENT30 fields. Omit fields from the GET so COA-specific dynamic values remain present. |
| Dynamic segment mapping | Dynamic attribute spelling varies by chart of accounts. Map against exported SegmentCode, Name, and ColumnName using the unique precedence algorithm in the resolver; never hardcode a customer segment key, assume SEGMENT1 is Company, or rely on response-key order. |
| accountCombinationsLOV returns zero exact rows | Pause Specify Ledger Options and route GL_MANAGE_ACCOUNT_COMBINATIONS in Financial Reporting Structures through the Import Account Combinations FBDI workflow owned by core.data-loader. Supply the exact StructureInstanceCode and SEGMENT1 through SEGMENTn values, create an immutable preview, and obtain the Data Loader approval required by that workflow. After terminal success, rerun the identical LOV lookup; never synthesize a CCID or continue from only the import process result. |
| Zero, one, or many matches | Apply the resolver's exact cardinality; never fuzzy-match, choose the first result, or borrow another ledger's combination |
| HTTP 401 or 403 | Classify auth or authorization, refresh an approved cached OAuth token once when applicable, retry the read once, then stop if still denied |
| HTTP 429, 5xx, or timeout | Classify transport or Fusion API and use only bounded read retries with backoff; disclose attempts and final status |
| HTTP 4xx, malformed response, pagination failure, or client exception | Stop with the actual input-validation, client, or Fusion API classification; never return value not found |
| HTTP 400 or Oracle 29140 | Persist the sanitized q and response and classify a resolver-contract failure. Do not retry the identical invalid attribute or expression and do not reinterpret it as zero matches. |
| Optional family lacks a supported direct field contract | Preserve the baseline, record the family-specific UI handoff, and require a same-scope re-export before Review and Submit readiness |
| Sensitive response data | Retain only sanitized evidence and required non-sensitive values; never persist credentials, tokens, or protected payloads |
| Segment-vector CSV emission | Use a standards-compliant CSV writer so actual LF bytes remain inside one quoted field. Fill slots in authoritative COA order, append empty slots through the exact package-derived count (30 for the validated 133-column contract), and retain the terminal LF. Never write the hyphen-delimited display, CodeCombinationId, literal `\n`, or CRLF into `RetEarnCcidSegments` |
| Scoped populated carrier construction | Use the fresh GL_SPECIFY_LEDGER_OPTIONS data export scoped by GL_PRIMARY_LEDGER and PRIMARY_LEDGER_ID as the sole carrier. Change only the exact owning PRIMARY logical row in both aliases and preserve every other byte unless the approved field delta requires it. A template-only package or project-owned create package may be historical shape evidence but is never the carrier. A post-import verification export is proof only and never the carrier for the already-approved import; compare semantic parity and classify service-generated differences without copying them into that immutable candidate. |
