# Specify Ledger Options Primary-Ledger Input Validation

## Required Groups

| Requirement Group | Accepted Fields | If Missing | How to Resolve | Applies When | Resolver |
|---|---|---|---|---|---|
| Primary-ledger scope | PrimaryLedgerName | Block before reading or changing an options row | The user supplies the exact primary-ledger identity for this task context | Always | resolve_primary_ledger_scope_exact |
| Retained earnings account | RetainedEarningsAccount business display value | Block the controlled new-primary options save | Ask the user for the exact concatenated account combination; do not ask for a CCID or physical CSV vector and do not infer it from chart structure, another ledger, or a role default | Controlled new-primary options save | resolve_retained_earnings_account |
| First period | FirstLedgerPeriodName | Block the operational or open-readiness path only | Ask the user to choose one exact eligible period returned for the primary ledger's calendar; do not choose the chronologically first label or discard adjustment periods | Outcome intent is operational or open readiness | resolve_first_open_period_exact |
| Accounting method policy | Optional AccountingMethodName desired-state receipt; physical code/type/language fields are not user intake | Never ask for method code/type or Journal Description Language for the supported new-ledger baseline | Preserve Standard Accrual code/type and apply the controlled English language intent. resolve_accounting_method_evidence invokes resolve_method_language_exact, writes the returned enabled code, and never writes literal EN unless Fusion returns it. If another method is explicitly requested, retain its exact display name for a manual Specify Ledger Options change after creation and same-scope re-export | Newly FSCR-created primary ledger options save | resolve_accounting_method_evidence |
| Posting-cutoff timezone | PostingCutoffTimezoneCode | Block the requested enabled-cutoff customization and route it to the UI handoff | Ask the user for the intended supported timezone; never infer UTC or another timezone | User explicitly requests PostingCutoffFlag Y |  |
| Custom reversal criteria | CriteriaSetName | Block only the custom-criteria request and route it to the UI handoff | Ask the user for the exact criteria set only when custom reversal criteria are explicitly requested | User explicitly requests custom reversal criteria |  |

## User Intake Classification

| Business Input | Intake Class | Applies When | Contract |
|---|---|---|---|
| Primary ledger | Definitely mandatory user input | Always | Exact ledger scope; this contextual task never falls back to a secondary ledger |
| Retained earnings account | Definitely mandatory user input | Controlled new-primary options save | Exact account combination that passes the retained-earnings semantic role contract |
| First period | Conditionally mandatory user input | Operational or open-readiness outcome | Exact eligible EnteredPeriodName selected by the user from the fully paged PeriodSetNameId result after local PeriodType filtering |
| Accounting method | Controlled default with optional desired-state input | Newly FSCR-created primary ledger | Keep STANDARD_ACCRUAL and S when omitted or Standard Accrual is requested. Another requested method is not authored directly and becomes a post-create manual-change handoff |
| Journal Description Language | Controlled resolver-derived default, not user intake | A newly FSCR-created options row carries an assigned SlaAccountingMethodCode and the carrier language is blank; live validation GL-781444 proves blank is invalid | Default the business intent to English, resolve the unique enabled English base-language row through languagesLOV, and write its returned code. EN is not a hardcoded technical code; a returned American English code such as US is authoritative. Ask only if the environment has zero or multiple eligible English base-language rows |
| Future enterable periods | Optional user input | User wants to override the controlled baseline | Integer from 0 through 999; never promoted to a mandatory question |
| Suspense, SLA suspense, rounding, entered-currency balancing, intercompany, average daily balances, budgetary control, budget journals, automatic tax, translation, sequencing, custom reversal criteria, journal approval, reconciliation, posting cutoff, SLA cash basis, USSGL | Optional opt-in families | User explicitly requests the named family | Do not ask baseline questions; preserve existing values or use the proven disabled baseline, and use a named UI handoff when direct CSV authoring is outside the supported contract |
| Description, IDs, audit fields, process state, and lifecycle state | Not intake for this task | Always | Preserve exported values; never fabricate or overwrite them |

## Field Validation

| Check | What Happens | Applies When | Resolver |
|---|---|---|---|
| Missing-value normalization | Preserve raw supplied text for review; treat null and whitespace-only text as missing; do not silently trim or rewrite a value | Every text input |  |
| Exact-text normalization | Reject leading or trailing whitespace for a nonblank value; preserve internal whitespace, punctuation, and case; never case-fold, fuzzy-match, or substitute a similar label | Ledger, account, period, method, timezone, and criteria-set text |  |
| Retained-earnings account structure | Reject a partial, extra-segment, or structurally invalid concatenated account before semantic resolution | Retained earnings is supplied |  |
| Retained-earnings segment shape | Split the supplied account with the resolved COA delimiter and require exactly the active SEGMENT1 through SEGMENTn values in the already-resolved physical order. Do not trigger a value-set or other export for this check | Retained earnings is supplied | resolve_retained_earnings_account |
| Retained-earnings CCID existence | Query accountCombinationsLOV by _CHART_OF_ACCOUNTS_ID equal to StructureInstanceNumber with no fields projection, page until hasMore is false, map every active segment uniquely from exported SegmentCode, Name, and ColumnName, and require exactly one exact row. Zero pauses this task for routed Manage Account Combinations FBDI creation and a mandatory post-success re-query | Retained earnings is required | resolve_retained_earnings_account |
| Retained-earnings account semantics | Require EnabledFlag Y or true, effective dates, AccountType O, DetailPostingAllowedFlag Y, and SummaryFlag N from the fixed accountCombinationsLOV attributes. BalanceEnabledFlag remains unavailable and must not be inferred. Missing or ambiguous dynamic-key mapping blocks without triggering another export | Retained earnings is required | resolve_retained_earnings_account |
| Retained-earnings physical serialization | Derive `RetEarnCcidSegments` from the resolved account's ordered segment values and the package-derived vector shape, not from CodeCombinationId and not from the hyphen-delimited display. For the validated 133-column contract, emit one quoted CSV field containing exactly 30 physical slots separated by actual LF bytes and terminated by LF: place the COA segments in authoritative structure order, then empty trailing slots through slot 30. Reject literal `\n`, CRLF, missing terminator, wrong slot count, reordered segments, or a display-string/CCID substitution | Before preview and after re-export | resolve_retained_earnings_account |
| Future-enterable-period range | Accept only an integer from 0 through 999; reject decimals, signs outside the range, booleans, and numeric text with decoration | User supplies FutureEnterablePeriodsLimit |  |
| First-period membership | Require one exact EnteredPeriodName from the PeriodSetNameId result after local PeriodType comparison; preserve adjustment periods and never treat service ordering as chronological authority | FirstLedgerPeriodName is required or supplied | resolve_first_open_period_exact |
| Accounting-method physical fields | Reject user-supplied method code/type or technical language code as unsupported direct intake. Resolve the controlled English default authoritatively through the method resolver's language sublookup for the supported new-ledger baseline | Any physical method component is supplied by the user or the carrier language is blank | resolve_accounting_method_evidence |
| Standard Accrual options tuple | Require SlaAccountingMethodCode STANDARD_ACCRUAL and SlaAccountingMethodType S. When this options save carries the assigned method, require a nonblank exact enabled resolver-derived SlaDescriptionLanguage; blank is a create-time carrier state, not a valid options-save default | Always for the newly FSCR-created options flow, including when another desired method was stated | resolve_accounting_method_evidence |
| Alternative method handoff | Preserve the exact requested nonblank display name only in the handoff record; never put its tuple into the FSCR-authored options package | AccountingMethodName is neither Standard Accrual nor STANDARD_ACCRUAL | resolve_accounting_method_evidence |
| Posting-cutoff cross-field rule | Reject PostingCutoffFlag Y with blank PostingCutoffTimezoneCode; PostingCutoffDate may remain blank when the supported UI contract permits it | Posting cutoff is requested |  |
| Auto-reversal cross-field rule | AutorevAfterOpenPrdFlag Y does not require a criteria set; require CriteriaSetName only when the user separately requests custom criteria | Auto-reversal or custom criteria is discussed |  |
| Unknown or service-owned fields | Reject attempts to set identifiers, audit columns, process state, lifecycle state, or undocumented option columns | User supplies fields outside the supported contract |  |
| Optional-family baseline | Do not treat an omitted optional family as missing; preserve the existing value or proven disabled matching-role baseline | An optional family was not requested |  |

The whitespace and case rules above are conservative FSCR intake guards, not a claim that Oracle normalizes names or account displays the same way. They prevent silent mutation before authoritative exact-match and product validation.
