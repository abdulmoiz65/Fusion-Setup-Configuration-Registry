# Assign Balancing Segment Values to Ledger Dependency Readiness

## Required Dependency Order

| Sequence | Dependency | What Must Happen |
|---|---|---|
| 1 | Paired validated scoped exports and ledger configuration | Validate both export request shapes locally, then resolve the exact target ledger and its current balancing-segment metadata, direct-ledger assignments, and legal-entity assignments from same-release, primary-ledger-scoped task exports |
| 2 | Company Value selection or validation | If no value is supplied, return an eligible-value preview and stop. If a value is supplied, confirm it through the exact ledger value-set LOV, then verify against both exports that it is not assigned to a legal entity or already directly assigned for an overlapping period |
| 3 | FSM package baseline | Preserve the current task manifest, supported headers, aliases, and unrelated rows; generate the assignment row only after the selected value passes all checks |

## Dependency Classification

| Result Category | When Used | Can Run Lookup/Create? |
|---|---|---|
| Ready | Every mandatory dependency has exactly one authoritative result | No; proceed to controlled defaulting |
| Blocked | Any dependency is missing, ambiguous, stale, or conflicts with another source | No; obtain evidence before package generation |
