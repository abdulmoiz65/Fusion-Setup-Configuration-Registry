## Export Acquisition Contract

There are two distinct export roles. A populated chart-of-accounts export supplies semantic segment evidence; a template-only Manage Primary Ledgers export supplies the physical import carrier. They are not interchangeable.

| Sequence | Artifact Role | Exact Task | Export Mode | Reuse and Submission Rule | Accepted Output | Permitted Use |
|---|---|---|---|---|---|---|
| 1 | Chart-of-accounts role evidence | GL_MANAGE_CHARTS_OF_ACCOUNTS_STRUCTURE_INSTANCES | Populated task data | Reuse a validated current same-environment and same-release export only when it contains the exact resolved StructureInstanceCode. Otherwise show the exact environment, task, mode, and purpose, obtain explicit export-operation approval, submit exactly one new routed populated export, and poll it to terminal success. A header-only package does not qualify | Seven task CSV members plus ASM_SETUP_CSV_METADATA.xml, including populated rows for the selected structure instance and all four role-resolution members | Resolve GL flexfield identity, balancing segment, and optional management segment only |
| 2 | Primary-ledger authoring carrier | GL_MANAGE_PRIMARY_LEDGERS | Template-only | After every reference and CoA-role dependency passes, show the exact environment, task, template-only mode, and purpose, obtain explicit export-operation approval, and submit exactly one routed template-only export for the current authoring attempt. If that accepted request already produced a successful valid package, reconcile and reuse that result instead of submitting another job | Ten header-only task CSV members plus ASM_SETUP_CSV_METADATA.xml, with both PRIMARY aliases retaining the exact exported 133-column headers | Preserve the template package shape and add only the documented four-row primary-ledger delta |

The normal new-job count is therefore one when qualifying CoA evidence already exists and two when it does not. An accepted or successful export request must be reconciled before another job is submitted; loss of a caller receipt is not authorization to create duplicate exports.

## Lookup Execution Rules

| Situation | What Happens |
|---|---|
| Exact-match request | Encode or bind the supplied value without changing case, punctuation, or internal whitespace; follow pagination until hasMore is false before counting matches |
| Field projection | Use only the exact describe-backed fields shown above. Do not request ShortName, ChartOfAccountsName, CalendarName, AccountedPeriodType, PeriodName, PeriodStatus, CurrencyName, StartDate, EndDate, LanguageName, BaseLanguageFlag, or language EnabledFlag from a LOV that does not expose it |
| Accounting-period filter | Put only PeriodSetNameId in q. Read all pages, then compare PeriodType and the selected EnteredPeriodName locally. A semicolon-combined PeriodSetNameId and PeriodType expression is not part of the validated contract |
| HTTP 400 or Oracle 29140 | Classify as a resolver contract or input-validation failure, persist the sanitized q and response, and stop. Never translate an invalid attribute or malformed expression into value not found, and never retry the identical invalid q |
| Duplicate-name lookup finds one or more exact matches | Stop before CoA export acquisition or primary-template export; do not rename automatically and do not prepare a package |
| Zero, one, or many matches | Apply each resolver's documented cardinality; never choose the first returned item, fuzzy match, or reinterpret ambiguity as success |
| HTTP 401 or 403 | Classify auth or authorization failure, refresh an approved cached OAuth token once when applicable, retry the read once, then stop if still denied |
| HTTP 429, 5xx, or timeout | Classify transport or Fusion API failure and use only bounded read retries with backoff; disclose attempts and final status |
| HTTP 4xx, malformed response, pagination failure, or client exception | Stop with the exact client or Fusion API classification; never return value not found |
| CoA export candidate is header-only | Treat it as unusable for semantic-role derivation and obtain one populated task-level export through the routed workflow |
| CoA export candidate omits the selected StructureInstanceCode | Reject it for this request even if the package is otherwise current; submit one populated export only when no other qualifying current package exists |
| An export POST may already have been accepted | Reconcile the known process or persisted result before another POST. Never convert a missing caller receipt, polling timeout, or delayed artifact write into permission for a duplicate export job |
| Local evidence mismatch | Stop with catalog mismatch or input validation as appropriate; do not borrow values from another environment, release, chart of accounts, ledger, or package |
| Accounting-method name is omitted | Author Standard Accrual as STANDARD_ACCRUAL, S, and blank language without asking the user for a method |
| Standard Accrual is explicitly supplied | Author the same controlled tuple and retain the supplied display receipt without requesting technical fields |
| Another accounting method is explicitly supplied | Preserve the exact requested display name only as desired-state evidence, author Standard Accrual for creation, disclose the post-create manual Specify Ledger Options handoff, and require same-scope re-export before Review and Submit |
| Sensitive response data | Retain only sanitized lookup evidence and the exact non-sensitive values needed by this task; never persist credentials or tokens |
