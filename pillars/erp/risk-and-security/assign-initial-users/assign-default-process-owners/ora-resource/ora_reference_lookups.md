## Lookup Execution Rules

| Situation | What Happens |
|---|---|
| The Risk Management search setting is already enabled | Retain only redacted Core evidence and continue to the complete owner-coverage inventory without consultant output. |
| The Risk Management search setting is disabled | Request fresh approval using the business-labelled setting table. After approval, re-read the Site capability and value through Core, delegate the one create or update to Core, and require final enabled-value verification before owner coverage. |
| The search setting cannot be read, supported, changed, or verified | Stop before the owner-coverage inventory and route the result to task-local error handling. Do not expose profile codes, values, request details, or privilege mechanics. |
| A lookup response is incomplete, malformed, or unavailable | Stop the affected preview or verification stage. Do not infer missing values or represent a partial page set as complete. |
| A live lookup returns an authentication or authorization failure | Route the failure to task-local error handling; do not treat the requested value as absent. |
