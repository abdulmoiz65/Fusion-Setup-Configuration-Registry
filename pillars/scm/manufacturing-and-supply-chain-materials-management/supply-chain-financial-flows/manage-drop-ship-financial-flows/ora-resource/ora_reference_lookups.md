## Lookup Execution Rules

| Condition | Action |
|---|---|
| A create supplies AgreementNumber | Escape the value for the quoted Fusion query, search the target environment, and inspect every returned page. Proceed only when the complete response contains no exact AgreementNumber match. Recheck immediately before preparing the immutable upload artifact; a duplicate or uncertain result blocks the create. |
| A header update supplies AgreementNumber and AgreementId | Query the exact supplied AgreementNumber and require the returned AgreementId to equal the supplied AgreementId. AgreementNumber is an immutable user key, never an update value; a missing or different result blocks the update. |
| One exact AgreementNumber match is returned | Populate `AgreementId` with the returned value and leave `CustomParentKey` blank. |
| No exact match or more than one match is returned | Stop; do not infer a different user key. |
| The response lacks AgreementId | Stop and correct the FDOS business-object mapping. |
| An existing child row is needed | Use the expanded parent lookup. Treat `UniqueId` and `PrimaryTradeRelationNumber` as returned child identifiers; do not invent a child key or use `CustomParentKey`. A correction requires `RestAction=PATCH`, `OperationType=Correct`, replacement dates in the payload, and `effectiveOf=RangeMode=CORRECTION;RangeStartDate={returned child start};RangeEndDate={returned child end}`; child end date, insert, and delete remain unsupported. |
| A QualifierRuleSetName is supplied | Query the declared LOV by exact name and populate `QualifierRuleSetId` from its one exact match. |
| QualifierRuleSetName is omitted | Leave `QualifierRuleSetId` blank; do not perform a lookup. |
| The qualifier lookup is missing, ambiguous, or lacks QualifierRuleSetId | Stop; do not infer or substitute a qualifier ID. |
| A child primary trade relation is requested | Resolve the parent AgreementNumber first, then resolve SellingBusinessUnitName and ReceivingTradeOrganizationName through their declared LOVs. Populate only the returned mapped values and leave CustomParentKey blank. |
| A business-unit or trade-organization lookup is missing, ambiguous, or lacks a mapped value | Stop; do not infer or substitute an ID. |
