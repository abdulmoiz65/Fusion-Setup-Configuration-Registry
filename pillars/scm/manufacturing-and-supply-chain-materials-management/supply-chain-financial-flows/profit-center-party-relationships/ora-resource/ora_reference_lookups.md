## Lookup Execution Rules

| Situation | What Happens |
|---|---|
| Missing request, authority, or match contract | Retain this lookup as incomplete; do not substitute SQL, browser access, guessed REST paths or locally trusted IDs |
| Caller-supplied IDs or undeclared child rows | Reject unverified identities. Buyer rows require explicit buyer intent and the buyer contracts below; parent-only registration does not waive reference verification |
| Header LOV execution context | All Live Lookups run within PCBU.RESOLVE_REFERENCES through the configured fscmRest backend, version 11.13.18.05, with REST-Framework-Version: 9 and the routed workflow's authentication. These definitions do not authorize standalone external calls |
| Header lookup order | For creates, resolve the BU LOV first. For updates, resolve the existing parent by its Name; do not require the create BU LOV to contain an existing BU. Resolve supplied supplier, customer and trade-organization values using that BU context. For a supplied ship-to value, resolve its reference set before its location. No header resolver satisfies a child-resource lookup contract |
| Optional header value explicitly left blank | Skip that field's lookup and return no resolved ID for it; do not choose a default supplier, customer, organization or location. Payload omission and required-field checks remain owned by the calling workflow |
| Candidate retrieval and selection | Retrieve all pages for the dependency-filtered, typed-text search. Zero candidates: report no match. One candidate: resolve its mapped ID. More than one: show all candidates with identifying codes/names and ask the user which to use; do not rank, select the closest match, or silently narrow to exact matches. Thus a search returning D1 and RWRD1 requires a choice even when the input is D1. Retain the chosen row only within its current BU/environment context |
| Search construction | Preserve numbers and codes as strings, including leading zeros. Append the Redwood case-insensitive contains search to the mandatory base filter: supplier VendorName/VendorCode; customer AccountNumber/AccountName/PartyName; trade OrganizationName/OrganizationCode; location LocationCode/InternalLocationCode. Escape text using commonUtils.sanitizeQparamString and URL-encode parameters, including ampersands. Do not count the entire unsearched dependency collection as typed-text candidates |
| BU or environment changes | Discard dependent resolved values and repeat applicable lookups in the new context. LegalEntityId is obtained from the selected BU row; never assume it equals ProfitCenterBUId |
