# Cost Component Mapping Groups Input Validation

## Required Groups

| Requirement Group | Accepted Fields | If Missing | How to Resolve | Applies When | Resolver |
|---|---|---|---|---|---|
| Mapping group identity | ComponentGroupCode (1-30 characters), Name, SetName | Stop before preview | Provide all three required create values | Creating a cost component mapping group | |
| Predefined component mapping | ComponentSource=PRE_DEFINED, SourceComponentCode, SourceCostComponentId, SourceSetName=Common Set, SourceSetId=0, DestSetName, CostElementCode | Stop before preview | Confirm Common Set is returned by `setIdSets` where SetId equals the mapping-group SetId or 0; predefined mappings always use Common Set and never the parent mapping group set | Creating a predefined component mapping | resolve_predefined_source_component |
| Landed cost component mapping | ComponentSource=LANDED_COST_MANAGEMENT, SourceComponentCode, SourceCostComponentId, SourceSetName, DestSetName, CostElementCode, CapitalizationFlag | Stop before preview | Provide the complete landed cost component mapping | Creating a landed cost component mapping | |
| Cost element mapping | SourceSetName, SourceCostElementCode, SourceCostElementId, DestSetName, CostElementCode, CostElementId | Stop before preview | Provide the complete source-to-destination cost element mapping | Creating a cost element mapping | |
| Component-code worksheet row | ComponentMappingType=COMPONENTS, ComponentSource, SourceComponentCode, SourceCostComponentId, CostComponentName, SourceSetName, SourceSetId, DestSetName, DestinationSetId, CostElementId, CostElementCode, CostElementType, CostElementTypeMeaning, RestAction | Reject the complete package before ZIP creation | Populate every required or key template field; ComponentSource must be PRE_DEFINED or LANDED_COST_MANAGEMENT and the generated row count must equal the validated source row count | Creating a component-code mapping | |
| Cost-element worksheet row | ComponentMappingType=COST_ELEMENTS, SourceElementType, SourceCostElementTypeMeaning, CostElementType, CostElementTypeMeaning, SourceSetId, DestinationSetId, RestAction, and resolved source and destination elements | Reject the complete package before ZIP creation | Populate every required or key template field using the current generated Data Loader template | Creating a cost-element mapping | |
| Generated template contract | Every field marked Yes or For new records in the generated attribute-details workbook | Reject the complete package before ZIP creation | Populate each required field from the validated row data before packaging | Generating any child row | |
| Parent mapping group identity | Existing `ComponentGroupId`, or the exact new-parent `ComponentGroupCode` and `SetName` | Stop before child import | Use `ComponentGroupId` for a child-only change. For a master-details create, retain blank child `ComponentGroupId` and use the exact parent surrogate keys. | Creating component-code or component-element child mappings | |
| Mapping group update identity | ComponentGroupId, Name or Description | Stop before preview | Read the mapping group and provide the requested Name and or Description changes | Updating a mapping group | read_mapping_group |
| Mapping group deletion identity | ComponentGroupId | Stop before preview | Read the mapping group to confirm the exact deletion scope; child presence does not block a parent-only delete. | Deleting a mapping group | read_mapping_group |
| Component-code mapping update identity | ComponentGroupId, ComponentGroupDetailId | Stop before preview | Provide the parent and child mapping identifiers | Updating or deleting a component-code mapping | |
| Cost-element mapping update identity | ComponentGroupId, ComponentGroupDetailId | Stop before preview | Provide the parent and child mapping identifiers | Updating or deleting a cost-element mapping | |
| Cost set value | SetName, or a resolved SetId and SetName | Stop before preview | Resolve exactly one cost set with the cost set LOV | Creating or updating a mapping that needs a set value | resolve_cost_set |
| Destination set scope | ComponentMappingGroupSetId and DestSetName matching a returned permitted set | Stop before preview | Resolve the destination set with the mapping-group set/Common Set endpoint | Creating or updating a child mapping | validate_destination_set_scope |
| Predefined source component value | A resolved active predefined component and either an existing parent `ComponentGroupId` or complete new-parent surrogate keys | Stop before preview | Resolve exactly one predefined source component with the component LOV. For a new master-details parent confirmed absent, resolve the source without a parent-bound `IsMapped` status; the absent-parent check is the duplicate preflight. | Creating a predefined component mapping | resolve_predefined_source_component |
| Landed-cost source component value | SetId and a resolved active landed-cost-management component | Stop before preview | Resolve exactly one landed-cost-management source component with the component LOV | Creating or updating a landed-cost-management mapping | resolve_landed_cost_source_component |
| Source cost element value | SourceSetName, a source-scope-validated SourceSetId, and a resolved eligible source cost element | Stop before preview | For a Common Set mapping group, use the `q=null` source-set lookup; otherwise exclude the mapping group’s own set. If SourceSetName is Common Set, resolve the source element only from the Common Set PROFIT_IN_INVENTORY finder; otherwise resolve it from the selected non-Common set’s general finder. | Creating or updating a cost-element mapping | validate_cost_element_source_set_scope |
| Destination cost element value | SetId and a resolved eligible cost element | Stop before preview | Resolve exactly one cost element with the cost element LOV | Creating or updating a mapping with a destination cost element | resolve_cost_element_for_set |
| Profit in inventory element | The element side, that side's resolved SetId, and a resolved PROFIT_IN_INVENTORY cost element | Stop before preview | A Common Set source is resolved directly with the Common Set PII finder. For a non-Common source or either destination side, resolve through the general set-specific resolver first and run the PII lookup only when that exact selected element is PROFIT_IN_INVENTORY, using the same set ID. | A Common Set source is selected, or a selected non-Common source/destination element is type PROFIT_IN_INVENTORY | resolve_profit_in_inventory_element |

## Dependency-Aware Validation

| Applies When | Result | Next Action | Resolver |
|---|---|---|---|
| A child-only mapping request is prepared and ComponentGroupId is present | Parent mapping group identity supplied | Continue to dependency readiness | |
| A master-details create has blank child ComponentGroupId and exact parent ComponentGroupCode and SetName | New-parent surrogate identity supplied | Continue to dependency readiness | |
| A child mapping request has neither an existing ComponentGroupId nor complete new-parent surrogate keys | Parent mapping group identity missing | Do not submit a child request | |

## Field Validation

| Check | What Happens | Applies When | Resolver |
|---|---|---|---|
| ComponentSource is PRE_DEFINED or LANDED_COST_MANAGEMENT | Reject any other component source value | Creating a component-code mapping | |
| CapitalizationFlag is supplied only for a landed cost component mapping | Reject a landed cost mapping without a flag value; its UI label is Include in Inventory. Use the current Data Loader template's one-character representation (`Y` or `N`) for import rows. | ComponentSource=LANDED_COST_MANAGEMENT | |
| ComponentGroupCode is nonblank and at most 30 characters; Name and SetName are nonblank | Reject the parent create request | Creating a mapping group | |
| isUsedInCostProfile is not Y | Reject a parent PATCH or DELETE request when isUsedInCostProfile=Y | Updating or deleting a mapping group | read_mapping_group |
| CapitalizationFlag is unchanged when isUsedinCTC=Y | Reject a landed-cost-management row that changes CapitalizationFlag | Updating a landed-cost-management mapping | check_capitalization_control |
| Existing child mappings are disclosed before a parent delete | Allow a parent-only DELETE when `isUsedInCostProfile` is not Y. If Fusion rejects the parent because of children, stop and prepare child cleanup only for that reported condition. | Deleting a mapping group | read_mapping_group |
| A default predefined component mapping exists before any non-default child mapping is created | Show the default-component readiness message when it is absent. When the request includes the default component, place that row first; otherwise do not reject an otherwise valid child mapping. | Creating a landed-cost or cost-element mapping, or a non-default predefined mapping | read_predefined_component_mappings |
| A predefined child create is not a duplicate | Reject the Data Loader package when its documented preflight returns a row | Creating a predefined component mapping | check_existing_predefined_component_mapping |
| A landed-cost child create is not a duplicate | Reject the Data Loader package when its documented preflight returns a row | Creating a landed-cost-management component mapping | check_existing_landed_cost_mapping |
| A cost-element child create is not a duplicate | Reject the Data Loader package when its documented preflight returns a row | Creating a cost-element mapping | check_existing_cost_element_mapping |
| Source component and cost element IDs come from the documented LOVs | Reject manually supplied or ambiguous identifiers; apply the resolver in the matching required information group | Creating or updating a component or cost element mapping | |
| DestSetName is the mapping group's set or Common Set | Reject the child mapping when DestSetName is not returned by `setIdSets` for SetId=ComponentMappingGroupSetId or SetId=0 | Creating or updating a component-code or cost-element mapping | validate_destination_set_scope |
| A Common Set source uses a PII element | Reject a Common Set source element unless it resolves through `findByCostElementTypeandSetId` with `PROFIT_IN_INVENTORY` and `bindSetId=0`. For a non-Common source or either destination side, use the PII finder only when that exact selected element is PROFIT_IN_INVENTORY. | Creating or updating a cost-element mapping | resolve_source_cost_element_for_set |
| Every child row is a complete template record | Reject the workbook before ZIP creation when ComponentSource is blank, a component-code row lacks a resolved source component, or a cost-element row lacks a source element resolved for its stated set and type | Creating a master-details package | |
| One-submission readiness | Validate every populated worksheet row against the current generated attribute-details and key-fields workbooks, then inspect the generated workbook values rather than only the source payload | Generating a create, update, or delete package | |
| A returned display value is null | Retain it blank unless the generated template explicitly requires a documented replacement; validate all companion columns against the current attribute-details workbook | Generating any child row | |
| Source type uses the stored code | Compare the requested source type with SourceElementType and CostElemType where supplied, not with SourceCostElementTypeMeaning | Validating a cost-element row | |
| CapitalizationFlag is normalized independently | Encode the component-code template value as Y or N and re-read the generated attribute-details workbook for each import | Generating a component-code row | |
