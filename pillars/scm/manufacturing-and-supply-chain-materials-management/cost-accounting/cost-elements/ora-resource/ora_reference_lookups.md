## Lookup Execution Rules

| Situation | What Happens |
|---|---|
| Lookup scope | All resolvers above are read-only REST lookups. They must not create, update, delete, upload, or initiate setup data. |
| Environment identity | Join each documented relative request path to the active, approved Fusion restBaseUrl. Do not supply or override a host. |
| REST client and framework version | Every referenced lookup must use the exact header `REST-Framework-Version: 9`. Invoke every lookup through core/fusion-api/rest-api-client/scripts/fusion_rest_client.py. Preserve the documented query parameters as separate values; the client encodes them for transport. |
| Lookup result safety | A LIKE query only narrows results; exact matching remains mandatory before a value is derived. |
