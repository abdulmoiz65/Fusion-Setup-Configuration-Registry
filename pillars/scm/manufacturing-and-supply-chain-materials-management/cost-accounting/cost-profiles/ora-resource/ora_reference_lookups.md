## Lookup Execution Rules

| Situation | What Happens |
|---|---|
| A documented `q` filter contains a string value | Use single quotes for the Fusion query literal; shell quoting must preserve those literals. |
| The exact Set Name returns one result | Retain the returned SetId, SetCode, and SetName for the Cost Profile setup |
| The request returns zero or multiple results | Stop; do not choose a set by partial name or position |
| A delete or update has a resolved Set Id and Cost Profile Code | Use the Set-qualified `costProfileDetails` request and require exactly one matching row before populating `CostProfileId`. |
| A delete or update has a Cost Profile Code but no Set | Use the unqualified `costProfileDetails` request only. Continue only when it returns one exact Cost Profile Code match, then retain its `CostProfileId` and `SetId`. |
| A Cost Profile ID lookup returns zero or multiple rows | Stop before Data Loader preparation or any upload. Request the Set Name when the unqualified code lookup is ambiguous. |
| Cost Profile ID lookup scope | Route these requests through the configured REST client as read-only GETs. Do not use the `costProfileDetails` service for any upload or other write operation. |
| The component group lookup returns one result | Use ComponentGroupId as Component Group Id |
| The component group lookup returns zero or multiple results | Stop; do not substitute a partial group name or a group from another set |
| The valuation structure type returns one result | Use the returned lookup code as Valuation Structure Type Code |
| The valuation structure type returns zero or multiple results | Stop; do not choose a type by partial meaning or position |
| The valuation structure lookup returns one exact set-and-code result of the resolved type | Use ValStructureId as Valuation Structure Id |
| The valuation structure lookup returns zero or multiple results, or returns a different type | Stop; do not substitute free-text identifiers, a partial match, or a valuation structure of another type |
| The cost method returns one result | Use the returned lookup code as Cost Method Code |
| The cost method returns zero or multiple results | Stop; do not choose a method by partial meaning or position |
| Cost By UOM returns one result | Use the returned lookup code as Cost by UOM Code |
| Cost By UOM returns zero or multiple results | Stop; do not choose a UOM by partial meaning or position |
| Process Negative Quantity returns one result | Use the returned lookup code as Process Negative Quantity Code |
| Process Negative Quantity returns zero or multiple results | Stop; do not choose a quantity policy by partial meaning or position |
| Consigned Accounting Distribution Basis returns one result | Use the returned lookup code as Consigned Accounting Distribution Basis |
| Consigned Accounting Distribution Basis returns zero or multiple results | Stop; do not choose a basis by partial meaning or position |
| Operation Scrap Accounting returns one result | Use the returned lookup code as Operation Scrap Accounting Code |
| Operation Scrap Accounting returns zero or multiple results | Stop; do not choose an accounting policy by partial meaning or position |
| Operation Scrap Valuation returns one result | Use the returned lookup code as Operation Scrap Valuation Code |
| Operation Scrap Valuation returns zero or multiple results | Stop; do not choose a valuation policy by partial meaning or position |
| Receipt Without Cost returns one result | Use the returned lookup code as Receipt Without Cost Code |
| Receipt Without Cost returns zero or multiple results | Stop; do not choose a partial meaning or a positional result |
| Unreferenced RMA Receipt Cost returns one result | Use the returned lookup code as Unreferenced RMA Receipt Cost Code |
| Unreferenced RMA Receipt Cost returns zero or multiple results | Stop; do not choose a receipt-cost policy by partial meaning or position |
| The referenced RMA lookup returns one result | Use the returned Meaning as Referenced RMA Cost |
| The referenced RMA lookup returns zero or multiple results | Stop; do not substitute a different lookup code or Meaning |
| The read request fails | Classify the read failure and stop before retrying |
