# Reference Lookups

All lookups in this file are read-only. A no-match or ambiguous result stops the task at the declared issue terminal; it does not authorize a Fusion write.

## Required Request Headers

Every request in this lookup contract must send the exact `Rest-Framework-Version: 9` header. A response received without this header requirement being met is not valid lookup evidence.

## Live Lookup Execution Route

Every live lookup in this file must be executed only through `core.fusion-api.rest-api-client`, using its standard Fusion REST route and a read-only GET request. The task supplies the domain-specific request path, repeated query parameters, requested fields, match rule, output mapping, and any required additional headers; it does not implement OAuth, HTTP execution, retry, or response handling.

Pass the task-required header to the core client as `--header 'Rest-Framework-Version: 9'`. The core client owns bearer authentication, configured-environment validation, and the one safe retry after a 401 or 403 response.

## Lookup Execution Rules

| Situation | What Happens |
|---|---|
| A live lookup is about to run | Invoke core.fusion-api.rest-api-client with GET, the documented path, repeated query parameters, and the required Rest-Framework-Version: 9 header; do not call Fusion through a task-local client or direct HTTP implementation |
| An existing group must be identified for parent-only update, membership add or update, membership removal, or delete | Invoke resolve_existing_cost_element_group through core.fusion-api.rest-api-client with GET and the declared case-insensitive CostElementGroupCode q filter when a group ID is not supplied. |
| An existing member must be identified for membership removal | Invoke resolve_existing_cost_element_group_member through core.fusion-api.rest-api-client with GET, the resolved parent ID, and the declared case-insensitive CostElementCode q filter when an existing child ID or cost element ID is not supplied. |
| No cost element term or type is supplied after CostOrganizationId resolves | Invoke the cost-elements finder with bindCostElemTypeCode=null and BindCostOrgId set to the resolved cost organization, without a q parameter; retrieve all available result pages and present the applicable elements for selection |
| A cost element term, type, or both are supplied | Apply each supplied value as the documented q and/or finder type filter; do not discard a supplied filter |
| A user supplies CostElementGroupId | Honor it as the exact existing-group identity; do not require group code or a cost organization qualifier |
| A user supplies CostElementGroupDetailId or CostElementId for membership removal | Honor it only after verifying that it belongs to the resolved group; do not require an element code or type qualifier |
| A user supplies CostElementCode for membership removal | Match it only within the resolved group; require ElementTypeCode only when several existing members share that code |
| Multiple matches are returned | Present only applicable values and require the user to choose |
| A selected cost element is not returned for the selected cost organization | Reject the selection and stop |
