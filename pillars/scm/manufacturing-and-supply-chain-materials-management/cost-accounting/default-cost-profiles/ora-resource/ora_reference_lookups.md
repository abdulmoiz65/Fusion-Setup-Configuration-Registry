## Lookup Execution Rules

| Situation | What Happens |
|---|---|
| A documented `q` filter contains a string value | Use single quotes for the Fusion query literal; shell quoting must preserve those literals. |
| A documented lookup returns exactly one result and hasMore is false | Map only the documented returned fields to the indicated target attributes. |
| A lookup returns zero or multiple results, or hasMore is true | Stop; do not select a result by position, partial value, or another cost organization. |
| A read-only request fails | Classify the failure and stop before retrying or substituting another lookup. |
