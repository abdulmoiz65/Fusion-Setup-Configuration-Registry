# Input Validation

## Required Groups

| Requirement Group | Accepted Fields | If Missing | How to Resolve | Applies When | Resolver |
|---|---|---|---|---|---|
| Relationship change | Contextual maintenance organization, related organization, requested action, and relationship type | Stop before Data Loader preview | Supply the missing organization identity, add or remove action, and relationship type. | Every create or remove request | |
| Primary supporting relationship | Contextual maintenance organization, related organization not enabled for maintenance, and supports as primary relationship type | Stop before Data Loader preview | Correct the related organization or use a non-primary relationship type. | Requested relationship type is supports as primary | |
| Data Loader request | Active Run Book task, published Maintenance Organization Relationships business object, and a supplied setup-data artifact or a live-schema sample generated by core.data-loader | Stop before Data Loader preview | Select the task in the Run Book and generate or validate the source artifact through core.data-loader. | Every create or remove request | |

## Field Validation

| Check | What Happens | Applies When | Resolver |
|---|---|---|---|
| Contextual organization | Require a maintenance-enabled organization. Oracle documents that only maintenance organizations are available as contextual search results. | Every create or remove request | |
| Reciprocal relationship | Permit a reciprocal relationship only between maintenance organizations. | Requested relationship type is reciprocal | |
| Supporting relationship | Permit a supporting relationship from a contextual maintenance organization to an organization not enabled for maintenance. | Requested relationship type is supports or supports as primary | |
| Primary relationship | Permit only one primary maintenance organization for an organization not enabled for maintenance. | Requested relationship type is supports as primary | |
| Source data | Require core.data-loader to validate the supplied source format and registered-object template, or generate the live Maintenance Organization Relationships sample before preview. | Every create or remove request | |
| Direct REST request | Reject a request to construct a REST payload or call a Fusion REST write endpoint. | Every request | |
