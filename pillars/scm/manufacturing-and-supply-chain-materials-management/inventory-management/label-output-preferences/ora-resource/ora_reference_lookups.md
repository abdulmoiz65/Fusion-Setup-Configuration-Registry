## Lookup Execution Rules

| Situation | What Happens |
|---|---|
| A declared resolver is needed | Run its read-only GET through core.fusion-api.rest-api-client using the configured Fusion environment. |
| A code and display value are supplied | Resolve both and stop unless they identify the same single row. |
| A lookup fails or is ambiguous | Stop before Data Loader preparation. Do not infer a value or route to direct REST write guidance. |
