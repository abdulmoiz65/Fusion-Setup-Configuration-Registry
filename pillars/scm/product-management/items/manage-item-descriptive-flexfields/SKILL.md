## CSV Export, Import, and Validation Workflow

`CSVExportImportSupportedFlag` is `Y` for this task, so route task setup data work through the relevant skills:

1. Route all Item DFF setup-data activity through `core.fusion-api.apps-common`, selecting its Descriptive Flexfields workflow.
2. Pass the flexfield code `EGP_SYSTEM_ITEMS_DFF` with the task context to identify the Item Descriptive Flexfield.
3. The selected core workflow routes export to `shared.setup-export.task-level-export` and approved FSM CSV import to `core.data-loader`.
4. Validate setup task data with `shared.validation.setup-data-validator`.
5. Validate reference data with `shared.validation.reference-data-validator`.
