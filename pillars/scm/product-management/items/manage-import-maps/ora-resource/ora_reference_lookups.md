## Lookup Execution Rules

| Situation | What Happens |
|---|---|
| An explicit LookupCode is supplied for a standard-lookup-backed field | Preserve that code and mark the corresponding display-value resolver not applicable |
| A display or input value is supplied or defaulted for a standard-lookup-backed field | Invoke core.fusion-api.apps-common.lookups in its Standard lookup view and fill only the exact returned LookupCode |
| A standard lookup returns exactly one case-insensitive exact Meaning match | Preserve the returned system value and map its LookupCode into the documented Data Loader field |
| A standard lookup returns zero or multiple exact Meaning matches | Stop before workbook preview and report the field, lookup type, and supplied value |
| The REST request is a create and ItemClassName is absent, null, or whitespace-only | GET the documented ROOT_ICC item-class endpoint when the active-task cache has no response for the same target environment and endpoint contract, require one exact current item, and map only ItemClass into ItemClassName |
| The REST request is an update, regardless of ItemClassName presence | Return not_applicable from MIM.RESOLVE_ROOT_ITEM_CLASS; do not query itemClasses or read, reuse, or refresh the ROOT_ICC cache |
| ItemClassName is supplied with a non-whitespace value | Preserve the supplied value and do not invoke the ROOT_ICC item-class lookup |
| A consecutive REST create prompt omits ItemClassName with the same target environment and endpoint contract | Reuse the active-task ROOT_ICC item-class cache only while it contains exactly one item with ItemClassCode ROOT_ICC and a nonblank ItemClass |
| An applicable REST create request needs ROOT_ICC and its cache belongs to another target environment or endpoint contract or cannot validate the exact item | Discard the nonmatching cache entry and issue a new GET before defaulting ItemClassName |
| A destination mapping is requested on the REST route | GET importMapAttributes when the active task cache has no response for the same target environment and endpoint contract, validate one exact current item, and map its four required response fields plus LanguageCode when non-null into the destination payload |
| A REST transformation is supplied | Preserve it beneath its parent destination; invoke resolve_import_map_transformation_function and resolve_import_map_transformation_return_attribute after destination resolution |
| A REST transformation requires importMapFunctions metadata | Issue GET to exactly /fscmRestApi/scm/redwood/11.13.18.05/importMapFunctions with no query string, including no empty question mark, and no query parameters; read FunctionName, FunctionSyntax, and Examples from the full response body |
| An importMapFunctions request is being constructed | Do not add fields, onlyData, limit, offset, q, finder, or any other query parameter; this Jersey restriction applies only to importMapFunctions and does not change another lookup endpoint contract |
| A REST transformation ExpressionCode resolves to one exact FunctionName and equals FunctionSyntax after outer trimming | Mark function validation resolved and continue without a syntax advisory |
| A REST transformation ExpressionCode resolves to one exact FunctionName but differs from FunctionSyntax after outer trimming | Preserve ExpressionCode, disclose FunctionSyntax and Examples as an advisory, and continue |
| A REST transformation function has no exact FunctionName match | Stop before preview; return ordered case-insensitive exact suggestions first and then case-insensitive substring suggestions without selecting one |
| A REST transformation destination has a null LanguageCode | Build ReturnAttributeName with exactly EntityName, AttributeGroupName, and AttributeCode and no trailing separator |
| A REST transformation destination has a non-null LanguageCode | Append the exact LanguageCode as the fourth ReturnAttributeName component |
| A REST transformation or expression is not supplied | Return not_applicable from both transformation lookup nodes and do not derive a transformation child |
| A destination mapping or transformation lookup requires a live lookup | Invoke core.fusion-api.rest-api-client with the documented relative endpoint; do not issue an unmanaged REST request or use another executor |
| Consecutive REST prompt has the same target environment and endpoint contract | Reuse an active-task lookup cache only while the selected item or matched function remains present exactly once |
| Target environment or endpoint contract changes, or a selected item or function cannot be validated | Discard the nonmatching cache entry and issue a new GET before resolving the destination or transformation |
| An FSM destination row has DestinationColumn and its unchanged DestinationTable contains the exact case-sensitive substring DUMMY_TABLE | Record the row as not_applicable with the DUMMY_TABLE skip reason; do not invoke importMapAttributes, assign a match count, or produce an unmatched warning |
| An FSM destination row has DestinationColumn and its unchanged DestinationTable does not contain the exact case-sensitive substring DUMMY_TABLE | Compare only ContextCode, DestinationTable, DestinationColumn, and Language to AttributeGroupCode, EntityCode, AttributeCode, and LanguageCode respectively; ignore display fields |
| An FSM destination row has no DestinationColumn | Treat it as source-only and do not invoke destination matching for that row |
| An FSM destination row has zero exact matches | Record an unmatched warning, preserve the row and ZIP unchanged, and allow return to the core.data-loader Task Hook workflow |
| An FSM destination row has multiple exact matches | Stop before upload and report the full four-field key and match count; do not choose a result |
| A matched REST destination item has a non-null LanguageCode | Copy the exact returned LanguageCode into the destination child; do not omit, normalize, infer, or replace it with an independently supplied value |
| A matched REST destination item has a null LanguageCode | Leave destination LanguageCode unset; do not invent or default a language code |
| A matched REST destination item lacks EntityName, AttributeGroupName, AttributeCode, or AttributeName | Stop before preview as an incompatible destination contract; do not infer a value or preserve an independently supplied DestinationEntity or DestinationColumn |
| A read-only lookup returns 401 or 403 | Stop as an authentication or privilege failure; do not treat the lookup value as absent |
| A lookup has a transport, timeout, incompatible response, or Fusion API failure | Stop and classify the failure; do not infer a value, use stale data, or proceed to Data Loader preview |

## FSM Identity Examples

| Finding | Required Result |
|---|---|
| DestinationColumn is TransactionType while the live AttributeName is Transaction Type | Match on DestinationColumn to AttributeCode; the AttributeName difference is irrelevant |
| ContextCode is ItemAttachment while the live AttributeGroupName is Attachment | Match on ContextCode to AttributeGroupCode ItemAttachment; the AttributeGroupName difference is irrelevant |
| DisplayParameter or another display label differs while all four code fields match | Treat the destination row as one exact match because display fields are not part of FSM identity |
| Language is blank and the live LanguageCode is null or blank | Treat the language member of the exact key as matched; do not substitute a language code |
| DestinationTable is SYN_DUMMY_TABLE_STAGE and DestinationColumn is populated | Record the unchanged row as not_applicable because the exact case-sensitive substring DUMMY_TABLE is present; do not invoke importMapAttributes or issue an unmatched warning |
