## Dependency-Aware Validation

| Applies When | Result | Next Action | Resolver |
|---|---|---|---|
| A default sorting order is requested | Route only to `ORA_ORDER_PREFERENCES_DETAILS.csv`; valid when the attribute resolves through `resolve_reservation_priority_attribute` and ordering maps to Priority 0 or 1 | Continue to FSM package validation | resolve_reservation_priority_attribute |
| A default sorting order is requested | Fetch `defaultSortingOrder` through the declared `omReservationPriorities` GET contract and reconcile it with the fresh exported baseline | Stop on an incomplete or failed read; otherwise continue to FSM package validation | fetch_reservation_priority_default_sort_orders |
| A sorting rule is requested | Route only to `ORA_PREFERENCE_RULE.csv`; valid when its row conforms to the current export-derived rule header | Continue to FSM package validation | |
| A sorting rule is requested | Fetch `ruleDetails` through the declared `omReservationPriorities` GET contract and reconcile it with the fresh exported baseline | Stop on an incomplete or failed read; otherwise continue to FSM package validation | fetch_reservation_priority_rules |
| A sorting rule omits a name or description | Generate each omitted value from the one validated attribute, or from the ordered combination of validated attributes when more than one is selected; preserve any supplied value | Require the generated RuleCode to be 30 characters or fewer and check it against the fresh baseline before FSM package validation | resolve_reservation_priority_attribute |
| A sorting rule is created | Add its matching US source-language name and description row to `ORA_TRANSLATION_FOR_PREFERENCE_RULE.csv` | Validate the translation row's RuleCode, name, description, Language, and SourceLang before FSM package validation | |
| A sorting rule has ordered values | Keep every entry Priority at 1 and map the requested first, second, and later choices to one-based SortingOrder values | Continue to FSM package validation | |
| A sorting rule has selected entries | Count each `AttributePriorityJson` entry, including repeated attributes with different values; valid only when the count is three or fewer | Stop and request that the rule be reduced before FSM package validation | |
| A sorting rule does not explicitly request active or default state | Set the created rule IsActive and IsDefault to N; preserve existing rules | Continue to FSM package validation | |
| A sorting rule is explicitly set as default | Set the selected rule IsDefault to Y and set IsDefault to N for every other RESERVATION_PRIORITY rule marked Y in the fresh baseline | Require exactly one Reservation Priority default rule in the final package | |
| Both a default sorting order and a sorting rule are requested | Route the default sorting order to Order Preferences Details and the sorting rule to Order Preference Rules | Validate both section-specific changes before package preparation | |
| A Reservation Priority attribute is supplied | Valid only when `resolve_reservation_priority_attribute` returns exactly one lookup result | Replace the submitted attribute name or code with the returned `LookupCode`, then continue to any attribute-value resolver and FSM package validation | resolve_reservation_priority_attribute |
| Order Type is supplied as a Reservation Priority attribute | Valid only when `resolve_reservation_priority_order_type` returns exactly one lookup result | Replace the supplied value with the returned `LookupCode`, then continue to FSM package validation | resolve_reservation_priority_order_type |
| Demand Class is supplied as a Reservation Priority attribute | Valid only when `resolve_reservation_priority_demand_class` returns exactly one lookup result | Replace the supplied value with the returned `LookupCode`, then continue to FSM package validation | resolve_reservation_priority_demand_class |
| Sales Channel is supplied as a Reservation Priority attribute | Valid only when `resolve_reservation_priority_sales_channel` returns exactly one lookup result | Replace the supplied value with the returned `LookupCode`, then continue to FSM package validation | resolve_reservation_priority_sales_channel |
| Customer Class is supplied as a Reservation Priority attribute | Valid only when `resolve_reservation_priority_customer_class` returns exactly one lookup result | Replace the supplied value with the returned `LookupCode`, then continue to FSM package validation | resolve_reservation_priority_customer_class |
| Shipment Priority is supplied as a Reservation Priority attribute | Valid only when `resolve_reservation_priority_shipment_priority` returns exactly one lookup result | Replace the supplied value with the returned `LookupCode`, then continue to FSM package validation | resolve_reservation_priority_shipment_priority |
| Customer is supplied as a Reservation Priority attribute | Valid only when `resolve_reservation_priority_customer` returns exactly one lookup result | Replace the supplied value with the returned `PartyId`, then continue to FSM package validation | resolve_reservation_priority_customer |
| An FSM import is requested | Valid when the package is an export-derived FSM ZIP for ORA_RESERVATION_PRIORITY_FOR_SALES_ORDERS | Continue to the preview and approval gate | |

## Field Validation

| Check | What Happens | Applies When | Resolver |
|---|---|---|---|
| Default sorting order routing | Update `ORA_ORDER_PREFERENCES_DETAILS.csv` only; map ASC or first position to Priority 0 and DESC or second position to Priority 1; do not create or alter a row in `ORA_PREFERENCE_RULE.csv` for this intent | A default sorting order is requested | |
| Sorting rule routing | Update `ORA_PREFERENCE_RULE.csv` and its matching source-language row in `ORA_TRANSLATION_FOR_PREFERENCE_RULE.csv`; do not create or alter an Order Preferences Details row for this intent | A sorting rule is requested | |
| Sorting rule identity and description | When omitted, generate single-attribute identity from its resolved label and LookupCode. For multiple attributes, generate the display name and description from the ordered resolved labels. Use the normal RuleCode only when it is 30 characters or fewer; otherwise use the deterministic abbreviated-and-hashed length-safe format. Write the name and description to the matching US source-language translation row. Preserve explicit values. Block a generated RuleCode that already exists unless the user explicitly requested an update. | A sorting rule is requested | resolve_reservation_priority_attribute |
| ORA_TRANSLATION_FOR_PREFERENCE_RULE source row | Require the exact exported header and one row with OrderPreferenceCode `RESERVATION_PRIORITY`, the created RuleCode, generated or supplied RuleName and Description, `Language` `US`, and `SourceLang` `US`. Preserve all existing and other-language rows; do not invent translations. | A sorting rule is created | |
| Sorting rule entry ordering | In every `AttributePriorityJson` object, set `Priority` to numeric 1. Use one-based numeric `SortingOrder` for requested choice order: first 1, second 2, then increment. Reject entries that use Priority as the ordering ordinal. | A sorting rule is added to an FSM package | |
| Sorting rule attribute limit | Allow at most three distinct AttributeCodes in one Reservation Priority rule. Multiple `AttributePriorityJson` entries with the same AttributeCode and different values count as one attribute. | A sorting rule is added to an FSM package | |
| Sorting rule activation state | Set `IsActive` to Y only when the user explicitly requests the created or updated rule be active; otherwise set it to N. | A sorting rule is created or updated | |
| Sorting rule default state | Set `IsDefault` to Y only when the user explicitly requests the created or updated rule be default; otherwise set it to N. When set to Y, change every other RESERVATION_PRIORITY row whose IsDefault is Y to N, preserving all other values. Require exactly one final default rule. | A sorting rule is created or updated | |
| Reservation Priority attribute eligibility | Accept only a `LookupCode` returned by `resolve_reservation_priority_attribute` from `ORA_FOM_RESERVE_PRIORITY_ATTR`; do not use a hardcoded date-only allowlist | Any Reservation Priority attribute is supplied | resolve_reservation_priority_attribute |
| Sort order or position | Accept ASC or first position for Priority 0, and DESC or second position for Priority 1 | A default sorting order is requested | |
| Number of default-sort attributes | Accept no more than 3 attributes | A default sorting order is requested | |
| ORA_ORDER_PREFERENCES_DETAILS default row | ORA_ORDER_PREFERENCES.OrderPreferenceCode must be RESERVATION_PRIORITY; AttributeEntity must be the resolver-returned attribute `LookupCode`; Priority must be 0 or 1 as requested; AttributeDatatype and the populated value field must match the task-local Reservation Priority Attribute CSV Mapping; and the two unused value fields must be blank. | A default sorting order is added to an FSM package | resolve_reservation_priority_attribute |
| Demand Class default-sort row | Use AttributeEntity `DEMAND_CLASS`, AttributeDatatype `VARCHAR`, and `AttributeStringValue` equal to the resolver-returned Demand Class `LookupCode`; leave AttributeDateValue and AttributeNumValue blank. Validate the attribute through `resolve_reservation_priority_attribute` first. | A Demand Class default sorting order is added to an FSM package | resolve_reservation_priority_demand_class |
| ORA_PREFERENCE_RULE sorting rule row | Preserve the current export-derived `ORA_PREFERENCE_RULE.csv` header and all unrelated rules; do not infer undocumented columns or values | A sorting rule is added to an FSM package | |
| Order Type value storage | Use only the `LookupCode` returned by `resolve_reservation_priority_order_type`; never store the submitted Order Type display value | Order Type is supplied as a Reservation Priority attribute | resolve_reservation_priority_order_type |
| Demand Class value storage | Use only the `LookupCode` returned by `resolve_reservation_priority_demand_class`; never store the submitted Demand Class display value | Demand Class is supplied as a Reservation Priority attribute | resolve_reservation_priority_demand_class |
| Sales Channel value storage | Use only the `LookupCode` returned by `resolve_reservation_priority_sales_channel`; never store the submitted Sales Channel display value | Sales Channel is supplied as a Reservation Priority attribute | resolve_reservation_priority_sales_channel |
| Customer Class value storage | Use only the `LookupCode` returned by `resolve_reservation_priority_customer_class`; never store the submitted Customer Class display value | Customer Class is supplied as a Reservation Priority attribute | resolve_reservation_priority_customer_class |
| Shipment Priority value storage | Use only the `LookupCode` returned by `resolve_reservation_priority_shipment_priority`; never store the submitted Shipment Priority display value | Shipment Priority is supplied as a Reservation Priority attribute | resolve_reservation_priority_shipment_priority |
| Customer value storage | Use only the `PartyId` returned by `resolve_reservation_priority_customer`; never store the submitted Customer display value | Customer is supplied as a Reservation Priority attribute | resolve_reservation_priority_customer |
| FSM package metadata | Require exact-case ASM_SETUP_CSV_METADATA.xml with ObjectShortName ORA_RESERVATION_PRIORITY_FOR_SALES_ORDERS | An FSM import is requested | |
