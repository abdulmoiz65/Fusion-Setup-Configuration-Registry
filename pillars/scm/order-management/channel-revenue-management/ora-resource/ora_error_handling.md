# Manage Channel User Statuses REST Gates and Error Handling

## Error Situations

| Task Code | Task Name | Situation | What Should Happen |
|---|---|---|---|
| ORA_CJM_MANAGE_CHANNEL_USER_STATUSES | Manage Channel User Statuses | Required input is absent or violates the documented REST schema | Stop before preview or write and report the affected record and field |
| ORA_CJM_MANAGE_CHANNEL_USER_STATUSES | Manage Channel User Statuses | UserStatusFor or SystemStatus does not have one exact active case-insensitive standard-lookup meaning match | Stop before preview, report the affected name and lookup type, and request an unambiguous valid name; do not submit it for Fusion to validate during the write |
| ORA_CJM_MANAGE_CHANNEL_USER_STATUSES | Manage Channel User Statuses | No existing record matches UserStatusCode | Let core.data-loader prepare one channelUserStatuses create preview and require approval before adapter authorization |
| ORA_CJM_MANAGE_CHANNEL_USER_STATUSES | Manage Channel User Statuses | Exactly one existing record matches UserStatusCode | Let core.data-loader prepare an update preview for the documented mutable attributes and require approval before adapter authorization |
| ORA_CJM_MANAGE_CHANNEL_USER_STATUSES | Manage Channel User Statuses | Fusion rejects or ambiguously completes a Data Loader-authorized write | Stop without replaying the write and reconcile through fresh read-only GET requests |
| ORA_CJM_MANAGE_CHANNEL_USER_STATUSES | Manage Channel User Statuses | Read-after-write verification differs from the approved values | Classify the run as failed and stop without issuing a corrective write |
| ORA_CJM_MANAGE_CHANNEL_PROFILE_OPTIONS | Manage Channel Profile Options | The Conversion Rate Types LOV result is zero, ineffective, ambiguous, or fails | Stop before profile-value preview. Report the supplied UserConversionType and lookup result; do not guess ConversionTypeId or submit a profile-value update. |
| ORA_CJM_MANAGE_CHANNEL_PROFILE_OPTIONS | Manage Channel Profile Options | The installment credit-method meaning is blank after trimming | Stop before profile-value preview and request a non-empty lookup meaning. Do not derive a code for a different profile or lookup type. |
| ORA_CJM_MANAGE_ADJ_TYPES | Manage Channel Adjustment Types | The Data Loader Map omits channelAdjustmentTypes, adjustmentReasons, or their documented parent relationship | Stop before preview and identify the invalid map row |
| ORA_CJM_MANAGE_ADJ_TYPES | Manage Channel Adjustment Types | core.data-loader rejects the workbook or live UCM schema validation | Stop before upload and return the actionable validation result |
| ORA_CJM_MANAGE_ADJ_TYPES | Manage Channel Adjustment Types | Fusion reports that AdjustmentTypeId cannot be resolved from ParentUserKeys for an adjustmentReasons row | Classify as INPUT_VALIDATION. Stop without retry, identify the child AdjustmentTypeCode, resolve one exact existing parent, populate the Data Loader child parent-reference carrier with its AdjustmentTypeId, rebuild the immutable archive, rerun validation, and obtain fresh approval. |
| ORA_CJM_MANAGE_ADJ_TYPES | Manage Channel Adjustment Types | Fusion reports a duplicate Name and SetName combination or an unresolved AdjustmentTypeId for a parent PATCH | Classify as INPUT_VALIDATION. Stop without retry. Verify that the staged parent row contains the exact returned AdjustmentTypeId and RestAction PATCH when the code has one existing match; rebuild the archive, rerun validation, and obtain fresh approval. |
| ORA_CJM_MANAGE_ADJ_TYPES | Manage Channel Adjustment Types | The approval archive is absent, changed, stale, or not explicitly approved | Stop before the first upload or initiation POST and rebuild the exact archive preview |
| ORA_CJM_MANAGE_ADJ_TYPES | Manage Channel Adjustment Types | Fusion rejects or ambiguously completes a Data Loader-authorized upload or initiation | Stop without replaying the request and return the safe Fusion failure summary |
| ORA_CJM_MANAGE_CHANNEL_LOOKUPS | Manage Channel Lookups | The FSM package differs from the current task-level export structure or has an invalid code identity | Stop before preview and identify the affected file, row, and required correction |
| ORA_CJM_MANAGE_CHANNEL_LOOKUPS | Manage Channel Lookups | An existing LookupType lacks a complete exported parent carrier | Stop before package assembly. Obtain an FSM export source containing the parent and its alternate-key context. Preserve export-supplied technical fields, apply only supplied and changed parent business fields, and do not create a child-only package or regenerate a parent row from REST. If no such export route is available, direct the user to complete the change in the Fusion application UI. |
| ORA_CJM_MANAGE_CHANNEL_DESCRIPTIVE_FLEXFIELDS | Manage Channel Descriptive Flexfields | A supplied value-set name or description has no unique Fusion match | Stop package preparation. Report the supplied name and safe candidate names; do not guess a ValueSetCode or continue to CSV generation. |
| ORA_CJM_MANAGE_CHANNEL_DESCRIPTIVE_FLEXFIELDS | Manage Channel Descriptive Flexfields | The supplied DFF segment lacks a required template identity value or maps a field outside the current task template | Stop package preparation. Report the affected field and obtain the required source value; do not infer a missing identity value. |
| ORA_CJM_MANAGE_CHANNEL_DESCRIPTIVE_FLEXFIELDS | Manage Channel Descriptive Flexfields | Fusion reports a missing DFF parent carrier or skips a child row | Preserve the ProcessLog and stop. Verify the DFF code, resolved application ID, context identities, and template-based parent/context carrier rows; rebuild the package from those validated inputs before a new preview. Use a fresh export only as optional diagnostic or reconciliation evidence. |
| ORA_CJM_MANAGE_CHANNEL_DESCRIPTIVE_FLEXFIELDS | Manage Channel Descriptive Flexfields | Fusion reports a CSV parsing error or a staged row differs from its template header count | Stop without retry. Correct the staged CSV alignment, rerun parser and Data Loader validation, then obtain approval for a new immutable ZIP. |
| ORA_CJM_MANAGE_CHANNEL_DESCRIPTIVE_FLEXFIELDS | Manage Channel Descriptive Flexfields | Fusion rejects SegmentIdentifier or ColumnName | Preserve the ProcessLog and stop. Correct the named source field using the identifier rule or a Fusion-confirmed registered column; do not guess or hard-code a replacement. |
| ORA_CJM_MANAGE_CHANNEL_LOOKUPS | Manage Channel Lookups | An existing LookupType is supplied | Compare its supplied, template-supported parent business fields with the exact exported parent carrier. Prepare a parent update only for differing values; preserve every omitted business field and every export-supplied technical field. Block if more than one parent carrier matches. |
| ORA_CJM_MANAGE_CHANNEL_LOOKUPS | Manage Channel Lookups | An existing LookupCode is supplied | Compare only supplied mutable child values (Meaning, Description, EnabledFlag, StartDateActive, EndDateActive, DisplaySequence, and Tag) with the exact exported child row. Preserve current exported values for omitted fields, including EnabledFlag; prepare an update only when at least one supplied field differs; report an unchanged row as a no-op and do not submit a duplicate package. Treat LookupType and LookupCode as identity keys and ignore system-audit fields. Block if more than one exact code match exists. |
| ORA_CJM_MANAGE_CHANNEL_LOOKUPS | Manage Channel Lookups | Fusion reports a missing alternate key, null LookupType, or ViewApplicationId zero for Application Standard Lookup | Classify as FUSION_API, preserve the ProcessLog, and stop without retry. Before any new preview, rebuild from a fresh export with exactly one matching parent carrier, its current business fields, and blank parent and new-child system-audit fields; obtain new approval for the rebuilt package. |
| ORA_CJM_MANAGE_CHANNEL_LOOKUPS | Manage Channel Lookups | A new parent is missing export-derived technical attributes or is outside the selected Channel Revenue Management module | Stop before package assembly and obtain a current task-level export; do not invent or request technical parent values |
| ORA_CJM_MANAGE_CHANNEL_LOOKUPS | Manage Channel Lookups | The exact package changes after validation or approval preview | Stop before upload, rebuild the immutable package, and rerun validation |
| ORA_CJM_MANAGE_CHANNEL_LOOKUPS | Manage Channel Lookups | Fusion rejects or ambiguously completes an approved FSM upload or initiation | Stop without replaying the request and return the safe Fusion failure summary |
| ORA_CJM_MANAGE_CHANNEL_VALUE_SETS | Manage Channel Value Sets | The value-set lookup is ambiguous, the existing parent carrier is missing, a child value is invalid, or the package differs from the selected template | Stop before preview and identify the affected value set, parent, child row, or template field. Do not guess a ModuleId or construct a parent carrier from REST data. |
| ORA_CJM_MANAGE_CHANNEL_VALUE_SETS | Manage Channel Value Sets | The immutable FSM package changes after validation or approval preview, or Fusion rejects or ambiguously completes an approved import | Stop without retry. Rebuild and validate the package, then obtain fresh approval; reconcile an uncertain Fusion outcome with status before any new submission. |

| ORA_CJM_MANAGE_CHANNEL_LOOKUPS | Manage Channel Lookups | FUSION_API | Fusion rejects the authorized FSM upload or initiation request | Preserve redacted evidence and stop before retry |
| ORA_CJM_MANAGE_CHANNEL_DESCRIPTIVE_FLEXFIELDS | Manage Channel Descriptive Flexfields | CATALOG_MISMATCH | The value-set name or description has no unique current value-set match | Provide the exact ValueSetCode or an unambiguous current value-set name, then rebuild the package |
| ORA_CJM_MANAGE_CHANNEL_DESCRIPTIVE_FLEXFIELDS | Manage Channel Descriptive Flexfields | INPUT_VALIDATION | The required DFF or context parent carrier cannot be derived from the supplied identity values and current task template | Correct the DFF code, application ID, context identity, or template-supported carrier fields, then rebuild the package; use a fresh export only when optional reconciliation is needed |
| ORA_CJM_MANAGE_CHANNEL_VALUE_SETS | Manage Channel Value Sets | INPUT_VALIDATION | The value-set code, parent carrier, child value, date, sort order, template alignment, or Data Loader validation is invalid | Correct the named source field or package row, rebuild the immutable archive, and rerun validation |

| ORA_CJM_MANAGE_CHANNEL_VALUE_SETS | Manage Channel Value Sets | FUSION_API | Fusion rejects or ambiguously completes an approved FSM import | Preserve redacted evidence and stop before retry |
