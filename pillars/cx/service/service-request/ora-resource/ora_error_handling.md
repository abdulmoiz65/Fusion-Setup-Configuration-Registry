# Service Request Error Handling

## Issue Handling Rules

| Task Code | Task Name | Situation | What Should Happen | Next Action |
|---|---|---|---|---|
| ORA_SVC_MANAGE_SR_SEVERITIES_R13 | Manage Service Request Severities | Meaning or LookupCode is missing, or the lookup code is ambiguous | Return actionable issues and stop before live import | Provide Meaning or allow a customer-owned LookupCode to be generated, or resolve the duplicate lookup code. Leave DisplaySequence and Tag blank when they are not supplied. |
| ORA_SVC_MANAGE_SERVICE_REQUEST_INTERNAL_PRIORITIES | Manage Service Request Internal Priorities | Required Meaning or DisplaySequence is missing, a generated or supplied code uses the ORA prefix, or the lookup code is ambiguous | Return actionable issues and stop before live import | Provide Meaning and DisplaySequence, use or allow generation of a customer-owned code without the ORA prefix, or resolve the duplicate code |
| ORA_SVC_MANAGE_SERVICE_REQUEST_CHANNEL_TYPES | Manage Service Request Channel Types | Channel lookup code is not resolved through standardLookups, requested custom channel extension is not confirmed, or DFF context details are missing | Return actionable issues and stop before live import | Correct the channel code, use a documented predefined value, or provide explicit source confirming the extension and any DFF flex context |
| ORA_MANAGE_CHANNEL_TYPE_PROPERTIES | Manage Service Request Channel Type Visibility | PropertyName is a meaning or display label, PropertyName and PropertyLookupCode differ, or the property/value is unsupported | Return actionable issues and stop before live import | Use identical technical codes INTERACTIVE or ENABLED_FOR_COLLABORATION for PropertyName and PropertyLookupCode, resolve label fields from the Standard Lookup Meaning, and use Y or N for FSM import |
| ORA_SVC_SERVICE_REQUEST_SOURCES | Manage Service Request Sources | Meaning is missing, or the supplied or generated lookup code is ambiguous | Return actionable issues and stop before live import | Provide Meaning, allow or provide a unique LookupCode, or resolve the duplicate code. Leave DisplaySequence blank when it is not provided. |
| ORA_SVC_MANAGE_SERVICE_REQUEST_PROBLEM_TYPES | Manage Service Request Problem Types | Meaning is missing or the lookup code is ambiguous | Return actionable issues and stop before live import | Provide Meaning, allow or provide a unique LookupCode, or resolve the duplicate code. EnabledFlag defaults to Y and DisplaySequence remains blank when it is not supplied. |
| ORA_SVC_MANAGE_SERVICE_REQUEST_CONTACT_RELATIONSHIP_TYPES | Manage Service Request Contact Relationship Types | Meaning or DisplaySequence is missing, or the lookup code is ambiguous | Return actionable issues and stop before live import | Provide Meaning and DisplaySequence, allow or provide a unique customer-owned LookupCode, or resolve the duplicate code. EnabledFlag defaults to Y when it is not supplied. |
| ORA_SVC_SERVICE_REQUEST_STATUS | Manage Service Request Status Values | A required standalone status field is missing, the supplied or generated status code is ambiguous, the parent status cannot be resolved using ParentLookupType, or a requested parent relationship does not use the documented lookup types and relationship codes | Return actionable issues and stop before live import | Provide Meaning and DisplaySequence, allow or provide a unique customer-owned LookupCode, resolve ParentLookupCode using ParentLookupType, and use ChildLookupType ORA_SVC_SR_STATUS_CD, ParentLookupType ORA_SVC_SR_STATUS_TYPE_CD, and ORA_SVC_STATUS_TYPE_STATUS for both relationship-code fields. |
| ORA_MANAGE_SERVICE_REQUEST_OUTCOMES_AND_RESOLUTIONS | Manage Service Request Outcomes and Resolutions | A required standalone lookup field or requested outcome-to-resolution mapping field is missing | Return actionable issues and stop before live import | Select ORA_SVC_RESOLVE_OUTCOME_CD or ORA_SVC_SR_RESOLUTION_CD, provide Meaning and DisplaySequence, use or allow generation of a unique customer-owned code, or provide ChildLookupCode and ParentLookupCode for a mapping. |
| ORA_SVC_MANAGE_SERVICE_REQUEST_PROFILE_OPTIONS | Manage Service Request Profile Options | Profile option is not present in the same-task export, its level is unsupported, its value violates documented semantics, or its required scheduled process is absent | Return actionable issues and stop before live import | Use an exported task-owned profile option and supported level, retain definition and level metadata, provide the customer-required value, and add the required scheduled process to the implementation plan. |
| ORA_SVC_SERVICE_REQUEST_CATEGORIES | Manage Service Request Categories | Category package omits required category identity, has an unapproved hierarchy change, uses an invalid generated CategoryCode, sets DeletedFlag to Y, or lacks a required child-parent association | Return actionable issues and stop before live import | Provide the approved ORA_SVC_CATEGORY values; generate CategoryCode with uppercase letters, digits, and single underscores only; and, for a child, provide ParentCategoryCode and the ORA_SEVICE_CATEGORY_ASSOCIATION parent identity from the same-task export |
| ORA_SVC_MANAGE_SR_KNOWLEDGE_PROFILE_OPTIONS | Manage Service Request Knowledge Profile Options | Knowledge is not set up, the user lacks the Sales Administrator or Service Administrator role, or the requested level is unsupported by the same-task export | Return actionable issues and stop before live import | Complete Knowledge setup, confirm the required administrator role, and use the exported supported level or default SITE only when no supported level is supplied. |
| ORA_MANAGE_OBJECT_LINK_TYPES | Manage Object Link Types | Link type identity is ambiguous, update is disallowed, or delete is disallowed | Return actionable issues and stop before live mutation | Resolve a unique link type and check UpdateFlag or DeleteFlag |
