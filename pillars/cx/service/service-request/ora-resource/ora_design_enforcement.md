# Service Request Design Enforcement

## Design Rules

| Task Code | Task Name | Applies When | Severity | Required Lookup | What Blocks Preview | Fix Allowed? | User Guidance | Resolver |
|---|---|---|---|---|---|---|---|---|
| ORA_SVC_MANAGE_SR_SEVERITIES_R13 | Manage Service Request Severities | Creating or updating a customer-owned severity lookup code | Blocker | resolve_service_request_severity_lookup_code | A new severity Meaning is missing, an ORA-prefixed custom code is proposed, or the requested create or update does not meet its lookup match rule | Yes | Provide Meaning and use a customer-owned LookupCode or allow it to be generated from Meaning and Description. DisplaySequence and Tag remain blank when not supplied. Lower ranking means higher priority when a DisplaySequence is supplied. | resolve_service_request_severity_lookup_code |
| ORA_SVC_MANAGE_SERVICE_REQUEST_INTERNAL_PRIORITIES | Manage Service Request Internal Priorities | Creating or updating a customer-owned internal-priority lookup code | Blocker | resolve_internal_priority_lookup_code | Parent Meaning is not SR Internal Priority, new-row Meaning or DisplaySequence is missing, an ORA-prefixed customer code is proposed, or the requested create or update does not meet its lookup match rule | Yes | Set parent Meaning to SR Internal Priority; provide Meaning and DisplaySequence; use a customer-owned LookupCode or allow it to be generated from Meaning and Description; then review the immutable FSM Data Loader package before approval. | resolve_internal_priority_lookup_code |
| ORA_SVC_MANAGE_SERVICE_REQUEST_CHANNEL_TYPES | Manage Service Request Channel Types | Reviewing or changing channel type lookup values | Blocker | resolve_channel_type_lookup_code | LookupType is not ORA_SVC_CHANNEL_TYPE_CD, LookupCode is missing, requested code is outside the documented ORA_SVC channel code set without confirmed extension support, or DFF context details are missing | Yes | Use documented predefined channel type values unless Oracle source confirms an extension path; for confirmed changes, use the standard lookup-code contract and keep DFF values out of scope until flex context details are supplied | resolve_channel_type_lookup_code |
| ORA_MANAGE_CHANNEL_TYPE_PROPERTIES | Manage Service Request Channel Type Visibility | Changing channel visibility | Blocker | resolve_channel_visibility_property | LookupType is not ORA_SVC_CHANNEL_TYPE_CD, PropertyLookupType is not ORA_SVC_LOOKUP_PROP_TYPE_CD, PropertyName and PropertyLookupCode are not identical technical codes (INTERACTIVE or ENABLED_FOR_COLLABORATION), or PropertyValue is not Y or N | Yes | Resolve the channel and property lookup, set PropertyName equal to PropertyLookupCode without using a display label, then set PropertyValue to Y or N when importing via FSM | resolve_channel_visibility_property |
| ORA_SVC_SERVICE_REQUEST_SOURCES | Manage Service Request Sources | Any service request source setup request | Blocker | resolve_service_request_source_lookup_code | LookupCode, Meaning, or EnabledFlag is missing, or the lookup code is not unique under ORA_SVC_SOURCE_CD | Yes | Use a unique ORA_SVC_SOURCE_CD lookup code, leave DisplaySequence blank when it is not supplied, and review the immutable FSM Data Loader package before approval | resolve_service_request_source_lookup_code |
| ORA_SVC_MANAGE_SERVICE_REQUEST_PROBLEM_TYPES | Manage Service Request Problem Types | Any problem type setup request | Blocker | resolve_problem_type_lookup_code | Meaning is missing, or the supplied or generated lookup code is not unique under ORA_SVC_SR_PROBLEM_TYPE_CD | Yes | Use a unique customer-owned ORA_SVC_SR_PROBLEM_TYPE_CD lookup code without the ORA prefix, leave DisplaySequence blank when it is not supplied, and review the immutable FSM Data Loader package before approval | resolve_problem_type_lookup_code |
| ORA_SVC_MANAGE_SERVICE_REQUEST_CONTACT_RELATIONSHIP_TYPES | Manage Service Request Contact Relationship Types | Any contact relationship type setup request | Blocker | resolve_contact_relationship_type_lookup_code | Meaning or DisplaySequence is missing, or the supplied or generated lookup code is not unique under ORA_SVC_CONTACT_REL_TYPE_CD | Yes | Use a unique customer-owned ORA_SVC_CONTACT_REL_TYPE_CD lookup code without the ORA prefix, default EnabledFlag to Y when omitted, and review the immutable FSM Data Loader package before approval | resolve_contact_relationship_type_lookup_code |
| ORA_SVC_SERVICE_REQUEST_STATUS | Manage Service Request Status Values | Adding or changing SR status values | Blocker | resolve_service_request_status | A standalone status lacks Meaning or DisplaySequence, the supplied or generated code is not customer-owned and unique under ORA_SVC_SR_STATUS_CD, the parent status relationship is ambiguous, or a requested relationship omits the documented lookup types or relationship codes | Yes | Use a reviewed standard-lookup package for status values, default only the documented FSM fields, resolve ParentLookupCode with ParentLookupType, use ORA_SVC_LOOKUP_CODE_RELS only when a parent relationship is requested, and review each immutable Data Loader archive before approval | resolve_service_request_status |
| ORA_MANAGE_SERVICE_REQUEST_OUTCOMES_AND_RESOLUTIONS | Manage Service Request Outcomes and Resolutions | Any outcome or resolution setup request | Blocker |  | A standalone lookup row lacks a selected lookup type, Meaning, or DisplaySequence; a supplied or generated code is not customer-owned and unique; or a requested mapping lacks ChildLookupCode or ParentLookupCode | Yes | Use a reviewed standard-lookup package for outcomes or resolutions, default only the documented FSM fields, use ORA_SVC_LOOKUP_CODE_RELS only when a mapping is requested, and review each immutable Data Loader archive before approval |  |
| ORA_SVC_MANAGE_SERVICE_REQUEST_PROFILE_OPTIONS | Manage Service Request Profile Options | Setting SR auto-close, auto-resolve, default severity, default status, purge, attachment, or notification profile options | Blocker |  | The profile option is not task-owned in the same-task export, its level is unsupported, its value violates documented semantics, or a required scheduled process is not included in the implementation plan | Yes | Use the exported FND_APP_PROFILE_OPTION, ORA_FND_APP_PROFILE_OPTION_LEVEL, and FND_APP_PROFILE_VALUE contract; retain definition and level metadata, use the exported supported level or default SITE only when no supported level is supplied, and set the customer-approved value. Schedule required processes where documented. |  |
| ORA_SVC_SERVICE_REQUEST_CATEGORIES | Manage Service Request Categories | Designing or changing a category hierarchy | Blocker | resolve_service_request_categories | A category package omits the required ORA_SVC_CATEGORY identity and approved values, alters an exported hierarchy value without approval, uses a generated CategoryCode that is not uppercase letters, digits, and single underscores, sets DeletedFlag to Y, or includes a child without ParentCategoryCode and the matching ORA_SEVICE_CATEGORY_ASSOCIATION row | Yes | Use the same-task FSM export as the baseline. Retain existing StripeCd, CategoryShortName, BUOrgId, and system-derived hierarchy fields; for a generated code, normalize separators to single underscores and uppercase the result; set DeletedFlag to N; create the parent before a child; and include the child-parent association only for a child category. | resolve_service_request_categories |
| ORA_SVC_MANAGE_SR_KNOWLEDGE_PROFILE_OPTIONS | Manage Service Request Knowledge Profile Options | Enabling Knowledge in Service Requests | Blocker |  | Knowledge is not set up, the user lacks the Sales Administrator or Service Administrator role, or the requested profile level is unsupported | Yes | Use the exported profile contract; set SVC_ENABLE_KNOWLEDGE_IN_SR to Y only after Knowledge setup and the required administrator role are confirmed, and use the exported supported level or default SITE only when no supported level is supplied. |  |
| ORA_MANAGE_OBJECT_LINK_TYPES | Manage Object Link Types | Creating, updating, or deleting object link types | Blocker | resolve_object_link_type | Name or ShortName is missing, ShortName exceeds documented length, or delete is requested when DeleteFlag is false | Yes | Use unique ShortName and LinkTypeNumber; check UpdateFlag and DeleteFlag before live mutation | resolve_object_link_type |

## Enforcement Order

| Task Code | Task Name | Sequence | What Must Happen |
|---|---|---|
| ORA_SVC_MANAGE_SR_SEVERITIES_R13 | Manage Service Request Severities | 1 | Validate inputs, apply documented defaults, resolve the lookup code, then enforce customer-code rules |
| ORA_SVC_MANAGE_SERVICE_REQUEST_INTERNAL_PRIORITIES | Manage Service Request Internal Priorities | 1 | Validate inputs, apply documented defaults, resolve the lookup code, then review the FSM Data Loader package |
| ORA_SVC_MANAGE_SERVICE_REQUEST_CHANNEL_TYPES | Manage Service Request Channel Types | 1 | Validate inputs, apply documented FSM root and audit-field defaults, validate the requested channel lookup code against ORA_SVC_CHANNEL_TYPE_CD, then use standardLookups lookupCodes for lookup-code state and serviceChannelTypesLOV only for read-only channel flag cross-checks |
| ORA_MANAGE_CHANNEL_TYPE_PROPERTIES | Manage Service Request Channel Type Visibility | 1 | Resolve channel and property lookup, enforce identical technical PropertyName and PropertyLookupCode values, then enforce Y or N visibility setting for FSM import |
| ORA_SVC_SERVICE_REQUEST_SOURCES | Manage Service Request Sources | 1 | Validate inputs, resolve any existing ORA_SVC_SOURCE_CD lookup code, then review the FSM Data Loader package |
| ORA_SVC_MANAGE_SERVICE_REQUEST_PROBLEM_TYPES | Manage Service Request Problem Types | 1 | Validate inputs, resolve any existing ORA_SVC_SR_PROBLEM_TYPE_CD lookup code, then review the FSM Data Loader package |
| ORA_SVC_MANAGE_SERVICE_REQUEST_CONTACT_RELATIONSHIP_TYPES | Manage Service Request Contact Relationship Types | 1 | Validate inputs, apply documented defaults, resolve any existing ORA_SVC_CONTACT_REL_TYPE_CD lookup code, then review the FSM Data Loader package |
| ORA_SVC_SERVICE_REQUEST_STATUS | Manage Service Request Status Values | 1 | Validate inputs, apply the documented status lookup and parent-relationship defaults, then resolve the status code and parent status relationship |
| ORA_MANAGE_SERVICE_REQUEST_OUTCOMES_AND_RESOLUTIONS | Manage Service Request Outcomes and Resolutions | 1 | Validate inputs, apply the documented outcome, resolution, or mapping defaults, then enforce the lookup types and outcome-to-resolution relationship code |
| ORA_SVC_MANAGE_SERVICE_REQUEST_PROFILE_OPTIONS | Manage Service Request Profile Options | 1 | Validate the exported profile identity and customer-required value, apply documented level defaults, then confirm related scheduled process requirements where documented |
| ORA_SVC_SERVICE_REQUEST_CATEGORIES | Manage Service Request Categories | 1 | Validate the ORA_SVC_CATEGORY contract, retain exported hierarchy values, and create approved top-level categories before child categories with their required ORA_SEVICE_CATEGORY_ASSOCIATION rows |
| ORA_SVC_MANAGE_SR_KNOWLEDGE_PROFILE_OPTIONS | Manage Service Request Knowledge Profile Options | 1 | Confirm Knowledge Management scope and required role, then apply the documented profile identity and level defaults |
| ORA_MANAGE_OBJECT_LINK_TYPES | Manage Object Link Types | 1 | Resolve existing link type before choosing create, update, or delete path |
