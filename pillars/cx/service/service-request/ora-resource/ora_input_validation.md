# Service Request Input Validation

## Required Groups

| Task Code | Task Name | Requirement Group | Accepted Fields | If Missing | How to Resolve | Applies When | Resolver |
|---|---|---|---|---|---|---|---|
| ORA_SVC_MANAGE_SR_SEVERITIES_R13 | Manage Service Request Severities | Severity value definition | Meaning; optional LookupCode, DisplaySequence, EnabledFlag, StartDateActive, EndDateActive, Description, and Tag | Return issues before preview or import | Meaning is required for a new severity. Generate an omitted LookupCode from Meaning and Description; leave omitted DisplaySequence and Tag blank. | Adding or updating SR severity values | resolve_service_request_severity_lookup_code |
| ORA_SVC_MANAGE_SERVICE_REQUEST_INTERNAL_PRIORITIES | Manage Service Request Internal Priorities | Internal priority definition | Meaning and DisplaySequence; optional LookupCode, EnabledFlag, Description, StartDateActive, EndDateActive, and Tag | Return issues before preview or import | Set parent Meaning to SR Internal Priority. Meaning and DisplaySequence are required for a new internal priority. Generate an omitted customer-owned LookupCode from Meaning and Description without the ORA prefix, and default an omitted EnabledFlag to Y. | Any internal priority setup change | resolve_internal_priority_lookup_code |
| ORA_SVC_MANAGE_SERVICE_REQUEST_CHANNEL_TYPES | Manage Service Request Channel Types | Channel type lookup value | LookupCode, LookupType, Meaning, Description, EnabledFlag, StartDateActive, EndDateActive, DisplaySequence, Tag, optional lookupsDFF context values | Return issues before preview or import | Use LookupType ORA_SVC_CHANNEL_TYPE_CD, validate against standardLookups lookupCodes, and cross-check serviceChannelTypesLOV only when channel visibility flags are needed | Planning channel type values | resolve_channel_type_lookup_code |
| ORA_MANAGE_CHANNEL_TYPE_PROPERTIES | Manage Service Request Channel Type Visibility | Channel property decision | LookupCode, PropertyName, PropertyLookupCode, PropertyValue | Return issues before preview or import | Resolve LookupCode under ORA_SVC_CHANNEL_TYPE_CD. Set PropertyName and PropertyLookupCode identically to INTERACTIVE or ENABLED_FOR_COLLABORATION; derive PropertyMeaning and DisplayedPropertyName from the Standard Lookup Meaning. Set PropertyValue to Y or N. | Changing channel visibility | resolve_channel_type_visibility |
| ORA_SVC_SERVICE_REQUEST_SOURCES | Manage Service Request Sources | Service request source definition | Meaning; optional LookupCode, DisplaySequence, EnabledFlag, Description, StartDateActive, EndDateActive, and Tag | Return issues before preview or import | Use the reviewed ORA_SVC_SOURCE_CD standard-lookup export. Meaning is required; generate an omitted LookupCode from Meaning and Description, default an omitted EnabledFlag to Y, and leave an omitted DisplaySequence blank. | Any service request source setup change | resolve_service_request_source_lookup_code |
| ORA_SVC_MANAGE_SERVICE_REQUEST_PROBLEM_TYPES | Manage Service Request Problem Types | Problem type definition | Meaning; optional LookupCode, DisplaySequence, EnabledFlag, Description, StartDateActive, EndDateActive, and Tag | Return issues before preview or import | Use the reviewed ORA_SVC_SR_PROBLEM_TYPE_CD standard-lookup export. Meaning is required. Generate an omitted LookupCode from Meaning and Description without the ORA prefix, default an omitted EnabledFlag to Y, and leave omitted DisplaySequence, active dates, and Tag blank. | Any problem type setup change | resolve_problem_type_lookup_code |
| ORA_SVC_MANAGE_SERVICE_REQUEST_CONTACT_RELATIONSHIP_TYPES | Manage Service Request Contact Relationship Types | Contact relationship type definition | Meaning, DisplaySequence; optional LookupCode, EnabledFlag, Description, StartDateActive, EndDateActive, and Tag | Return issues before preview or import | Use the reviewed ORA_SVC_CONTACT_REL_TYPE_CD standard-lookup export. Meaning and DisplaySequence are required. Generate an omitted LookupCode from Meaning and Description without the ORA prefix, default an omitted EnabledFlag to Y, and leave omitted active dates and Tag blank. | Any contact relationship type setup change | resolve_contact_relationship_type_lookup_code |
| ORA_SVC_SERVICE_REQUEST_STATUS | Manage Service Request Status Values | Status value and parent-status relationship definition | For a standalone status: LookupType, Meaning, DisplaySequence; optional LookupCode, EnabledFlag, Description, StartDateActive, EndDateActive, and Tag. For a parent relationship: ChildLookupCode and ParentLookupCode; optional EnabledFlag and DisplaySequence. | Return issues before preview or import | Use the reviewed FND_APP_STANDARD_LOOKUP and ORA_FND_APP_STANDARD_LOOKUP_CODE templates for a standalone status under ORA_SVC_SR_STATUS_CD. Generate an omitted customer-owned LookupCode without the ORA prefix and default an omitted EnabledFlag to Y. When a parent relationship is requested, use ORA_SVC_LOOKUP_CODE_RELS; resolve ParentLookupCode with core.fusion-api.apps-common using ParentLookupType, then set ChildLookupType ORA_SVC_SR_STATUS_CD, ParentLookupType ORA_SVC_SR_STATUS_TYPE_CD, and both relationship-code fields ORA_SVC_STATUS_TYPE_STATUS. | Any Service Request status setup change | resolve_service_request_status |
| ORA_MANAGE_SERVICE_REQUEST_OUTCOMES_AND_RESOLUTIONS | Manage Service Request Outcomes and Resolutions | Outcome, resolution, and optional mapping definition | For a standalone outcome or resolution: LookupType, Meaning, DisplaySequence; optional LookupCode, EnabledFlag, Description, StartDateActive, EndDateActive, and Tag. For a mapping: ChildLookupCode and ParentLookupCode; optional EnabledFlag and DisplaySequence. | Return issues before preview or import | Use the reviewed FND_APP_STANDARD_LOOKUP and ORA_FND_APP_STANDARD_LOOKUP_CODE templates for standalone Outcome (ORA_SVC_RESOLVE_OUTCOME_CD) or Resolution (ORA_SVC_SR_RESOLUTION_CD) values. Generate an omitted customer-owned LookupCode without the ORA prefix and default an omitted EnabledFlag to Y. Use ORA_SVC_LOOKUP_CODE_RELS only when mapping; default the fixed type and relation-code fields from the contract. | Any outcome or resolution setup change |  |
| ORA_SVC_MANAGE_SERVICE_REQUEST_PROFILE_OPTIONS | Manage Service Request Profile Options | Existing profile option value | Existing ProfileOptionName and customer-required ProfileOptionValue; optional supported LevelName and LevelValue | Return issues before preview or import | Use the reviewed FND_APP_PROFILE_OPTION, ORA_FND_APP_PROFILE_OPTION_LEVEL, and FND_APP_PROFILE_VALUE export rows. Retain definition and level metadata; use the selected option's exported supported LevelName and LevelValue, defaulting both to SITE only when no supported level is supplied. Validate the customer-required value against documented semantics. | Changing existing SR profile options |  |
| ORA_SVC_SERVICE_REQUEST_CATEGORIES | Manage Service Request Categories | Category hierarchy | ORA_SVC_CATEGORY: StripeCd, CategoryShortName, BusinessUnitName, CategoryName, CategoryCode, ParentCategoryCode, EnabledFlag, DeletedFlag, CSSFlag, BUOrgId, Depth, Hierarchy, ChildCountParentCategoryId, CategoryIdHierarchy, RootCategoryCode, CategoryDescription; for a child relationship: ORA_SEVICE_CATEGORY_ASSOCIATION child and parent StripeCd, CategoryShortName, and BUOrgId values | Return issues before preview or import | Use the reviewed same-task FSM export. For an existing row retain exported identities and hierarchy values; for a new generated code, use uppercase letters, digits, and underscores only, normalize spaces, hyphens, and other separators to underscores, and collapse repeated underscores. For a new top-level category provide the category identity and leave ParentCategoryCode blank; for a child provide the parent code and the required association row. | Designing or changing service request categories | resolve_service_request_categories |
| ORA_SVC_MANAGE_SR_KNOWLEDGE_PROFILE_OPTIONS | Manage Service Request Knowledge Profile Options | Existing Knowledge profile option value | SVC_ENABLE_KNOWLEDGE_IN_SR and customer-required ProfileOptionValue; optional supported LevelName and LevelValue | Return issues before preview or import | Use the reviewed FND_APP_PROFILE_OPTION, ORA_FND_APP_PROFILE_OPTION_LEVEL, and FND_APP_PROFILE_VALUE export rows. Retain definition and level metadata; use the exported supported level, defaulting LevelName and LevelValue to SITE only when no supported level is supplied. Set Y only after Knowledge is in scope and the required administrator role is confirmed. | Enabling Knowledge in Service Requests |  |
| ORA_MANAGE_OBJECT_LINK_TYPES | Manage Object Link Types | Object link type definition | LinkTypeNumber, Name, ShortName, EnabledFlag, OutwardCd, InwardCd | Return issues before preview or import | Validate LinkTypeNumber or ShortName against objectLinkTypes before create or update | Creating or updating object link types | resolve_object_link_type |

## Dependency-Aware Validation

| Task Code | Task Name | Applies When | Result | Next Action | Resolver |
|---|---|---|---|---|---|
| ORA_SVC_MANAGE_SR_SEVERITIES_R13 | Manage Service Request Severities | A new severity Meaning is absent | Blocked | Request the required Meaning before generating a LookupCode or Tag |  |
| ORA_SVC_MANAGE_SR_SEVERITIES_R13 | Manage Service Request Severities | DisplaySequence or Tag is absent | Allowed | Leave the omitted optional field blank |  |
| ORA_MANAGE_CHANNEL_TYPE_PROPERTIES | Manage Service Request Channel Type Visibility | PropertyName is not identical to PropertyLookupCode, or either value is not INTERACTIVE or ENABLED_FOR_COLLABORATION | Blocked | Use the technical Standard Lookup code identically in PropertyName and PropertyLookupCode; do not use a meaning or display label |  |
| ORA_MANAGE_CHANNEL_TYPE_PROPERTIES | Manage Service Request Channel Type Visibility | Property Value is not Y or N | Blocked | Request Y or N because FSM import expects the channel visibility property value in flag format |  |
| ORA_SVC_SERVICE_REQUEST_CATEGORIES | Manage Service Request Categories | A child category is supplied without ParentCategoryCode or the parent association identity | Blocked | Request the parent category code plus parent StripeCd, CategoryShortName, and BUOrgId, or confirm that the row is top-level | resolve_service_request_categories |
| ORA_SVC_MANAGE_SR_KNOWLEDGE_PROFILE_OPTIONS | Manage Service Request Knowledge Profile Options | Knowledge Management is not in scope | Blocked | Confirm Knowledge Management scope before setting SVC_ENABLE_KNOWLEDGE_IN_SR |  |
| ORA_MANAGE_OBJECT_LINK_TYPES | Manage Object Link Types | ShortName is absent on create | Blocked | Request ShortName because inward and outward codes are generated from it |  |

## Field Validation

| Task Code | Task Name | Check | What Happens | Applies When | Resolver |
|---|---|---|---|---|---|
| ORA_SVC_MANAGE_SERVICE_REQUEST_CHANNEL_TYPES | Manage Service Request Channel Types | LookupType must be ORA_SVC_CHANNEL_TYPE_CD and LookupCode must be 30 characters or fewer | Block preview when the lookup type is different, the lookup code is missing, or the code exceeds the standard lookup-code limit | Every channel type setup request | resolve_channel_type_lookup_code |
| ORA_SVC_MANAGE_SERVICE_REQUEST_CHANNEL_TYPES | Manage Service Request Channel Types | Meaning must be 80 characters or fewer; Description must be 240 characters or fewer; EnabledFlag must be Y or N | Return row-level issues before preview or import | Creating or updating a standard lookup code | resolve_channel_type_lookup_code |
| ORA_SVC_MANAGE_SERVICE_REQUEST_CHANNEL_TYPES | Manage Service Request Channel Types | StartDateActive and EndDateActive must be date values when provided; DisplaySequence must be an integer when provided; Tag must be 150 characters or fewer | Return row-level issues before preview or import | Creating or updating a standard lookup code | resolve_channel_type_lookup_code |
| ORA_SVC_MANAGE_SERVICE_REQUEST_CHANNEL_TYPES | Manage Service Request Channel Types | lookupsDFF values require a supplied __FLEX_Context and documented segment contract | Block DFF mutation when the flex context or segment contract is missing | When a request includes channel type DFF values | resolve_channel_type_lookup_code |
| ORA_SVC_SERVICE_REQUEST_CATEGORIES | Manage Service Request Categories | A generated CategoryCode must contain only uppercase letters, digits, and underscores, with no repeated underscores | Return issues before preview or import; normalize source separators to one underscore before generating the code | Generating a new Service Request category code | resolve_service_request_categories |
