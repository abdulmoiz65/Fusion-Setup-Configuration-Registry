## Lookup Execution Rules

| Task Code | Task Name | Situation | What Happens |
|---|---|---|
| ORA_SVC_MANAGE_SR_SEVERITIES_R13 | Manage Service Request Severities | Lookup code is not unique under ORA_SVC_SR_SEVERITY_CD | Return issues before preview |
| ORA_SVC_MANAGE_SERVICE_REQUEST_INTERNAL_PRIORITIES | Manage Service Request Internal Priorities | Internal-priority lookup code is not unique under ORA_SVC_SR_INT_PRIORITY_CD | Return issues before preview |
| ORA_SVC_MANAGE_SERVICE_REQUEST_CHANNEL_TYPES | Manage Service Request Channel Types | Requested channel code is outside the documented predefined ORA_SVC channel codes and no Oracle source confirms the extension path | Return issues before preview; if a confirmed create or update is requested, use the standard lookup-code contract and block DFF segment handling unless a flex context is supplied |
| ORA_MANAGE_CHANNEL_TYPE_PROPERTIES | Manage Service Request Channel Type Visibility | Channel is missing from the channel type LOV | Return issues before preview |
| ORA_SVC_SERVICE_REQUEST_SOURCES | Manage Service Request Sources | Service-request source lookup code is not unique under ORA_SVC_SOURCE_CD | Return issues before preview |
| ORA_SVC_MANAGE_SERVICE_REQUEST_PROBLEM_TYPES | Manage Service Request Problem Types | Problem-type lookup code is not unique under ORA_SVC_SR_PROBLEM_TYPE_CD | Return issues before preview |
| ORA_SVC_MANAGE_SERVICE_REQUEST_CONTACT_RELATIONSHIP_TYPES | Manage Service Request Contact Relationship Types | Contact relationship type lookup code is not unique under ORA_SVC_CONTACT_REL_TYPE_CD | Return issues before preview |
| ORA_SVC_SERVICE_REQUEST_STATUS | Manage Service Request Status Values | Status code lookup cannot be resolved from the status LOV | Return issues before preview |
| ORA_MANAGE_OBJECT_LINK_TYPES | Manage Object Link Types | Object link type has DeleteFlag false and request asks to delete | Return issues before live delete approval |
