## Lookup Execution Rules

| Task Code | Task Name | Situation | What Happens |
|---|---|---|---|
| ORA_SVC_MANAGE_SEARCH_OPTIONS | Manage Global Search Profile Options | A Global Search profile-value lookup is requested | Resolve the exact Site-level FUSION_APPS_SEARCH_ENABLED record and return only Y or N; stop on no match, ambiguity, or an invalid value. |
| ORA_SVC_MANAGE_SERVICE_REQUEST_DYNAMIC_LINKS | Manage Service Request Dynamic Links | A Dynamic Link collection read is requested | Send the documented GET with no request body. Follow hasMore using supported limit and offset paging; do not create, update, or delete a record. |
| ORA_SVC_MANAGE_TAGS | Manage Tags | A Tags collection read is requested | Send the documented GET with no request body. Follow hasMore using supported limit and offset paging; do not create, update, or delete a tag. |
| ORA_CONFIGURE_ACTION_BAR_PARAMETERS | Configure Action Bar Parameters | An Action Bar configuration collection read is requested | Send the documented GET with no request body. Follow hasMore using supported limit and offset paging; do not create or update a configuration. |
| ORA_SVC_MANAGE_NOTE_TYPES | Manage Note Types | A Note Types collection read is requested | Send the documented GET with no request body and use offset and limit only when hasMore is true; do not create, update, or delete a lookup code. |
| ORA_MANAGE_SERVICE_REQUEST_MESSAGE_TYPES_AND_SUBTYPES | Manage Service Request Message Types and Subtypes | A Message Type or Subtype collection read is requested | Send the documented GET with no request body and use offset and limit only when hasMore is true; do not create, update, or delete a lookup code. |
| ORA_SVC_MANAGE_PASSIVE_BEACON_CONFIGURATION | Manage Passive Beacon Configuration | A passive Beacon provider-status collection read is requested | Send the documented GET with no request body. Follow hasMore using supported limit and offset paging; do not create, update, or delete a status. |
