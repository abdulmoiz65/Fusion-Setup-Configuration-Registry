## Lookup Execution Rules

| Task Code | Task Name | Situation | What Happens |
|---|---|---|---|
| QSC_MANAGE_PRODUCT_GROUPS | Manage Product Groups | A target ID, reference number, or internal name is supplied for an existing product-group action | Run resolve_product_group_identity before constructing a preview. |
| QSC_MANAGE_PRODUCT_GROUPS | Manage Product Groups | A read-only product-group collection is requested | Run list_product_groups with only documented query parameters. |
| QSC_MANAGE_PRODUCT_GROUPS | Manage Product Groups | A read-only product-relationship collection is requested | Run list_product_group_product_relationships with only documented query parameters. |
| QSC_MANAGE_PRODUCT_GROUPS | Manage Product Groups | A product relationship must be read or updated | Run resolve_product_group_product_relationship and use the server-returned ProdGroupItemsId. |
| QSC_MANAGE_PRODUCT_GROUPS | Manage Product Groups | Subgroups are requested for one parent product group | Resolve the parent identity, then run list_product_group_subgroups with the server-returned ProdGroupId. |
| QSC_MANAGE_PRODUCT_GROUPS | Manage Product Groups | Products associated to one product group are requested | Resolve the parent identity, then run list_product_group_product_relationships filtered by the server-returned ProdGroupId. |
| QSC_MANAGE_PRODUCT_GROUPS | Manage Product Groups | Filter attributes are created or requested for one product group | Resolve the parent identity before the immutable preview or child collection read. |
| QSC_MANAGE_PRODUCT_GROUP_USAGE | Manage Product Group Usage | A read-only usage collection is requested | Run list_product_group_usages with only documented query parameters. |
| QSC_MANAGE_PRODUCT_GROUP_USAGE | Manage Product Group Usage | A usage item or usage-scoped subcategory collection is requested | Run resolve_product_group_usage before the requested child lookup. |
| QSC_MANAGE_PRODUCT_GROUP_USAGE | Manage Product Group Usage | Usage engines, modes, preferences, or roots are requested | Use the matching usage-scoped collection lookup after resolving UsageCode. |
