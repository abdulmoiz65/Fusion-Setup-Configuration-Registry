# Input Validation

This resource owns request-shape validation for the scoped Service Catalog tasks. It does not authorize a REST mutation or an FSM import.

## Required Groups

|---|---|---|---|---|---|---|---|

| QSC_MANAGE_PRODUCT_GROUPS | Manage Product Groups | Existing product group action | ProdGroupId; or ProductGroupReferenceNumber; or InternalName | Stop before preview | Provide one exact identifier supported by the documented read API. | Update, delete, lock, or release-lock is requested | resolve_product_group_identity |
| QSC_MANAGE_PRODUCT_GROUPS | Manage Product Groups | FSM import | Immutable FSM package | Stop as unsupported | Use the selected documented REST execution route after its preview and approval gates; the effective setup-task catalog does not support export/import for this task. | FSM import is requested | |

## Field Validation

| Task Code | Task Name | Check | What Happens | Applies When | Resolver |
|---|---|---|---|---|---|
| QSC_MANAGE_PRODUCT_GROUPS | Manage Product Groups | Active flag | Accept at most one character when provided. | Create or update input includes ActiveFlag | |
| QSC_MANAGE_PRODUCT_GROUPS | Manage Product Groups | Optional text limits | Reject values that exceed the documented limits: ProdGroupDescription 1000, ProductGroupReferenceNumber 50, RevenueCategoryCode 30, and RevenueRoleCode 30 characters. | A corresponding field is supplied | |
| QSC_MANAGE_PRODUCT_GROUPS | Manage Product Groups | Date shape | Require date-time values for StartDate and EndDate when supplied. | A corresponding field is supplied | |
| QSC_MANAGE_PRODUCT_GROUPS | Manage Product Groups | Mutation route | Require a selected execution route, immutable preview, and current explicit approval before any POST, PATCH, DELETE, lock, release, or publish operation. | A mutation is requested | |
| QSC_MANAGE_PRODUCT_GROUPS | Manage Product Groups | Product relationship field shape | Require integer values for InventoryItemId, InvOrgId, ProdGroupId, ProdGroupItemsId, and DisplayOrderNum when supplied; require date-time values for StartDate and EndDate; limit ParPGReferenceNumber to 50 characters. | A product relationship request supplies the corresponding fields | |
| QSC_MANAGE_PRODUCT_GROUPS | Manage Product Groups | Subgroup create field shape | Require an integer Parent ProdGroupId; InternalName no longer than 150 characters; ProdGroupName no longer than 250 characters; and date-time values for StartDate, EndDate, GroupAssociationEffectiveFromDate, and GroupAssociationEffectiveToDate when supplied. | A subgroup-create request supplies the corresponding fields | resolve_product_group_identity |
| QSC_MANAGE_PRODUCT_GROUPS | Manage Product Groups | Filter attribute create field shape | Require integer values for Parent ProdGroupId, AttributeOptionId, and DisplayOrderNum when supplied; limit AttrName to 250 characters. | A filter-attribute create request supplies the corresponding fields | resolve_product_group_identity |
| QSC_MANAGE_PRODUCT_GROUP_USAGE | Manage Product Group Usage | Usage code length | Reject a UsageCode longer than 30 characters. | A usage item or child request supplies UsageCode | |
