## Lookup Execution Rules

| Task Code | Task Name | Situation | What Happens |
|---|---|---|---|
| ORA_SVC_MANAGE_COMM_CHANNELS | Manage Communication Channels | Communication channel identity or duplicate status must be checked | Use the documented Channels collection GET, match ChannelShortName exactly to the requested ChannelCode, and stop on multiple matches; this lookup does not authorize a channel write |
| ORA_SVC_MANAGE_COMM_CHANNELS | Manage Communication Channels | A selected communication channel is viewed | Accept exactly one of ChannelId, ChannelShortName, or DisplayName. Use an item GET for ChannelId, or an exact collection match for short name or display name; stop when a name selector is non-unique |
| ORA_MANAGE_EMAIL_PROFILE_OPTIONS | Manage Email Profile Options | Profile option values are checked | Read profile definitions and values only; definitions are read-only and value writes need a separate preview and approval |
| ORA_SVC_MANAGE_EMAIL_FILTERS | Manage E-Mail Filters | Inbound message filters are listed or preflighted | Use documented GET endpoints and lookup-code checks before any create or update preview |
| ORA_SVC_MANAGE_OMNI_CHANNEL_PROFILE_OPTS | Manage Omnichannel Profile Options | Profile option values are checked | Read profile definitions and values only; definitions are read-only and value writes need a separate preview and approval |
| ORA_MANAGE_MCA_PROFILE_OPTIONS | Manage MCA Profile Options | Profile option values are checked | Read profile definitions and values only; definitions are read-only and value writes need a separate preview and approval |
| ORA_SVC_INTERACTION_PROFILE_OPTIONS | Manage Interaction Profile Options | Profile option values are checked | Read profile definitions and values only; definitions are read-only and value writes need a separate preview and approval |
