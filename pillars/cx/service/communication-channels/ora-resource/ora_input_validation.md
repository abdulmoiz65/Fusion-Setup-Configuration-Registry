## Field Validation

| Task Code | Task Name | Check | What Happens | Applies When | Resolver |
|---|---|---|---|---|---|
| ORA_SVC_MANAGE_COMM_CHANNELS | Manage Communication Channels | Channel code uniqueness | Match the requested business ChannelCode exactly against ChannelShortName; block preview when an existing channel matches, otherwise continue to design checks | Email channel setup | resolve_email_channel_by_code |
| ORA_SVC_MANAGE_COMM_CHANNELS | Manage Communication Channels | Email channel account name | AccountName must be the company support email address for the channel; forwarding to the Oracle inbound address must be confirmed outside this resource | Email channel setup |  |
| ORA_SVC_MANAGE_COMM_CHANNELS | Manage Communication Channels | Generated channel short name | For a new row, ChannelShortName is AccountName in uppercase with spaces removed and must be unique in the same-task export | Create communication channel | resolve_email_channel_by_code |
| ORA_SVC_MANAGE_COMM_CHANNELS | Manage Communication Channels | Required lookup codes | ChannelTypeCd, StripeCd, and PurposeCd must be validated through their declared Common lookup before package preparation | Create or change communication channel |  |
| ORA_SVC_MANAGE_COMM_CHANNELS | Manage Communication Channels | Business-unit linkage | BUOrgId is sourced through the Business Unit skill and BusinessUnitIdFK must equal the resolved BUOrgId; BusinessUnitName fields remain blank for a new row | Create or change communication channel |  |
| ORA_SVC_MANAGE_COMM_CHANNELS | Manage Communication Channels | Sensitive integration fields | APIPassword, AccessToken, RefreshToken, and AuthToken must be blank in the FSM package | Create or change communication channel |  |
| ORA_MANAGE_EMAIL_PROFILE_OPTIONS | Manage Email Profile Options | Profile definition is read-only | Block any request that attempts to create, update, or delete a profile option definition | Any email profile option request | get_profile_option_definition |
| ORA_MANAGE_EMAIL_PROFILE_OPTIONS | Manage Email Profile Options | Exported definition and level fields are preserved | Retain exported FND_APP_PROFILE_OPTION definition fields, ORA_FND_APP_PROFILE_OPTION_LEVEL flags, and audit fields; do not enable an unsupported profile level | Any approved FSM package update | get_profile_option_definition |
| ORA_MANAGE_EMAIL_PROFILE_OPTIONS | Manage Email Profile Options | Profile value update is task-owned | Change only the approved FND_APP_PROFILE_VALUE ProfileOptionValue; retain exported profile identity, application ID, level, level value, and unchanged audit fields | Any approved FSM package update | get_profile_option_definition |
| ORA_SVC_MANAGE_INBOUND_EMAIL_PROFILE_OPTS | Manage Inbound E-Mail Profile Options | Parent task route is required | Do not create a profile option definition; retain exported FND_APP_PROFILE_OPTION and ORA_FND_APP_PROFILE_OPTION_LEVEL values and change only the approved FND_APP_PROFILE_VALUE ProfileOptionValue through Manage Email Profile Options | Any inbound email profile option value request |  |
| ORA_SVC_MANAGE_OUTBOUND_EMAIL_PROFILE_OPTS | Manage Outbound E-Mail Profile Options | Parent task route is required | Do not create a profile option definition; retain exported FND_APP_PROFILE_OPTION and ORA_FND_APP_PROFILE_OPTION_LEVEL values and change only the approved FND_APP_PROFILE_VALUE ProfileOptionValue through Manage Email Profile Options | Any outbound email profile option value request |  |
| ORA_SVC_MANAGE_EMAIL_FILTERS | Manage E-Mail Filters | Required filter fields | FilterTypeCd, Pattern, and ActionCd are required; CustomFilterFlag must be `Y` and DeletedFlag must be `N` for a new filter; FieldName is required for Header filters | Create or update inbound message filter | resolve_inbound_filter_lookup_codes |
| ORA_SVC_MANAGE_EMAIL_FILTERS | Manage E-Mail Filters | Pattern length and regular expression intent | Pattern must be nonempty and no longer than 400 characters; reviewers must confirm the regular expression intent before approval | Create or update inbound message filter |  |
| ORA_SVC_MANAGE_EMAIL_FILTERS | Manage E-Mail Filters | Action and filter type lookup codes | Use core.fusion-api.apps-common to read enabled ActionCd values from ORA_SVC_INBND_FLTR_ACTION_TYPE and FilterTypeCd values from ORA_SVC_INBND_FLTR_FIELD_TYPE | Create or update inbound message filter | resolve_inbound_filter_lookup_codes |
| ORA_SVC_MANAGE_OMNI_CHANNEL_PROFILE_OPTS | Manage Omnichannel Profile Options | Omnichannel profile definition is read-only | Block any request that attempts to create, update, or delete a profile option definition | Any Omnichannel profile option request | get_profile_option_definition |
| ORA_MANAGE_MCA_PROFILE_OPTIONS | Manage MCA Profile Options | MCA profile definition is read-only | Block any request that attempts to create, update, or delete a profile option definition | Any MCA profile option request | get_profile_option_definition |
| ORA_SVC_INTERACTION_PROFILE_OPTIONS | Manage Interaction Profile Options | Interaction retention days | SVC_INTERACTION_RETENTION_DAYS must be 1 or greater before Purge Interactions can use it | Interaction retention profile option request | get_profile_option_definition |
