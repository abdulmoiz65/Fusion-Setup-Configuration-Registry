## Lookup Execution Rules

| Task Code | Task Name | Situation | What Happens |
|---|---|---|---|
| ORA_SVC_MANAGE_CSS_REG_PROFILE_OPTS | Manage Digital Customer Service Profile Options | The profileValues API is used | Treat it as read-only current-session evidence;do not use it to create or update profile option values;use a same-task export when the caller needs Profile Level, Product Name, User Name, or persisted screen-level profile-value rows |
| ORA_SVC_MANAGE_CSS_ACCOUNT_SETUP_OPTS | Manage Digital Customer Service Account Setup Profile Options | The profileValues API is used | Treat it as read-only current-session evidence;do not use it to create or update profile option values;use a same-task export when the caller needs Profile Level, Product Name, User Name, or persisted screen-level profile-value rows |
| ORA_SVC_MANAGE_SELF_SERVICE_RELATIONSHIP_TYPE_STANDARD_LOOKUP | Manage Self-Service Relationship Type Standard Lookup | Standard lookup code lookup is used | Use the fixed lookup type ORA_SVC_CSS_REL_TYPE_CD and do not query or update unrelated lookup types |
| ORA_CREATE_DIGITAL_CUSTOMER_SERVICE_CUSTOM_ROLE_MAPPING | Manage Custom Role Mapping for Digital Customer Service | selfServiceRoles API evidence is used | Use it only to inspect or grant roles to a self-service user;do not treat it as proof that the Manage Custom Role Mapping FSM task is complete |
