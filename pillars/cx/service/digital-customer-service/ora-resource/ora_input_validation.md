# Input Validation

## Required Groups

| Task Code | Task Name | Requirement Group | Accepted Fields | If Missing | How to Resolve | Applies When | Resolver |
|---|---|---|---|---|---|---|---|
| ORA_SVC_MANAGE_CSS_REG_PROFILE_OPTS | Manage Digital Customer Service Profile Options | Digital Customer Service profile option update | ProfileOptionName from the documented or same-task-exported Digital Customer Service registration, self-service, chat, allowed-origins, CORS, proxy-user whitelist, and PUDS profile option list;ProfileOptionValue compatible with the documented possible values;same-task FSM export rows when importing setup data | Block preview and import | Provide the profile option code, intended value, and same-task FSM export or template package evidence | Any request to change Digital Customer Service registration, self-service, access, chat, allowed-origins, CORS, proxy-user whitelist, or PUDS profile options | |
| ORA_SVC_MANAGE_CSS_ACCOUNT_SETUP_OPTS | Manage Digital Customer Service Account Setup Profile Options | Account setup profile option update | ProfileOptionName SVC_AC_MQS_ACCOUNT_ID or SVC_AC_MQS_DATA_CENTER;ProfileOptionValue compatible with the documented possible values;same-task FSM export rows when importing setup data | Block preview and import | Provide the account message queue profile option code, intended value, and same-task FSM export or template package evidence | Any request to change account setup profile options for Customer Self-Service | |
| ORA_MANAGE_PROXY_USER_CONFIGURATION_DATA | Manage Proxy User Configuration Data | Proxy user configuration data | URL Pattern, HTTP Methods, IdP User Roles, Priority when applicable, Proxy User Key, Active flag, and credential-entry instructions that do not persist secrets | Block preview and import | Provide the URL pattern, method list, role, proxy user key, active flag, and same-task FSM export or documented UI evidence | Any request to add or update proxy user configuration data | |
| ORA_SVC_MANAGE_SELF_SERVICE_RELATIONSHIP_TYPE_STANDARD_LOOKUP | Manage Self-Service Relationship Type Standard Lookup | Self-service relationship type lookup code | LookupType ORA_SVC_CSS_REL_TYPE_CD;LookupCode;Meaning;optional Description, EnabledFlag, StartDateActive, EndDateActive, DisplaySequence, and Tag | Block preview and import | Provide the lookup code and meaning, then verify the fixed lookup type and same-task package structure | Any request to create or update self-service relationship type lookup values | |
| ORA_CREATE_DIGITAL_CUSTOMER_SERVICE_CUSTOM_ROLE_MAPPING | Manage Custom Role Mapping for Digital Customer Service | Custom role mapping | Self-Service Role and Job Role selected from existing or approved custom roles | Block execution | Provide the custom self-service role and identity-provider job role after prerequisite role setup is complete | Any request to map a custom self-service role to a job role | |

## Field Validation

| Task Code | Task Name | Check | What Happens | Applies When | Resolver |
|---|---|---|---|---|---|
| ORA_SVC_MANAGE_CSS_REG_PROFILE_OPTS | Manage Digital Customer Service Profile Options | Profile option code must be from the documented DCS option list or from an approved same-task export, including SVC_CSS_SEND_WELCOME_EMAIL, ORA_SVC_CSS_SELF_REG_B2C_AUTO_APPROVE, SVC_CHAT_ANONYMOUS_ACCESS_ENABLED, ORACLE.ADF.VIEW.ALLOWED_ORIGINS, SVC_CHAT_INLAYS_ACCESS_ENABLED, FND_IDP_PROXY_USER_WHITELIST, CORS_ACCESS_CONTROL_ALLOW_HEADERS, SVC_CSS_REG_CONT_MAP, SVC_CSS_REG_FLD_CONTACT, SVC_CSS_SELF_REGISTRATION, and SVC_CSS_SELF_REG_AUTO_APPROVE when confirmed for this task | Reject unknown profile option codes before preview | Profile option changes are requested | |
| ORA_SVC_MANAGE_CSS_ACCOUNT_SETUP_OPTS | Manage Digital Customer Service Account Setup Profile Options | Account setup profile option code must be SVC_AC_MQS_ACCOUNT_ID or SVC_AC_MQS_DATA_CENTER unless same-task evidence adds another code | Reject unknown account setup option codes before preview | Account setup profile option changes are requested | |
| ORA_MANAGE_PROXY_USER_CONFIGURATION_DATA | Manage Proxy User Configuration Data | Proxy user passwords and secret material must not be written to files | Redact and stop before artifact persistence | Credential fields are present in user input, exports, diagnostics, or generated files | |
| ORA_SVC_MANAGE_SELF_SERVICE_RELATIONSHIP_TYPE_STANDARD_LOOKUP | Manage Self-Service Relationship Type Standard Lookup | Lookup code request must use fixed lookup type ORA_SVC_CSS_REL_TYPE_CD | Reject attempts to change another lookup type through this task | Standard lookup setup is requested | |
| ORA_CREATE_DIGITAL_CUSTOMER_SERVICE_CUSTOM_ROLE_MAPPING | Manage Custom Role Mapping for Digital Customer Service | Ready-to-use self-service roles are not mapped to identity provider roles | Block the mapping request and ask for a custom self-service role | The selected self-service role is not custom | |
