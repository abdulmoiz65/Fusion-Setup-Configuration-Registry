## Lookup Execution Rules

| Task Code | Task Name | Situation | What Happens |
|---|---|---|---|
| ORA_CSO_LOCALES_MGMT | Manage Knowledge Locales | Request needs the complete supported-locale list | Use the `Available Knowledge Locales` section in `manage-knowledge-locales.md`, sourced from Oracle's Available Locales documentation; do not infer it from a REST response |
| ORA_CSO_LOCALES_MGMT | Manage Knowledge Locales | Request needs tenant locale setup data or active/inactive state | Use the completed Manage Knowledge Locales FSM export/import workflow; `ORA_CSO_ACTIVE_LOCALE_OBJECT.csv` is authoritative for activity. |
| ORA_CSO_LOCALES_MGMT | Manage Knowledge Locales | Request needs default or default-preferred locale state | Read `defaultLocale` and `defaultPreferredLocale` from `ORA_CSO_LOCALE_OBJECT.csv` in the completed FSM export. |
| ORA_CSO_LOCALES_MGMT | Manage Knowledge Locales | Request invokes the Get Locales API | Do not use the response to determine whether a tenant Knowledge locale is active or inactive. |
| ORA_CSO_USER_GROUPS_MGMT | Manage Knowledge User Groups | Request invokes the Get User Groups API | Use core.fusion-api.rest-api-client with the relative /km/api/v1/userGroups endpoint; the shared client joins it to the configured restBaseUrl |
| ORA_CSO_USER_GROUPS_MGMT | Manage Knowledge User Groups | Request provides a Business Unit name or validates businessUnitIds while Business Unit Support is enabled | Use the read-only finBusinessUnitsLOV endpoint to resolve one active exact BusinessUnitName or BusinessUnitId, then populate businessUnitIds with the returned BusinessUnitId. The endpoint does not establish an additional Service-specific eligibility rule. |
| ORA_CSO_KNOWLEDGE_PANEL_PROFILE_MGMT | Manage Knowledge Panel Profile Options | Request updates a Knowledge Panel profile option | Use a completed task FSM export as the package baseline and reconciliation evidence. Retain exported definition, level, and audit values, and do not use a REST route as a substitute for the approved FSM workflow. |
| ORA_CSO_KNOWLEDGE_SEARCH_PROFILE_MGMT | Manage Knowledge Search Profile Options | Request updates a Knowledge Search profile option | Use a completed task FSM export as the package baseline and reconciliation evidence. Retain exported definition, level, and audit values, and do not use a REST route as a substitute for the approved FSM workflow. |
| ORA_CSO_MY_KNOWLEDGE_PROFILE_MGMT | Manage My Knowledge Profile Options | Request updates a My Knowledge profile option | Use a completed task FSM export as the package baseline and reconciliation evidence. Retain exported definition, level, and audit values, and do not use a REST route as a substitute for the approved FSM workflow. |
| ORA_MANAGE_KNOWLEDGE_COMMON_PROFILE_OPTION | Manage Knowledge Common Profile Options | Request updates a Knowledge Common profile option | Use a completed task FSM export as the package baseline and reconciliation evidence. Retain exported definition, level, and audit values, and do not use a REST route as a substitute for the approved FSM workflow. |
