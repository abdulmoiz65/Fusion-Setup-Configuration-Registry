## Dependency-Aware Validation

| Task Code | Task Name | Applies When | Result | Next Action | Resolver |
|---|---|---|---|---|---|
| ORA_CSO_LOCALES_MGMT | Manage Knowledge Locales | Requested default locale is not active | Blocked | Select a locale present in the FSM active-locale object before setting the default Knowledge locale | resolve_fsm_locale_state |
| ORA_CSO_LOCALES_MGMT | Manage Knowledge Locales | Requested locale is the current default locale and operation is disable | Blocked | Keep the default locale active or select another active default locale before disabling the current default locale | resolve_fsm_locale_state |
| ORA_CSO_LOCALES_MGMT | Manage Knowledge Locales | Requested locale is inactive and operation is a locale review | Satisfied | Confirm that the requested code is supported through the `Available Knowledge Locales` section in `manage-knowledge-locales.md` and use the Manage Knowledge Locales FSM workflow for tenant setup-data review |  |

## Field Validation

| Task Code | Task Name | Check | What Happens | Applies When | Resolver |
|---|---|---|---|---|---|
| ORA_CSO_LOCALES_MGMT | Manage Knowledge Locales | Locale identifier does not resolve to exactly one FSM locale-state record | Reject before preview | A locale operation is requested | resolve_fsm_locale_state |
| ORA_CSO_LOCALES_MGMT | Manage Knowledge Locales | Requested locale code is not a supported application locale | Reject before preview | Enable or set a default locale | resolve_fsm_locale_state |
| ORA_CSO_FILE_ATTACHMENTS_MGMT | Manage Knowledge Files and Images | Allowed file extensions are not supplied | Reject before preview | Configure at least one extension or explicitly use * to allow all file extensions |  |
| ORA_CSO_FILE_ATTACHMENTS_MGMT | Manage Knowledge Files and Images | propertyReferenceKey is not IMCONTENT_FILE_UPLOAD_FORMAT or the package creates an ORA_CSO_FILES_AND_IMAGES row | Reject before preview | Retain the exported property key and existing ORA_CSO_FILES_AND_IMAGES rows; do not create a Files and Images row |  |
| ORA_CSO_ARTICLE_STATUS_MGMT | Manage Knowledge Article Statuses | A user-defined status is missing a localized label for an active locale | Reject before preview | Add a localized label for every active locale |  |
| ORA_CSO_ARTICLE_STATUS_MGMT | Manage Knowledge Article Statuses | A user-defined status has no unique referenceKey | Reject before preview | Generate a unique referenceKey before preparing the FSM package |  |
| ORA_CSO_ARTICLE_STATUS_MGMT | Manage Knowledge Article Statuses | A new user-defined status has a recordId value | Reject before preview | Leave recordId blank so Fusion generates it during creation |  |
| ORA_CSO_ARTICLE_STATUS_MGMT | Manage Knowledge Article Statuses | The feature property is not KM_ARTICLE_STATUS_ENABLED, its value is not TRUE or FALSE, or a root/localized row does not preserve the export-defined object, node order, parent linkage, or locale ID | Reject before preview | Use the exact configuration property; retain existing root fields; use current dates only for approved new or updated statuses; link localized rows to their status referenceKey and resolve localeId from active Manage Knowledge Locales task data | resolve_article_status_active_locale |
| ORA_CSO_ARTICLE_STATUS_MGMT | Manage Knowledge Article Statuses | A status is deactivated while it is used in the latest version of an article | Reject before preview | Remove the status from the latest article versions before deactivation |  |
| ORA_CSO_ARTICLE_STATUS_MGMT | Manage Knowledge Article Statuses | An article status is selected for deletion | Unsupported | Delete the article status from the UI |  |
| ORA_CSO_USER_GROUPS_MGMT | Manage Knowledge User Groups | Reference Key has unsupported characters | Reject before preview | Use only uppercase letters, numbers, and underscores |  |
| ORA_CSO_USER_GROUPS_MGMT | Manage Knowledge User Groups | A new user group has an objectId value or a REST-only recordId column | Reject before preview | Leave objectId blank so Fusion generates it, and remove recordId from the FSM CSV |  |
| ORA_CSO_USER_GROUPS_MGMT | Manage Knowledge User Groups | Root and localized-attribute rows do not retain the export-defined object names, root referenceKey linkage, locale representation, or stripeCd | Reject before preview | Use ORA_CSO_USER_GROUP_OBJECT at node sequence 1 and ORA_KNOWLEDGE_USER_GROUP_LOCALIZED_ATTRIBUTE_OBJECT at node sequence 2; retain an existing stripeCd, use only ORA_SVC_CRM, ORA_SVC_HRHD, or ORA_SVC_ISR for an approved new or updated group, and link each localized row to the exact root referenceKey |  |
| ORA_CSO_USER_GROUPS_MGMT | Manage Knowledge User Groups | A supplied Business Unit name does not resolve to exactly one active BusinessUnitId | Reject before preview | Provide an exact active Business Unit name or ID | resolve_active_business_unit |
| ORA_CSO_KNOWLEDGE_PANEL_PROFILE_MGMT | Manage Knowledge Panel Profile Options | Profile option update lacks a completed export, an existing ProfileOptionName, or an approved ProfileOptionValue | Reject before preview | Complete a task export, select an existing profile option, and provide one approved value | resolve_fsm_panel_profile_option_export |
| ORA_CSO_KNOWLEDGE_SEARCH_PROFILE_MGMT | Manage Knowledge Search Profile Options | Profile option update lacks a completed export, an existing ProfileOptionName, or an approved ProfileOptionValue | Reject before preview | Complete a task export, select an existing profile option, and provide one approved value | resolve_fsm_profile_option_export |
| ORA_CSO_MY_KNOWLEDGE_PROFILE_MGMT | Manage My Knowledge Profile Options | Profile option update lacks a completed export, an existing ProfileOptionName, or an approved ProfileOptionValue | Reject before preview | Complete a task export, select an existing profile option, and provide one approved value | resolve_fsm_my_knowledge_profile_option_export |
| ORA_MANAGE_KNOWLEDGE_COMMON_PROFILE_OPTION | Manage Knowledge Common Profile Options | Profile option update lacks a completed export, an existing ProfileOptionName, or an approved ProfileOptionValue | Reject before preview | Complete a task export, select an existing profile option, and provide one approved value | resolve_fsm_common_profile_option_export |
| ORA_MANAGE_KNOWLEDGE_FOR_SERVICE_REQUESTS_PROFILE_OPTIONS | Manage Knowledge for Service Requests with Redwood User Interface Profile Options | Profile option update lacks a completed export, an existing ProfileOptionName, or an approved ProfileOptionValue | Reject before preview | Complete a task export, select an existing profile option, and provide one approved value | resolve_fsm_service_requests_profile_option_export |
| ORA_CSO_CONTENT_TYPES_MGMT | Manage Knowledge Content Types Classic | Request is not routed to Manage Knowledge Content Types Redwood | Reject before package preparation | Route the request to the Redwood task skill |  |
