## Design Rules

| Task Code | Task Name | Applies When | Severity | Required Lookup | Blocking Condition | Recommendation | Fix Allowed? |
|---|---|---|---|---|---|---|---|
| ORA_CSO_LOCALES_MGMT | Manage Knowledge Locales | Operation disables a locale | Error | resolve_fsm_locale_state | The selected locale is the current default Knowledge locale | Select another active default locale before disabling the current default locale | Yes |
| ORA_CSO_LOCALES_MGMT | Manage Knowledge Locales | Operation deactivates an active locale | Warning | resolve_fsm_locale_state | The warning has not been shown and separately approved before artifact preparation | Show: Warning! Deactivation of a locale will cause all objects including existing KB content in this locale to become inaccessible but they will not be deleted. Obtain explicit approval before creating, modifying, or validating any mutation package, preview ZIP, or import artifact. | Yes |
| ORA_CSO_LOCALES_MGMT | Manage Knowledge Locales | Operation deactivates the default preferred Knowledge locale | Warning | resolve_fsm_locale_state | The business has not acknowledged that the default preferred setting will be reset to none | Confirm the warning impact before continuing | Yes |
| ORA_CSO_LOCALES_MGMT | Manage Knowledge Locales | Operation changes locale configuration through FSM | Error | resolve_fsm_package_contract | A completed FSM export for the current preview is not available | Complete the task export and use it as the mutation package reference | Yes |
| ORA_CSO_USER_GROUPS_MGMT | Manage Knowledge User Groups | An edit or delete request targets a predefined Knowledge user group | Error |  | The selected user group is predefined | Select a custom user group; predefined Knowledge user groups can't be edited or deleted | Yes |
| ORA_CSO_USER_GROUPS_MGMT | Manage Knowledge User Groups | Knowledge Management Business Unit Support is enabled | Error | resolve_active_business_unit | businessUnitIds is empty or does not identify an active BusinessUnitId | Resolve a supplied Business Unit name to one active identifier, then populate businessUnitIds with the returned BusinessUnitId | Yes |
| ORA_CSO_USER_GROUPS_MGMT | Manage Knowledge User Groups | A request attempts to delete a Knowledge user group | Error |  | The request uses an FSM deletion flow or a REST DELETE as a substitute | Deletion is unsupported for this use case; do not use a direct REST DELETE | No |
| ORA_CSO_USER_GROUPS_MGMT | Manage Knowledge User Groups | A review, create, or edit request is gated on role data-security policies or user access assignment | Error |  | Role data-security policies or user access assignment is treated as a prerequisite | Do not require role data-security policies or user access assignment for this flow | Yes |
| ORA_CSO_KNOWLEDGE_PANEL_PROFILE_MGMT | Manage Knowledge Panel Profile Options | An FSM profile-option value update is requested | Error | resolve_fsm_panel_profile_option_export | The completed export does not resolve one existing definition, supported level, and value-row contract | Complete the FSM export preflight before preparing the approved package | Yes |
| ORA_CSO_KNOWLEDGE_SEARCH_PROFILE_MGMT | Manage Knowledge Search Profile Options | An FSM profile-option value update is requested | Error | resolve_fsm_profile_option_export | The completed export does not resolve one existing definition, supported level, and value-row contract | Complete the FSM export preflight before preparing the approved package | Yes |
| ORA_CSO_MY_KNOWLEDGE_PROFILE_MGMT | Manage My Knowledge Profile Options | A profile option value update is requested | Error | resolve_fsm_my_knowledge_profile_option_export | The definition, current Site value, or Site-level enabled and updateable flags are not confirmed | Complete the FSM export preflight before showing the exact FSM import for approval | Yes |
| ORA_MANAGE_KNOWLEDGE_COMMON_PROFILE_OPTION | Manage Knowledge Common Profile Options | A profile option value update is requested | Error | resolve_fsm_common_profile_option_export | The definition, current Site value, or Site-level enabled and updateable flags are not confirmed | Complete the FSM export preflight before showing the exact FSM import for approval | Yes |
| ORA_CSO_MY_KNOWLEDGE_PROFILE_MGMT | Manage My Knowledge Profile Options | An FSM export contains no materialized profile rows | Warning | resolve_fsm_my_knowledge_profile_option_export | The export is treated as the only update route | Retain the export as baseline evidence and continue through the documented Apps Common profile-options preflight | Yes |
| ORA_MANAGE_KNOWLEDGE_COMMON_PROFILE_OPTION | Manage Knowledge Common Profile Options | An FSM export contains no materialized profile rows | Warning | resolve_fsm_common_profile_option_export | The export is treated as the only update route | Retain the export as baseline evidence and continue through the documented Apps Common profile-options preflight | Yes |
