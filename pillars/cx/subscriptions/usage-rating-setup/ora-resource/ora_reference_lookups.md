## Lookup Execution Rules

| Task Code | Task Name | Situation | What Happens |
|---|---|---|---|
| CUSTOM_MANAGE_BALANCE_CODES | Manage Balance Codes | A BalanceCode path value is missing or the item GET reports that the balance code is not found | Return actionable issues and stop the read-only lookup |
| CUSTOM_MANAGE_BALANCE_CODES | Manage Balance Codes | The collection GET returns an API failure | Stop and report the failure; do not retry automatically |
| CUSTOM_MANAGE_BALANCE_PROFILES | Manage Balance Profiles | A balance-profile row is returned and grouping criteria are requested | Query its groupCriteria child collection and include every returned row in the result |
| CUSTOM_MANAGE_USAGE_ENTITLEMENT | Manage Usage Entitlement | Usage entitlements are retrieved with or without an identity filter | Use the documented GET collection or alternate-key finder without a request body |
| CUSTOM_MANAGE_USAGE_ENTITLEMENT | Manage Usage Entitlement | Entitlement assignments are listed | Use the documented GET collection without a request body; page until hasMore is false and do not use expand with fields |
