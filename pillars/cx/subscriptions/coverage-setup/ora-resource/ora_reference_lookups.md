## Lookup Execution Rules

| Task Code | Task Name | Situation | What Happens |
|---|---|---|---|
| CUSTOM_MANAGE_STANDARD_COVERAGE | Manage Standard Coverage | An existing standard coverage needs to be checked | Use only the documented GET collection endpoint, q filter, and fields parameter; this lookup is read-only. |
| CUSTOM_MANAGE_STANDARD_COVERAGE | Manage Standard Coverage | Standard Coverages are listed | Use only the developer-provided GET collection endpoint filtered by StandardCoverageYn=Y; this lookup is read-only. |
| CUSTOM_MANAGE_STANDARD_COVERAGE | Manage Standard Coverage | Standard Coverage related details are requested | Resolve the matching coverage, then use its MatrixId only with the developer-provided exact pricing-matrix rule endpoint; all related lookups are read-only. |
| CUSTOM_MANAGE_AVAILABILITY | Manage Availability | A schedule or exception is retrieved | Use only the documented GET collection endpoint and PUID alternate-key finder; this lookup is read-only. |
| CUSTOM_MANAGE_DEFAULT_COVERAGE | Manage Default Coverage | Default Coverages are listed or evaluated | Use only the developer-provided GET collection endpoint; this lookup is read-only. |
