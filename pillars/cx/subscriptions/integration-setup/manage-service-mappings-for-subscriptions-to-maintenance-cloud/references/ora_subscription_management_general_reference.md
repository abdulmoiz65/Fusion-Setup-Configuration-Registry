# Subscription Management General Reference

## Use

Read this reference before resolving Service Mapping sources for Subscriptions to Maintenance Cloud when the request needs general Oracle Subscription Management business context, including subscription lifecycle, products, coverage products, covered levels, validation, activation, and approval context.

## Source

- [Using Subscription Management](https://docs.oracle.com/en/cloud/saas/subscription-management/fasum/using-subscription-management.pdf)

## Key Guidance

- Subscription Management supports subscriptions, subscription products, coverage products, covered levels, import and REST integration, pricing, billing, renewals, amendments, suspension, and termination.
- Coverage products support serviceable items for a specific period.
- Covered level context can include asset, product, party, customer account, party site, asset group, or product group depending on setup.
- A serialized asset is treated as an individual product in the coverage context.

## Boundaries

This guide is business context only. It does not confirm a current Service Mapping source object, alias, attribute type, access flag, publication status, runtime value, REST path, or update route. Confirm those details from the current environment export, supported read-only lookup, or approved implementation contract.
