# Subscription Management General Reference

## Use

Read this reference first when a customer request needs general Oracle Subscription Management business context, including subscription lifecycle, products, pricing, billing, Accounts Receivable interfacing, or subscriptions created from Order Management. Use the guide to understand the customer use case before looking up current release-specific documentation.

## Source

- [Using Subscription Management](https://docs.oracle.com/en/cloud/saas/subscription-management/fasum/using-subscription-management.pdf)

## Boundaries

This guide is general background, not the authoritative source for the current Fusion release, deployed configuration, Service Mapping source alias, view object, data type, access, publication state, or REST describe result. It never replaces the mandatory current `Algorithm_BO.xml` and `ARInterface` Service Mapping source XML preflight. Confirm technical details using the current applicable Oracle source, current export, deployed configuration, or approved describe result.
