# Manage Price Adjustments Input Validation

## Manage Price Adjustment Variables

For `CUSTOM_MANAGE_PRICE_ADJUSTMENT_VARIABLES`, format every Data Loader `StartDate` and `EndDate` value as `YYYY/MM/DD` (for example, `2026/01/01`). Do not submit ISO-hyphenated dates such as `2026-01-01`; Fusion rejects them during Data Loader import. Validate date-effective value rows before preview and again before upload.

For the current `CUSTOM_MANAGE_PRICE_ADJUSTMENT_VARIABLES` UCM template, use `VariableNumber` as the parent-link surrogate key on every `priceAdjustmentVariableValues` child row. For values-only loads against an existing parent, leave the parent sheet header-only; do not add parent reference rows or create, update, or delete the parent. Set child `RestAction` to `POST`. Refresh and validate against the live template before every approval preview.

When multiple new variables and their values are requested, use two Data Loader stages: a parent-only `POST` load containing all new variables, then—only after successful status and REST verification—a values-only load with a header-only parent sheet and all child `POST` rows. Do not combine the new parents and values in one workbook.
