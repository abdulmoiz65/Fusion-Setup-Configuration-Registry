# Manage Price Adjustments Design Enforcement

## Enforcement Order

| Task Code | Task Name | Sequence | Step | What Must Happen |
|---|---|---|---|---|
| CUSTOM_MANAGE_PRICE_ADJUSTMENTS | Manage Price Adjustments | 1 | Resolve category and category-step configuration | Confirm the exact category and its configured flags before preparation |
| CUSTOM_MANAGE_PRICE_ADJUSTMENTS | Manage Price Adjustments | 2 | Enforce category eligibility and ordering | Allow only source-documented category use and ordering |
| CUSTOM_MANAGE_PRICE_ADJUSTMENTS | Manage Price Adjustments | 3 | Confirm lookup and category creation plan | Obtain one business confirmation for the combined lookup-code and category values. For a new lookup code, require a header-only standardLookups parent worksheet and a populated lookupCodes child worksheet. Present supplied values, retrieved values, defaults, and process-reconciliation result before the Data Loader preview gates |
| CUSTOM_MANAGE_PRICE_ADJUSTMENTS | Manage Price Adjustments | 4 | Reconcile asynchronous Data Loader outcomes | Poll every 30 seconds. A Success, Warning, Error, or Failed status requires its resolver GET; only an exact created record permits the next stage or completion. An intermediate status continues polling |
| CUSTOM_MANAGE_PRICE_ADJUSTMENT_VARIABLES | Manage Price Adjustment Variables | 1 | Resolve the variable identity and current values | Read the variable collection before selecting create or update behavior |
| CUSTOM_MANAGE_PRICE_ADJUSTMENT_VARIABLES | Manage Price Adjustment Variables | 2 | Enforce advanced-pricing-term constraints | Keep variable use within the documented price-escalation design |
| CUSTOM_MANAGE_MILESTONE_TEMPLATES_FOR_BILLING_AND_REVENUE_RECOGNITION | Manage Milestone Templates for Billing and Revenue Recognition | 1 | Confirm milestone billing eligibility | Confirm the subscription product is of sales product type Subscription and uses a one-time charge; exclude coverage and warranty products. |
| CUSTOM_MANAGE_MILESTONE_TEMPLATES_FOR_BILLING_AND_REVENUE_RECOGNITION | Manage Milestone Templates for Billing and Revenue Recognition | 2 | Confirm milestone definitions | Confirm each milestone has a billing and revenue recognition percentage and that its completion date is used for the bill-line interface and revenue satisfaction event. |

## Design Rules

| Task Code | Task Name | Applies When | Severity | Required Lookup | Blocking Condition | Recommendation | Fix Allowed? |
|---|---|---|---|---|---|---|---|
| CUSTOM_MANAGE_PRICE_ADJUSTMENTS | Manage Price Adjustments | A category is proposed for a charge adjustment | Error | resolve_price_adjustment_category | ChargeLevelFlag or UserEnterableFlag is not enabled for the requested use | Select a category configured for charge-level, user-enterable price adjustments | Yes |
| CUSTOM_MANAGE_PRICE_ADJUSTMENTS | Manage Price Adjustments | An adjustment is added after activation | Error | resolve_price_adjustment_category | AllowAfterActivationFlag is not enabled | Select an eligible category or use a supported pre-activation path | Yes |
| CUSTOM_MANAGE_PRICE_ADJUSTMENTS | Manage Price Adjustments | An adjustment category is selected after an adjustment basis | Error | resolve_price_adjustment_category | AdjustmentStepSequenceNumber is not greater than the existing price element step sequence | Select a category with a later step sequence | Yes |
| CUSTOM_MANAGE_PRICE_ADJUSTMENTS | Manage Price Adjustments | A specific-dates adjustment is proposed | Error |  | Prospective accounting is enabled, the charge is one-time or usage, or coverage billing conditions prohibit date-effective charge adjustments | Use a supported effectivity or revise the charge and billing design | Yes |
| CUSTOM_MANAGE_PRICE_ADJUSTMENTS | Manage Price Adjustments | Adjustment sequence numbers are assigned within one category | Warning |  | Duplicate sequence numbers would leave application order nondeterministic | Assign unique adjustment sequence numbers | Yes |
| CUSTOM_MANAGE_PRICE_ADJUSTMENTS | Manage Price Adjustments | A new category is proposed | Error | resolve_price_adjustment_category_inventory | Category name, code, placement sequence, price element or adjustment basis, or display preference is absent or unconfirmed | Retrieve the inventory and ask the customer to confirm all mandatory values | Yes |
| CUSTOM_MANAGE_PRICE_ADJUSTMENTS | Manage Price Adjustments | A new category is proposed | Error | resolve_price_adjustment_categories_lookup | The matching ORA_OSS_PRICE_ADJ_CATEGORY lookup code is absent, inactive, outside its active date range, or does not match the approved code, meaning, and sequence. A Failed lookup-code Data Loader status alone is not a blocker when the exact active code is retrievable | Create through Data Loader standardLookups with a header-only parent worksheet and lookupCodes child data. Reconcile any Failed process with the exact lookup GET; if it matches, do not retry and proceed to the priceAdjustmentCategories Data Loader stage | Yes |
| CUSTOM_MANAGE_PRICE_ADJUSTMENTS | Manage Price Adjustments | A lookup-code Data Loader result is Warning, Error, or Failed | Error | resolve_price_adjustment_categories_lookup | The exact active lookup code is not retrievable and matched after the terminal status | GET the exact lookup code. If it matches, classify the terminal result as reconciled and continue; otherwise disclose the mismatch and stop | Yes |
| CUSTOM_MANAGE_PRICE_ADJUSTMENTS | Manage Price Adjustments | A category Data Loader result is Warning, Error, or Failed | Error | resolve_price_adjustment_category | The exact category is not retrievable and matched after the terminal status | GET the exact category. If it matches, classify the terminal result as reconciled and complete; otherwise disclose the mismatch and stop | Yes |
| CUSTOM_MANAGE_PRICE_ADJUSTMENTS | Manage Price Adjustments | A create or update request specifies REST POST or PATCH | Error |  | The requested mutation is not prepared as a Data Loader operation | Prepare the corresponding Data Loader source and use Data Loader for the mutation; direct REST POST and PATCH are prohibited | No |
| CUSTOM_MANAGE_PRICE_ADJUSTMENTS | Manage Price Adjustments | A category is proposed relative to another category or Price Element | Error | resolve_price_adjustment_category_inventory | The source sequence plus one is occupied, reference records are missing, or records already occur between the two references | Present all intervening records and ask the customer to select the exact placement | Yes |
| CUSTOM_MANAGE_PRICE_ADJUSTMENTS | Manage Price Adjustments | Defaults are applied or intelligently changed | Warning |  | The customer has not seen the applied values and their meaning before creation | Present the defaults and changes as a confirmation warning before preview | Yes |
| CUSTOM_MANAGE_PRICE_ADJUSTMENTS | Manage Price Adjustments | Charge adjustment sequencing or business rules are requested | Warning | resolve_price_adjustment_category_inventory | The requested application order is not expressed through category step sequence and adjustment sequence | Route the decision to Manage Price Adjustments; Oracle applies adjustments by configured category step sequence and then adjustment sequence regardless of entry order | Yes |
| CUSTOM_MANAGE_PRICE_ADJUSTMENTS | Manage Price Adjustments | Bill-line adjustment sequencing or business terms are requested | Warning | resolve_price_adjustment_category_inventory | The application order or justification is not expressed through the category and adjustment design | Route the decision to Manage Price Adjustments and document the business reason, such as billing correction, service credit, freight recovery, or goodwill concession | Yes |
| CUSTOM_MANAGE_PRICE_ADJUSTMENT_VARIABLES | Manage Price Adjustment Variables | A delete operation is requested | Error | resolve_price_adjustment_variable | Subscription price adjustment variables cannot be deleted after creation | Retire or update the variable only through a documented approved process | No |
| CUSTOM_MANAGE_PRICE_ADJUSTMENT_VARIABLES | Manage Price Adjustment Variables | An expression-based escalation references a variable | Error | resolve_price_adjustment_variable | The variable name is not resolvable, or the expression does not use documented brace syntax | Use an existing variable and reference it as {VariableName} | Yes |
| CUSTOM_MANAGE_PRICE_ADJUSTMENT_VARIABLES | Manage Price Adjustment Variables | Advanced Pricing Terms are enabled for a product | Error |  | Basic Pricing Term is also enabled, Bill TCV is supplied, Bill Immediately is selected, or an early termination fee is configured | Use only Advanced Pricing Terms, and remove incompatible product settings | Yes |
| CUSTOM_MANAGE_MILESTONE_TEMPLATES_FOR_BILLING_AND_REVENUE_RECOGNITION | Manage Milestone Templates for Billing and Revenue Recognition | A milestone template is prepared for a product | Error |  | The product is not sales product type Subscription, does not use a one-time charge, or is a coverage or warranty product | Use milestone billing only for eligible subscription products with a one-time charge. | Yes |
| CUSTOM_MANAGE_MILESTONE_TEMPLATES_FOR_BILLING_AND_REVENUE_RECOGNITION | Manage Milestone Templates for Billing and Revenue Recognition | Milestone template definitions are prepared | Error |  | A milestone name or source is not resolved by the prerequisite dependency checks, or a milestone has no stated billing and revenue recognition percentage | Resolve both prerequisites and provide the percentage for every milestone before preparing the Data Loader archive. | Yes |
