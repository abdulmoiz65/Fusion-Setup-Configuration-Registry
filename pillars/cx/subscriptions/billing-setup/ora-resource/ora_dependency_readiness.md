# Manage Price Adjustments Dependency Readiness

## Required Dependency Order

| Task Code | Task Name | Sequence | Dependency | What Must Happen |
|---|---|---|---|---|
| CUSTOM_MANAGE_PRICE_ADJUSTMENTS | Manage Price Adjustments | 1 | Current-state discovery | Retrieve all price adjustment categories and Price Elements with all returned attributes and step-sequence information; retrieve the ORA_OSS_PRICE_ADJ_CATEGORY lookup and lookup codes. |
| CUSTOM_MANAGE_PRICE_ADJUSTMENTS | Manage Price Adjustments | 2 | Lookup-code readiness | Confirm the proposed code and meaning are absent, or obtain customer confirmation to reuse an existing matching lookup code and meaning. |
| CUSTOM_MANAGE_PRICE_ADJUSTMENTS | Manage Price Adjustments | 3 | Lookup-code creation | Create the lookup code through the Data Loader standardLookups business object. Keep the standardLookups parent worksheet header-only, put the new-code data only in its lookupCodes child worksheet, and set the approved sequence, ActiveFlag Y, and StartDateActive 1991-01-01. |
| CUSTOM_MANAGE_PRICE_ADJUSTMENTS | Manage Price Adjustments | 4 | Lookup-code monitoring and verification | Poll the lookup Data Loader status every 30 seconds for at most 20 minutes. On Success, Warning, Error, or Failed, GET the exact lookup code. Continue when one active code matches the approved code, meaning, sequence, and dates; record a Warning, Error, or Failed process as reconciled and do not retry it. For an intermediate status, continue polling and do not start the category stage. |
| CUSTOM_MANAGE_PRICE_ADJUSTMENTS | Manage Price Adjustments | 5 | Category creation | Only after the verified lookup code is available, create the price adjustment category through the approved priceAdjustmentCategories Data Loader operation. |
| CUSTOM_MANAGE_PRICE_ADJUSTMENTS | Manage Price Adjustments | 6 | Category monitoring and retrieval | Poll the category Data Loader status every 30 seconds for at most 20 minutes. On Success, Warning, Error, or Failed, GET the exact category by its system-generated AdjustmentStepId. If it matches the approved category values, show every returned category attribute to the implementer; otherwise return the status and retrieval mismatch. For an intermediate status, continue polling and do not report creation as complete. |
| CUSTOM_MANAGE_MILESTONE_TEMPLATES_FOR_BILLING_AND_REVENUE_RECOGNITION | Manage Milestone Templates for Billing and Revenue Recognition | 1 | Milestone-name lookup readiness | Resolve the configured milestone-name lookup type and intended active lookup code or meaning before preparing a milestone template. |
| CUSTOM_MANAGE_MILESTONE_TEMPLATES_FOR_BILLING_AND_REVENUE_RECOGNITION | Manage Milestone Templates for Billing and Revenue Recognition | 2 | Milestone-source lookup readiness | Resolve the configured milestone-source lookup type and intended active lookup code or meaning before preparing a milestone template. |
| CUSTOM_MANAGE_MILESTONE_TEMPLATES_FOR_BILLING_AND_REVENUE_RECOGNITION | Manage Milestone Templates for Billing and Revenue Recognition | 3 | Milestone template preparation | Prepare milestoneTemplates data only after both lookup prerequisites are resolved and the documented product eligibility is confirmed. |
