## Lookup Execution Rules

| Task Code | Task Name | Situation | What Happens |
|---|---|---|---|
| CUSTOM_MANAGE_PRICE_ADJUSTMENTS | Manage Price Adjustments | The category lookup or its category-step row cannot be read | Stop before preview or any REST data-loader operation and return the lookup issue |
| CUSTOM_MANAGE_PRICE_ADJUSTMENTS | Manage Price Adjustments | A category request omits a sequence, or placement or sequence is absent or collides | Return two complete, sequence-ordered tables before asking for placement: Current Price Adjustment Categories with Code, Name, Seq., Bill line attribute, and Display; then Current Price Elements with Code, Name, Seq., Bill line attribute, and Display. Show all returned business values for those columns, including a blank when a value is absent; do not expose opaque IDs, links, or audit/session identifiers. Ask the implementer to choose a position relative to named records or supply an exact numeric sequence |
| CUSTOM_MANAGE_PRICE_ADJUSTMENTS | Manage Price Adjustments | A requested placement is between two existing Price Adjustment Categories, between a Price Adjustment Category and a Price Element, or between two Price Elements | Resolve both sequence numbers. If no configuration record exists between them and the lower sequence plus one is unoccupied, propose that sequence to the user and ask whether to proceed with that sequence. If any record exists between the references, ask the user to provide an exact numeric sequence; do not infer one |
| CUSTOM_MANAGE_PRICE_ADJUSTMENTS | Manage Price Adjustments | A lookup code or meaning exists but no corresponding category exists | Tell the customer that the lookup is available and ask whether to reuse its exact code and meaning or provide different values |
| CUSTOM_MANAGE_PRICE_ADJUSTMENTS | Manage Price Adjustments | The lookup-code Data Loader process reports Warning, Error, or Failed | Run resolve_price_adjustment_categories_lookup. If exactly one active record matches the approved code, meaning, sequence, and active-date data, record the process outcome as reconciled, do not create the lookup code again, and proceed with the approved priceAdjustmentCategories Data Loader stage; otherwise stop and disclose the mismatch or missing code |
| CUSTOM_MANAGE_PRICE_ADJUSTMENTS | Manage Price Adjustments | A lookup-code or category Data Loader process is intermediate | Continue the 30-second status polling interval. Do not start a dependent stage or report creation as complete until the status is terminal and the exact record is reconciled through its resolver |
| CUSTOM_MANAGE_PRICE_ADJUSTMENTS | Manage Price Adjustments | A price-adjustment category create or update, including a direct REST POST or PATCH request, is requested | Use the approved Data Loader workflow and its exact preview and approval controls. Do not invoke a direct REST mutation |
| CUSTOM_MANAGE_PRICE_ADJUSTMENT_VARIABLES | Manage Price Adjustment Variables | A variable or variable-value write is requested | This resource supplies read-only lookup and validation rules only; use the approved Data Loader workflow and its exact preview and approval controls for any write |
| CUSTOM_MANAGE_MILESTONE_TEMPLATES_FOR_BILLING_AND_REVENUE_RECOGNITION | Manage Milestone Templates for Billing and Revenue Recognition | The supplied milestone name or source lookup type, code, or meaning is missing or ambiguous | Stop before Data Loader artifact preparation. Request the configured lookup type and one exact lookup code or meaning. |
| CUSTOM_MANAGE_MILESTONE_TEMPLATES_FOR_BILLING_AND_REVENUE_RECOGNITION | Manage Milestone Templates for Billing and Revenue Recognition | A user requests milestone templates defined in the environment | Use list_milestone_templates as a read-only collection request. Return the accessible template records and expanded billing and revenue milestones; do not prepare a Data Loader artifact. |
| CUSTOM_MANAGE_MILESTONE_TEMPLATES_FOR_BILLING_AND_REVENUE_RECOGNITION | Manage Milestone Templates for Billing and Revenue Recognition | A user requests the display meaning of milestone Name, Source, or Event Type | Use describe_milestone_template_lookups as a read-only describe request. Resolve only the choice-list meanings returned by the describe contract. |
