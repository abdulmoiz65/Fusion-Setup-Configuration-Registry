# Manage Opportunity Profile Options Reference Lookups

Read configured state through
[Apps Common Profile Options](../../../../../../core/fusion-api/apps-common/profile-options/SKILL.md)
and its [profile-options contract](../../../../../../core/fusion-api/apps-common/profile-options/references/profile-options.md).
Reuse core authentication, transport, value-resource keys, and payloads. For
this Opportunity task, the capability mapping below supplies the core level
preflight; parent flag aliases are not additional required fields. Apply this
task's Read and Export Approval Scope to the declared GETs and export steps.
Successful export membership or classified export failure selects mutation
readiness after exact live lookup; export values are never current-value
authority. These lookups are read-only.

## Lookup Execution Rules

| Situation | What Happens |
|---|---|
| Candidate discovery | Run resolve_opportunity_option_candidates before code-keyed reads; preserve its work list and source/task provenance separately from current configured state |
| Inventory requests all options | Export plus seed reads establish only task_export_and_documented_candidates coverage unless verified complete applicable identity evidence is supplied. Report the boundary and use RETURN_PARTIAL_INVENTORY when all-options coverage is unproved, even if all known candidates were read |
| Inventory requests explicit candidates | Only explicit user scope selects explicit_candidates; complete every selected identity/configured-child read and preserve per-code not_found where applicable. Do not reinterpret all-options intent as this scope |
| Display-name-only input | Resolve one exact code from validated local identity mappings before the core GET; otherwise request the exact code/source evidence. No invented display-name finder or generic profileOptions collection GET |
| Exact code omitted from export or Review without export | Keep direct live reads; establish ownership from documented exact code or an exact live advertised display name bound to current Oracle Opportunity evidence. Do not require a new export |
| Exact-code Review | Read definition, profileOptionLevels, and complete Site/User/Product GETs directly; skip export, export approval, and mutation privilege; record not_requested_for_review |
| Inventory or Review | Read exact definition and paginate all Site/User/Product children; report explicit not configured and timestamps; keep delivered, effective, exported, and configured values separate |
| Level capability is needed | Confirm profileOptionLevels and its fields from profileOptions/describe; paginate the exact option child and match one LevelName SITE/PRODUCT/USER row. Use EnabledFlag and UpdateableFlag (exact spelling); both must be Y for mutation. Do not require parent aliases such as SiteLevelEnabled or SiteLevelUpdatable when the selected schema omits them; their absence is not a blocker when the child resolves. If the schema also exposes parent aliases, require their values to agree with the child row. Treat missing/duplicate/invalid/conflicting capability evidence as unknown and block mutation without assuming Y or inferring capability from a current value or generic PATCH support |
| Live option is absent from successful complete export | Allow Review and disclose omission; for Set/BulkSet select declared REST fallback after exact live identity resolution |
| Exact-task export fails or times out | Preserve failure reason and unknown membership, continue exact Apps Common reads, and allow PATCH only for an existing exact live child; no ZIP or omission proof required |
| Export contains the option but omits the selected value | Block FSM update; do not select REST or create a synthetic package row |
| Exact code/display name or request/live/export identity conflicts | Stop without substituting another code, level, or row |
| REST Site target | Use literal SITE key; one row selects PATCH; explicit absence selects POST only for confirmed successful-export omission and blocks update after export failure |
| REST Product target | Require exact application short name as the existing legacy item key. Create LevelValue applies only after the current Oracle creation-support gate passes; never use the display label |
| REST User target | Use exact UserName item key; resolve profileUsers to one UserGuid for create LevelValue; never use a display name or Site key |
| Stored value is lookup-backed | Extract only the named lookup type from live SqlValidation, resolve one exact active stored code or meaning to its code, and show both; never execute SQL |
| Stored value requires another object/ID resolver | Load the supported owning core contract and require exact active dependency evidence; block if no declared safe resolver can validate the current value contract |
| FSM identity/value closure resolves | Preserve matching live and export state, definition, level, key, capabilities, SqlValidation, and dependency rows for package validation |
| REST state refresh on approved resume | Re-read definition/capability/scope/current row/dependency; reuse immutable same-target omission or failure receipt; after failure require the approved child still exists; changed export outcome/membership/reason invalidates route and approval |
| Lookup or mutation evidence is ambiguous or incomplete | Stop and report exact classified failure; do not infer state from defaults, effective profileValues, export-only rows, or another scope |
