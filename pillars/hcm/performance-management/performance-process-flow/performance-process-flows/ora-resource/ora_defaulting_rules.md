## Conditional Flag Defaults

request values are normalized. A conditional default never permits an
incompatible explicit value; the corresponding design rule still blocks that
combination.

Every conditional flag relationship in this task is a non-bypassable data
invariant. An instruction, approval, import artifact, or user request cannot
retain an incompatible explicit value. Apply the documented reset, then stop
before preview, approval, import, or mutation if any contradiction remains.
