# Absence Plans Reference Lookups

All calls in this file are read-only. They validate source values and current metadata only; they do not authorize or perform a plan mutation.

Source guidance: [Absence Plan Setup - REST API Details](https://confluence.oraclecorp.com/confluence/display/FUSIONANC/Absence+Plan+Setup+-+REST+API+Details), [Absence Plans Minimal + LOVs](https://confluence.oraclecorp.com/confluence/pages/viewpage.action?pageId=21792518140), and the developer-provided sanitized Fusion UI HAR captured on 2026-09-01. The HAR establishes request and response mappings only; its host, runtime-view token, locale, and tenant identifiers are never portable defaults. Additional formula and DonationType attachment-point evidence: [Absence Plans VB UI Analysis, version 2](https://confluence.oraclecorp.com/confluence/pages/viewpage.action?pageId=21810192649), specifically its field/provider inventory, child layouts, and fastFormulasLOV fetch chains.

## LOV Resolution Policy

Resolve every Absence Plans LOV through the current authenticated target's documented REST LOV endpoint or a current REST `absencePlans/describe` binding. Read every page and require one exact active/effective match before writing its returned code or identifier to a Data Loader source. Never open a browser UI, replay a runtime URL or token, reuse a captured client value, or use a UI response as lookup evidence.

## Plan-Type Intent Matrix

For a policy description, this user-provided matrix may propose a plan type
only. An exact user selection of one matrix Plan Type Name is an explicit
selection that maps to its listed code. Neither a matrix proposal nor a
current describe or capture value authorizes AbsencePlanTypeCode without the
user's explicit selection or confirmation.

| Policy Description | Proposed Plan Type | Proposed AbsencePlanTypeCode |
|---|---|---|
| Vacation | Accrual | A |
| Maternity entitlement | Qualification | Q |
| Unpaid tracking | No Entitlement | N |
| Statutory shared leave | Agreement | ORA_ANC_AGREE |
| Earned overtime time | Compensatory | ORA_ANC_COMP |
| Received donated time | Donation | ORA_ANC_DON |

For an unpaid-tracking request, the No Entitlement matrix entry is a candidate
only. It can be proposed only when the user states that the plan tracks time
without an entitlement or qualification assessment and without an accrual
balance. If that policy direction is absent, the skill must ask the user to
choose Qualification or No Entitlement; it must not use the matrix row as an
automatic selection. Do not recommend a Qualification combination solely
because the request is unpaid; consider it only when policy expressly requires
an entitlement or qualification assessment.
