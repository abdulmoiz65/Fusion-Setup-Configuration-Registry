## Lookup Execution Rules

| Situation | What Happens |
|---|---|
| A status lookup is needed | Use only /fscmRestApi/resources/11.13.18.05/commonLookupsLOV with LookupTypeFinder and LookupType ANC_SETUP_OBJ_STATUS |
| A legislation lookup is needed | Use only /fscmRestApi/resources/11.13.18.05/territoriesLOV and map the selected TerritoryShortName to TerritoryCode |
| An associated absence type is resolved | Use the `absenceTypesLovV2` query with only `LegislationCode='<LegislationCode>'` in Fusion's server-side `q` filter. Do not add `Name`, `AbsenceTypeId`, `AbsenceTypeId NOT IN ()`, or `Name IS NOT NULL` predicates: this LOV can omit a valid row when they are added. Read every returned page, then exact-match the supplied Name or AbsenceTypeId locally; when both are supplied, require that they identify the same row. |
| A lookup returns an authentication or authorization failure | Stop and classify the failure; a rejected cached token may be refreshed once for a read operation only |
| A lookup returns zero or multiple acceptable rows | Stop and request a more precise value; never select an arbitrary row |
| A query source value contains a quote or reserved URL character | Escape Fusion string literals and URL-encode the complete query parameter before the read-only request |
| A lookup response lacks documented fields | Stop as a query-contract failure; do not substitute another endpoint or infer mappings |
| DFF metadata differs from captured documentation | Use the current target-environment describe response as authoritative and reject fields absent from it |
| A date-effective DAT is prepared | Refresh the registered UCM template first. Use REST describe only for DFF contexts and segments, never as authority for DAT columns or effectiveOf support. |
| A DDF or DFF correction or update is requested | Run resolve_absence_category_flex_dataloader_contract before source generation. Accept the registered category surrogate plus effective-dated child evidence; do not require a new surrogate column or copy a REST key string into the numeric category ID. Empty PostUrl or PatchUrl registration values are not a prohibition and do not supply an override URL. |
| A lookup succeeds | Record only the resolver name, selected business identity, and mapped values needed downstream; never persist credentials or bearer tokens |
