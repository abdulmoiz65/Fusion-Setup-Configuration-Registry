# Leave Agreements Dependency Readiness

Redwood current-version View, Create, Edit, and Delete are the supported business scope. For Edit or Delete, retrieve the exact current parent, full before state, and affected children before evaluating changed-field dependencies. Unchanged stored selections do not become new create inputs. Dated Update, Correction, End date, Delete changes, and caller-selected ZAP are unavailable business operations; internal date-free ZAP is the loader control for current whole-object Delete. Present supported choices without treating the whole task as blocked.

## Required Dependency Order

| Sequence | Dependency | What Must Happen |
|---|---|---|
| 1 | Supported operation and current identity | Distinguish View/Create/Edit/Delete. For existing-object requests resolve the exact current parent and requested child, read the full before state and affected children, and retain their identity and stored Start Date |
| 2 | Create Start Date or retained parent context | Normalize the new parent business Start Date for Create. Edit requires verified stored parent Start Date for internal RangeStartDate; whole-object Delete derives date-free RangeMode=ZAP. Neither accepts a new operation date; a supported child Add uses the verified stored parent Start Date |
| 3 | Agreement pattern and legislation | Resolve selected create values or UI-permitted changed values; retain unchanged stored values. Scope dependent selections to this context before proposing create-only coded defaults |
| 4 | Legislation- and date-scoped selections | Resolve supplied or affected Legislative Grouping and Certifications in the selected legislation and parent Start Date context; invalidate dependent evidence only when its applicable context changes |
| 5 | Target absence plans | On Create or added/changed entitlement rows, preserve valid exact identity or resolve the supplied exact Target Plan through its owning resolver. Do not demand new plan IDs for a plain parent Edit |
| 6 | Common codes and optional header selections | Resolve supplied or changed status, validation formula, partner rule, reasons, Event Type and eligibility rule. Management is the observed read-only value; coded default candidates apply only to Create |
| 7 | Eligibility dependency | For Create or an affected eligibility choice, resolve only the selected Formula or Profile dependency, using retained before state where unchanged; reject simultaneous or stale values |
| 8 | Conversion source and plan relationships | For Create or affected source/entitlement changes, resolve Source Absence Type within the existing declared scope and Source Plan through its returned plans link. Preserve valid stored mappings on plain parent Edit |
| 9 | Entitlement payment values | Resolve a supplied or changed Payment Percentage Display Formula per affected child, then Override Allowed only when that row has a valid formula; retained unchanged values remain part of the before state |
| 10 | Complete configuration and applicable impact | Create requires valid pattern-specific plan mappings. Edit reviews the full resulting configuration and affected children without requiring replacement rows. Whole-agreement Delete requires the exact parent and complete known child inventory. Disclose unknown downstream references; Fusion enforces deletion restrictions at approved load. A known protection constraint still blocks preparation |
| 11 | Registered Data Loader contract | Refresh BusinessObject absenceLeaveAgreementTemplates metadata and current template; verify selected parent/child action, identity keys and field support before source preparation |
| 12 | Operation-specific adapter controls | Use native Create RangeStartDate with physical EffectiveStartDate blank by default; Edit derives RangeStartDate from verified stored Start Date; whole-object Delete uses date-free RangeMode=ZAP. Neither changes stored dates |

## Dependency Classification

| Result Category | When Used | Can Run Lookup/Create? |
|---|---|---|
| Satisfied | Applicable exact identities, full existing before state, affected dependencies and current selected-action metadata are present | No further dependency action; do not manufacture new child dependencies |
| Lookup | A documented code, type, or existing template must resolve | Read-only lookup only |
| Verify | The current registered Data Loader contract must be refreshed | Read-only core.data-loader metadata only |
| Blocked | A supported operation lacks an applicable exact identity, before state, dependency, known protection review, or adapter contract | Stop the affected execution, preserve its draft, and name the missing applicable evidence; do not invent a dependency-validation API for whole-agreement Delete |
| Unsupported | A dated Update, Correction, End date, Delete changes, or caller-selected ZAP operation is requested | No mutation; explain its unavailability and present applicable View/Create/Edit/Delete choices. Internal date-free ZAP remains the loader mapping for current whole-object Delete |
