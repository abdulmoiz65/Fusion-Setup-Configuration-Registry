# Input Validation

## Required Groups

| Requirement Group | Accepted Fields | If Missing | How to Resolve | Applies When | Resolver |
|---|---|---|---|---|---|
| Source format classification | A ZIP containing a member whose basename is exactly ASM_SETUP_CSV_METADATA.xml, or a native HDL source without that marker | Stop | Classify the source before applying any SalaryBasis HDL business-object, template, field, or child-row validation. Route an FSM-marked ZIP through the Data Loader FSM workflow unchanged. | Every import or create request that supplies a source file |  |
| Registered Salary Basis business object | BusinessObject: SalaryBasis | Stop | Resolve the exact registered business object; do not substitute a similarly named object | Every request | resolve_salary_basis_business_object |
| Current Salary Basis field contract | One or more supplied fields that are present in the current SalaryBasis template and attribute metadata | Stop | Read the current SalaryBasis schema and submit only fields whose name and value conform to it | A create, update, import, or validation request contains configuration values | read_salary_basis_schema |
| Legislative Data Group | One exact effective Legislative Data Group matching the supplied name or ID, plus a current SalaryBasis schema field or child that accepts its resolved identity shape | Stop | Resolve the supplied LDG through legislativeDataGroupsLOV and use only the current SalaryBasis schema-declared field or child shape | A Legislative Data Group is supplied for a create, update, import, or preview request | resolve_salary_basis_ldg |
| Effective Start Date | A nonblank effective start date accepted by the current SalaryBasis parent-row schema | Stop | Supply the effective date in the current template's accepted format before resolving time-effective references | Every create or new import row | read_salary_basis_schema |
| Salary Basis code | A supplied nonblank Code that satisfies the current SalaryBasis schema, or a code derived from a supplied SalaryBasisName by uppercasing letters and replacing spaces between words with underscores | Stop | Preserve a supplied Code. When omitted, derive it from the supplied SalaryBasisName through the task-local code resolver, then validate the result against the current schema and duplicate check. | A create, update, import, or preview request | derive_salary_basis_code |
| Salary Basis status | An enabled ACTIVE_INACTIVE code A or I, or exact enabled meaning Active or Inactive; when omitted, the default is Active | Stop | Resolve a supplied value against ACTIVE_INACTIVE, or resolve the Active default, and use its LookupCode | Every create, update, import, or validation request | resolve_salary_basis_status |
| Salary Basis Type | Enabled ORA_CMP_SAL_BASIS_DET_METHOD code U, C, ORA_SIMPLE_COMPONENTS, or R; or its exact enabled meaning | Stop | Resolve the supplied value against ORA_CMP_SAL_BASIS_DET_METHOD and use its LookupCode | Every create or new import row | resolve_salary_basis_type |
| Frequency | Enabled CMP_SALARY_BASIS code or exact enabled meaning | Stop | Resolve the supplied value against CMP_SALARY_BASIS and use its LookupCode | Every create or new import row | resolve_salary_basis_frequency |
| Annualization Factor | A user-supplied value that satisfies the current SalaryBasis schema, or an exact default mapped from the resolved Frequency | Stop | Preserve a supplied value. When omitted, apply only the `ora_defaulting_rules.md` mapping; for PERIOD or an unmapped code, require the user to provide a value. | A Frequency is supplied | resolve_salary_basis_frequency |
| Input Value Name and ID | A user-supplied value that satisfies the current SalaryBasis field and dependency contract, or the default Amount, plus one exact Amount child InputValueId | Stop | Preserve and validate a supplied value. When omitted, use Amount. Resolve InputValueId only from one exact Name Amount child of the resolved ElementTypeId. | The referenced payroll-enabled Salary Basis flow is in scope | resolve_salary_basis_input_value_id |
| Salary basis element details | One effective payrollElementDefinitionsLOV record matching ElementName and LegislativeDataGroupName | Stop | Correct the existing element through the Elements task, then rerun the read-only validation. Category, primary classification, processing type, proration, retro groups, calculation rule, and automatic eligibility are outside this resolver's contract. | The referenced payroll-enabled Salary Basis flow is in scope | resolve_salary_basis_element |
| Grade Rate association | One exact active effective GradeRateName, plus a current SalaryBasis schema field or child association that accepts the resolved value | Stop | Resolve the supplied Grade Rate through the Grade Rates read contract, then use only the current SalaryBasis schema-declared field or child shape | A Grade Rate is supplied | resolve_salary_basis_grade_rate |
| Salary Basis uniqueness | No existing Salary Basis with the same name and LDG, and no existing Salary Basis with the same code and LDG | Stop | Correct the name or code before source preparation | Every create request | check_salary_basis_duplicates |
| Parent amount, rounding, and range policy | SalaryAnnualizationFactor when required; AmountDecimalPrecision when supplied; enabled rounding and range-validation values when supplied | Stop | Validate the supplied value, range, and lookup code through the current SalaryBasis schema and its declared lookup contract | A parent SalaryBasis row supplies annualization, decimal precision, rounding, or range controls | read_salary_basis_schema |
| Incremental components | One or more distinct SalaryComponentCode child values when type resolves to C and ComponentUsage resolves to selected components | Stop | Validate the collection and each child identity only through the current SalaryBasis child metadata | SalaryBasisType resolves to C and ComponentUsage selects components | read_salary_basis_schema |
| Simple components | One or more SimpleComponentCode child values; each child has unique DisplaySequence and ProcessingSequence, and the type-required component fields | Stop | Validate the collection and component-type-specific fields only through the current SalaryBasis child metadata | SalaryBasisType resolves to ORA_SIMPLE_COMPONENTS | read_salary_basis_schema |
| Calculated-component attributes | One or more attribute children with their supported parent, sequence, impact, and factor fields | Stop | Validate the collection and component-type-specific fields only through the current SalaryBasis child metadata | A simple component resolves to ORA_CALCULATED_AMOUNT | read_salary_basis_schema |
| Rate components | One or more distinct rate-definition children, with unique display sequence and exactly one overall rate | Stop | Validate the collection and each child identity only through the current SalaryBasis child metadata | SalaryBasisType resolves to R | read_salary_basis_schema |
| Rate definition details | Category: Element; Storage Type: Amount; resolved salary basis element; Reporting Required: selected; Calculate Live Rates: selected; Returned Rate Details: unchanged; Contributor Type: Input Value | Stop | Use the Rate Definition task to create the documented rate definition | SalaryBasisType resolves to R, Salary amount is determined by rates | resolve_salary_basis_rate_definition |
| Range differential association | One exact Differential Profile Name resolved for the selected LDG, plus a Grade Rate association | Stop | Resolve the range differential through its describe-confirmed custom action and validate the selected Grade Rate through its own resolver | A parent SalaryBasis row supplies a range differential | resolve_salary_range_differential_code |

## Dependency-Aware Validation

| Applies When | Result | Next Action | Resolver |
|---|---|---|---|
| The supplied ZIP contains ASM_SETUP_CSV_METADATA.xml | Continue | Treat the source as FSM, preserve the archive unchanged, and continue only through the Data Loader FSM preview and approval workflow. Do not require a SalaryBasis HDL business-object match, HDL template, or HDL child-row validation. |  |
| The supplied source is native HDL and has no FSM marker | Continue | Continue with the SalaryBasis HDL registered-business-object and schema validation path. |  |
| The current schema has not been read | Blocked | Stop before preview or import preparation | read_salary_basis_schema |
| A supplied field is absent from the current schema or its value violates the current type, length, or key/reference contract | Blocked | Correct the supplied field or value, then revalidate | read_salary_basis_schema |
| Every supplied field is validated by the current schema | Continue | Evaluate the current schema's reference-object and lookup dependencies | read_salary_basis_schema |
| A supplied Legislative Data Group does not resolve to exactly one effective legislativeDataGroupsLOV record, or the current SalaryBasis schema has no supported association field or child | Blocked | Correct the LDG or remove the unsupported association; do not infer a loader attribute, ID, or row shape | resolve_salary_basis_ldg |
| Effective Start Date is missing or invalid for a create or new import row | Blocked | Supply a current-schema-valid date before resolving effective references | read_salary_basis_schema |
| Code is omitted and SalaryBasisName is missing or blank | Blocked | Provide SalaryBasisName so Code can be derived, or provide an explicit Code | derive_salary_basis_code |
| A supplied status is not an enabled ACTIVE_INACTIVE code or exact meaning | Blocked | Provide A or I, or the exact enabled meaning Active or Inactive | resolve_salary_basis_status |
| Status is omitted | Continue | Resolve the default Active value through ACTIVE_INACTIVE and use LookupCode A | resolve_salary_basis_status |
| A supplied Salary Basis Type is not an enabled ORA_CMP_SAL_BASIS_DET_METHOD code or exact meaning | Blocked | Provide U, C, ORA_SIMPLE_COMPONENTS, or R, or its exact enabled meaning | resolve_salary_basis_type |
| A supplied Frequency is not an enabled CMP_SALARY_BASIS code or exact meaning | Blocked | Provide an enabled CMP_SALARY_BASIS code or its exact enabled meaning | resolve_salary_basis_frequency |
| Annualization Factor is omitted and resolved Frequency is PERIOD or has no documented default mapping | Blocked | Provide Annualization Factor | resolve_salary_basis_frequency |
| The resolved element does not return exactly one payrollElementInputValues child whose Name is Amount | Blocked | Correct the element or input value through the owning Elements task, then revalidate | resolve_salary_basis_input_value_id |
| The referenced payroll-enabled flow is in scope and payrollElementDefinitionsLOV does not return exactly one effective record with the supplied element name and LDG | Blocked | Correct the element in the Elements task before continuing, then rerun the read-only validation | resolve_salary_basis_element |
| A supplied Grade Rate does not resolve to exactly one active effective GradeRateName, or the current SalaryBasis schema has no supported association field or child | Blocked | Correct the Grade Rate or remove the association; do not infer a loader attribute or row shape | resolve_salary_basis_grade_rate |
| A range differential is supplied without a current-schema-valid Grade Rate and selected LDG, or does not resolve exactly through the declared custom action | Blocked | Supply the required Grade Rate and LDG, then correct the differential profile name | resolve_salary_range_differential_code |
| Parent amount, rounding, or range values are unsupported by current SalaryBasis metadata, violate their declared shape, or use a disabled lookup value | Blocked | Correct or remove the unsupported value; do not infer a field, lookup type, or loader shape from the UI | read_salary_basis_schema |
| An incremental, simple, calculated-attribute, or rate-component child is unsupported by current metadata, duplicated where its collection requires uniqueness, or violates its type-specific prerequisites | Blocked | Correct the child collection and revalidate it against current child metadata; do not flatten it into the parent row or infer a child key | read_salary_basis_schema |
| SalaryBasisType resolves to R and the rate definition does not meet the documented setup | Blocked | Create or correct the rate definition in the Rate Definition task before continuing | resolve_salary_basis_rate_definition |

## Field Validation

| Check | What Happens | Applies When | Resolver |
|---|---|---|---|
| Exact field identity | Accept only fields returned by the current SalaryBasis template and attribute metadata | Every supplied Salary Basis value | read_salary_basis_schema |
| Field shape | Validate supplied values against current data type, data length, number precision, and applicable key or reference metadata | Every supplied Salary Basis value | read_salary_basis_schema |
| Dependency source | Do not treat a referenced object or lookup as satisfied until its requirement is present in the current SalaryBasis schema | A supplied field carries a reference-object or lookup contract | read_salary_basis_schema |
| Legislative Data Group identity | Resolve one exact effective Legislative Data Group, then require the current SalaryBasis schema to declare the target field or child and its accepted identity shape | A Legislative Data Group is supplied | resolve_salary_basis_ldg |
| Effective date | Require an explicit, current-schema-valid Effective Start Date before a create or new import; use it when checking time-effective references | Every create or new import row | read_salary_basis_schema |
| Salary Basis code derivation | When Code is omitted, derive it from SalaryBasisName by uppercasing letters and replacing spaces between words with underscores; then validate the resulting Code against the current schema and duplicate check | A create, update, import, or preview request | derive_salary_basis_code |
| Status defaulting and lookup validation | When status is omitted, resolve Active from enabled ACTIVE_INACTIVE values and use LookupCode A. When status is supplied, resolve only that supplied value from enabled ACTIVE_INACTIVE values. | Every create, update, import, or validation request | resolve_salary_basis_status |
| Salary Basis Type lookup validation | Resolve a supplied Salary Basis Type only from enabled ORA_CMP_SAL_BASIS_DET_METHOD values; use the resulting LookupCode in the validated value | A Salary Basis Type is supplied | resolve_salary_basis_type |
| Frequency lookup validation | Resolve a supplied Frequency only from enabled CMP_SALARY_BASIS values; use the resulting LookupCode in the validated SalaryBasisCode value | A Frequency is supplied | resolve_salary_basis_frequency |
| Annualization Factor defaulting | Preserve a supplied Annualization Factor. When omitted, apply only the exact resolved-frequency map in `ora_defaulting_rules.md`; require user input for PERIOD and unmapped codes. | A Frequency is supplied | resolve_salary_basis_frequency |
| Input Value Name and ID resolution | When omitted, use Amount and apply the existing schema and dependency validation. Resolve InputValueId only from one exact child Name matching the resolved Input Value Name for the resolved ElementTypeId; a nonmatching child is a query-contract failure. | The referenced payroll-enabled Salary Basis flow is in scope | resolve_salary_basis_input_value_id |
| Documented element identity | For the referenced payroll-enabled flow, validate only exact ElementName, LegislativeDataGroupName, and effective dates. Do not infer category, primary classification, processing type, calculation rule, or automatic eligibility. | Before accepting the supporting element as ready | resolve_salary_basis_element |
| Grade Rate association | Resolve one exact active effective GradeRateName, then require the current SalaryBasis schema to declare the target field or child and its accepted identity shape. | A Grade Rate is supplied | resolve_salary_basis_grade_rate |
| Range differential dependency | Require selected LDG and Grade Rate before accepting a resolved range differential; resolve the differential only through its describe-confirmed custom action. | A parent SalaryBasis row supplies a range differential | resolve_salary_range_differential_code |
| Element response semantics | Treat a result as valid only when returned ElementName and LegislativeDataGroupName equal the requested values exactly. Unrelated records are a query-contract failure. | Every payroll element lookup | resolve_salary_basis_element |
| Create duplicate guard | Validate exact name and code collisions before loader-source preparation. | Every create request | check_salary_basis_duplicates |
| Name and Code bounds | Require SalaryBasisName and Code to be nonblank and no longer than 80 characters; Code is derived only when omitted and then still passes schema and duplicate validation | Every create, update, import, or preview request that supplies the field | read_salary_basis_schema |
| Annualization and precision bounds | Require Annualization Factor to be at least 0.000001 and no greater than 10000 when the current schema accepts the documented numeric rule; require AmountDecimalPrecision to be an integer from 0 through 10 when supplied | A parent SalaryBasis row supplies the field | read_salary_basis_schema |
| Incremental component collection | Require distinct SalaryComponentCode values. Treat display sequence and description returned by the selected component as derived display data unless current child metadata explicitly accepts a write. | SalaryBasisType resolves to C and ComponentUsage selects components | read_salary_basis_schema |
| Simple component collection | Require DisplaySequence and ProcessingSequence to be integers from 1 through 999 and unique within the basis. Apply BasedOnComponentCode, OverallSalaryImpact, UserSelectedComponent, and DefaultValue only when the selected component type and current metadata require them. | SalaryBasisType resolves to ORA_SIMPLE_COMPONENTS | read_salary_basis_schema |
| Calculated component attributes | Require at least one attribute for a calculated-amount component; require a lower processing sequence for based-on references; accept ComponentFactor only when nonnegative and current metadata supports it. | A simple component resolves to ORA_CALCULATED_AMOUNT | read_salary_basis_schema |
| Rate component collection | Require distinct rate definitions, DisplaySequence from 1 through 999 and unique within the basis, and exactly one overall rate. Treat rate periodicity and precision as read-derived data unless current metadata declares a writable target. | SalaryBasisType resolves to R | read_salary_basis_schema |
| Documented rate-definition configuration | For a rates-based Salary Basis, require Element, Amount, the resolved element, Reporting Required selected, Calculate Live Rates selected, Returned Rate Details unchanged, and Input Value contributor type | Before accepting the supporting rate definition as ready | resolve_salary_basis_rate_definition |
