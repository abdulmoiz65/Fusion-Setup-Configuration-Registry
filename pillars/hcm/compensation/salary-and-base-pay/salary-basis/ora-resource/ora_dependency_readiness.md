# Dependency Readiness

## Required Dependency Order

| Sequence | Dependency | What Must Happen |
|---|---|---|
| 1 | Registered SalaryBasis business object | Resolve exactly one registered BO named SalaryBasis. |
| 2 | Current SalaryBasis schema | Retrieve the current template, components, and attribute metadata. |
| 3 | Salary Basis status | Resolve a supplied status from enabled ACTIVE_INACTIVE values, or resolve the Active default when status is omitted. |
| 4 | Salary Basis Type | Resolve any supplied type from enabled ORA_CMP_SAL_BASIS_DET_METHOD values. |
| 5 | Frequency | Resolve any supplied frequency from enabled CMP_SALARY_BASIS values. |
| 6 | Annualization Factor | Preserve a supplied value, or default it only from the resolved frequency mapping. Require a user value for PERIOD or an unmapped code. |
| 7 | Schema-declared dependencies | Validate only the reference-object and lookup dependencies returned by the current SalaryBasis schema for the supplied fields. |
| 8 | Payroll element endpoint contract | Read payrollElementDefinitionsLOV describe metadata before selecting its finder or query parameters. |
| 9 | Salary basis element | When the referenced payroll-enabled flow is in scope, validate the existing element through the describe-confirmed read-only payrollElementDefinitionsLOV resolver. |
| 10 | Compensation element input-value endpoint contract | Read compensationElementsLOV describe metadata before selecting its finder parameters or following payrollElementInputValues. |
| 11 | Salary basis input value ID | Resolve InputValueId for exactly one child Input Value Name matching the resolved Input Value Name from the resolved ElementTypeId. |
| 12 | Salary range differential endpoint contract | When a Differential Profile Name is supplied, read salaryRangeDifferentials describe metadata before using the findByAdvancedSearchQuery custom action, headers, or request parameters. |
| 13 | Salary range differential code | Resolve the supplied Differential Profile Name through the describe-confirmed read-only salaryRangeDifferentials custom action. |
| 14 | Input Value Name | Preserve a supplied value and apply the existing validation rules, or use Amount when omitted before applying those rules. |
| 15 | Grade Rate association | When supplied, resolve one exact active effective Grade Rate and verify its SalaryBasis schema-declared target field or child. |
| 16 | Salary Basis uniqueness | Confirm name and code do not collide in the selected LDG before loader-source preparation. |
| 17 | Salary basis rate definition | When SalaryBasisType resolves to R, create the documented Element/Amount rate definition in the Rate Definition task. |

## Dependency Classification

| Result Category | When Used | Can Run Lookup/Create? |
|---|---|---|
| Satisfied | The exact registered BO, current schema, and all applicable schema-declared dependencies validate | No create through this resource; continue only to the separate Data Loader workflow |
| Blocked | Registered-BO lookup, template retrieval, attribute metadata, or a required schema-declared dependency is unavailable or invalid | Read-only lookup only; stop before preview, import preparation, or mutation |
| Documented prerequisite gap | A required element, rate definition, group, or Full-mode HCM rates generation is missing or fails its declared read-only validation | Do not infer completion or create through this resource; stop for the owning task or documented execution contract |
