# Reference Lookups

All configuration reads are GET-only and must use
`core.fusion-api.rest-api-client`. Escape string literals, URL-encode the
complete `q` value, page until `hasMore` is false, and retain the returned item
identity and key fields required for later Data Loader preparation.

## Lookup Execution Rules

| Situation | What Happens |
|---|---|
| An exact ContextType contains a quote or escape character | Escape the string literal first and then URL-encode the complete q value. |
| A contains context search is requested | Search the bounded ORA_FEEDBACK_CONTEXT_TYPE codes and meanings locally, then retrieve configurations only with exact q=ContextType predicates for matched codes. Never send q=Name or a ContextType contains predicate. |
| A collection response has hasMore true | Advance offset by the number of returned rows and continue until hasMore is false. |
| A read returns partial, ambiguous, or failed evidence | Keep the result distinct from not found and stop any dependent mutation preparation. |
| A configuration list or detail is rendered | Retrieve every bounded page from Common > Manage Common Lookups for ORA_FEEDBACK_CONTEXT_TYPE, ORA_NOTE_VISIBILITY_CODE when a nonblank code exists, and PER_SUPERVISOR_TYPE only when ContextType is ORA_NO_CONTEXT; resolve applicable returned codes exactly before composing the response. |
| ContextType is ORA_NO_CONTEXT | Display the current Meaning returned by ORA_FEEDBACK_CONTEXT_TYPE, including Anytime Feedback when that is the current exact meaning; do not display No Context as the business label. |
| ContextType is ORA_NO_CONTEXT and NotificationManagerTypeList is nonblank | Resolve and display Manager Type through PER_SUPERVISOR_TYPE; this is the only context in which Manager Type is visible. |
| ContextType is not ORA_NO_CONTEXT | Do not resolve or display NotificationManagerTypeList as an active setting; keep the value blank in normalized list results and create or edit artifacts, and hide Manager Type in detail or edit views even when Fusion returns a stored backend value such as LINE_MANAGER. |
| ContextType is supplied or must be validated | Route only to [Common > Manage Common Lookups](../../../../global-human-resources/global-human-resources-common/manage-common-lookups/SKILL.md) with LookupType ORA_FEEDBACK_CONTEXT_TYPE. |
| DefaultNoteVisibilityCode is a selected value other than No Default | Route only to [Common > Manage Common Lookups](../../../../global-human-resources/global-human-resources-common/manage-common-lookups/SKILL.md) with LookupType ORA_NOTE_VISIBILITY_CODE. |
| A read returns a backend null for DefaultNoteVisibilityCode | Render and retain the normalized business value as No Default rather than blank or null. |
| A read returns the literal #NULL for DefaultNoteVisibilityCode | Classify the row as invalid stored data; do not present #NULL as No Default and do not copy it into another artifact. |
| Create or edit explicitly requests No Default | Preserve the normalized value exactly as No Default and do not run the visibility lookup. Stop before Data Loader preview when the registered adapter does not advertise a supported No Default mapping. |
| ContextType is ORA_NO_CONTEXT and ManagerType or NotificationManagerTypeList is supplied or returned | Route only to [Common > Manage Common Lookups](../../../../global-human-resources/global-human-resources-common/manage-common-lookups/SKILL.md) with LookupType PER_SUPERVISOR_TYPE. |
| A profile-option value is required | Route only to hcm.global-human-resources.global-human-resources-common.manage-profile-options. |
| A create, edit, or delete is requested | Use configuration reads only for resolution and verification; route the mutation exclusively through core.data-loader. |
