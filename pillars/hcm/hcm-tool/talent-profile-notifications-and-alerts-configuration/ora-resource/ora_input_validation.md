# Talent Notifications Input Validation

Classify guidance, blank-template, draft-questionnaire, and implementation
requests before any Fusion-dependent validation. Only implementation validates
hybrid identity-or-business-intent intake against the dynamic Profile
Management partition of a fresh FSM export.

| Task Code | Task Name | Condition | Result | Guidance | Resolver |
|---|---|---|---|---|---|

| HRT_MANAGE_TALENT_NOTIFICATIONS | Talent Notifications | User asks for the blank or fillable requirements template | blank_template_provided | Return the checked-in workbook unchanged and make no Fusion-dependent request | |
