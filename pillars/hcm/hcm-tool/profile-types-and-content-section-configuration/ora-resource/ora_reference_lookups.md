## Lookup Execution Rules

| Task Code | Task Name | Situation | What Happens |
|---|---|---|---|
| HRT_MANAGE_PROFILE_TYPES | Profile Types | Business intent needs context or comparison | Use only declared local project evidence and read-only resolver results; log each inferred value with source, sanitized evidence, confidence, materiality, and review status |
| HRT_MANAGE_PROFILE_TYPES | Profile Types | Technical normalization or exact duplicate check is required | Use only a declared provider read for every candidate section. For profileTypeSectionsLOV, zero exact rows for every candidate clears only the duplicate gate; any one exact duplicate routes the complete ZIP to the duplicate-stop terminal, and multiple matches for a candidate are ambiguous. The result does not replace provider, reference, archive-scope, Task Hook, approval, or readback gates |
| HRT_MANAGE_PROFILE_TYPES | Profile Types | A section is generated for any supported seeded profile type other than Person | Select exactly one active source row for that target by explicit SectionContext plus exact ProfileTypeCode and ContentTypeContextName, retain its ParentSectionSectionContext and TemplateBasedSectionFlag, resolve the corresponding Person section with resolve_profile_type_parent_template, then use resolve_model_content_section_properties to merge only selected-Person B/null-SourceCode rows with template M rows before customization or immutable preview; on zero parent matches request explicit scope approval and delegate parent construction and ordering to FSM processing; never choose among multiple active source sections by content type alone |
| HRT_MANAGE_PROFILE_TYPES | Profile Types | A current-state content-section verification is requested | Use only the GET allowlist in references/read-only-rest-verification.md, complete pagination before exact matching, compare server-normalized properties and separately prove catalog presence versus assignment, then terminate with the read-only report; never continue to proposal, preview, export, import, or execution |

## Source Basis

- Oracle documents Education as a predefined content-section template and the
  Active, Approval Required, property, and predefined subscriber behavior:
  https://docs.oracle.com/en/cloud/saas/talent-management/fauep/content-sections-templates.html
  and
  https://docs.oracle.com/en/cloud/saas/talent-management/fauep/content-section-properties.html.
- Oracle documents the read-only `profileTypeSectionsLOV` resource, including
  `findTemplateSections` and `findByProfileTypeId`:
  https://docs.oracle.com/en/cloud/saas/human-resources/farws/op-profiletypesectionslov-get.html.
- Oracle documents task CSV import creation, task capability reads, process
  polling, and ProcessLog retrieval under `setupTaskCSVImports`:
  https://docs.oracle.com/en/cloud/saas/applications-common/26b/farca/api-setup-task-csv-imports.html.
- The native header-only task template exported from the selected Fusion
  environment is authoritative for the task marker, registered migration
  service, business-object graph, exact member names, columns, and node paths.
  Never copy its environment, submitter, process, or other instance metadata
  into reusable guidance or project diagnostics.
