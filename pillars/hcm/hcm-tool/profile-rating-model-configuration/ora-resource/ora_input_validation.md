## Validation Rules

| Task Code | Task Name | Check | Blocking Condition | Business Impact | Correction |
|---|---|---|---|---|---|
| HRT_MANAGE_PROFILE_RATING_MODELS | Profile Rating Models | Sequence and code uniqueness | Sequence is not consecutive from 1 or a level code repeats | Scale and read-back mapping are ambiguous | Renumber and assign stable unique codes |
| HRT_MANAGE_PROFILE_RATING_MODELS | Profile Rating Models | Numeric direction | Required values are not unique whole numbers increasing toward the best level | Performance calculation or Skills Center semantics are invalid | Correct numbers and confirm highest number is best |
| HRT_MANAGE_PROFILE_RATING_MODELS | Profile Rating Models | Skills Center identifiers | A Skills Center level identifier is missing, repeated, nonnumeric, decreasing, or outside 1 through 9 | The Skills Center proficiency scale is unsupported | Use unique increasing integer identifiers within 1 through 9 |
| HRT_MANAGE_PROFILE_RATING_MODELS | Profile Rating Models | Calculation ranges | A range is missing, reversed, overlapping, or has an unexplained precision gap | Calculated values can map twice or not at all | Align contiguous ranges to declared precision |
| HRT_MANAGE_PROFILE_RATING_MODELS | Profile Rating Models | Performance handoff completeness | A calculated-rating handoff omits calculation method, decimal places, decimal rounding rule, mapping metric, mapping method, or the owner of Target Ratings Distribution | The downstream Performance section cannot reproduce the intended calculation and distribution behavior | Complete the Performance-owned handoff fields without adding them to the rating-model payload |
| HRT_MANAGE_PROFILE_RATING_MODELS | Profile Rating Models | Distribution values | A percentage is outside 0 through 100, direct minimum exceeds maximum, or Performance target percentages do not total 100 | Downstream distribution behavior is invalid | Correct the applicable owner-specific values |
| HRT_MANAGE_PROFILE_RATING_MODELS | Profile Rating Models | Skills-only scope | Review points, ranges, categories, or distributions are supplied without another consumer | Unneeded components expand downstream impact | Remove the values or select the requiring consumer |
| HRT_MANAGE_PROFILE_RATING_MODELS | Profile Rating Models | Customer mapping | A source sheet or column is missing, ambiguous, or only similar | Requirements can be assigned to the wrong field | Require explicit mapping review; never auto-map uncertainty |
| HRT_MANAGE_PROFILE_RATING_MODELS | Profile Rating Models | Initial technical completeness | Code, name, descriptions, languages, numeric values, or optional components are absent before discovery but a supported proposal can be produced | Users are forced to understand Fusion configuration before stating the outcome | Continue to a review-only proposal and record provenance; block only before technical normalization if unresolved |
| HRT_MANAGE_PROFILE_RATING_MODELS | Profile Rating Models | Question materiality | A follow-up requests a skill, task, consumer, loader route, field name, or other technical value that can be inferred or proposed without changing business behavior | The interaction becomes a technical questionnaire | Do not ask it; infer or propose the value and expose it under Review assumptions |
