# Learning Audience Error Handling and Execution Boundary

These rules apply repository error-handling and workflow boundaries to the
source gaps. No live Fusion calls, Data Loader metadata requests, registry
registration, or table writes are performed during resource authoring.

For Manage User Groups, unresolved user-suppliable information is an
interactive pause, not a terminal task failure. Ask for the exact missing
attribute or evidence, preserve completed work and the resume point, and
continue from the same step after the user replies. Keep preview and execution
gated until the information is resolved; never guess a value to avoid asking.

Do not ask for HCM Filtered Lists evidence when the user-group dependency is
Not applicable under ora_dependency_readiness.md. A task-wide planner rejection
can still reflect incomplete conditional contracts; report that as a registry
authoring/readiness gap, not as a missing feature on the pod. This applicability
correction is not an explicit registry-readiness override or submission approval.

| CUSTOM_MANAGE_USER_GROUPS | Manage User Groups | Existing-parent child loads fail with object-level `Not Found` | Re-resolve the parent and compare the numeric learningOrganizationId with the exact returned `@context.key`. If both child-only and parent-PATCH-plus-child loader shapes failed, the numeric item route fails, and the composite route succeeds, record a Data Loader registration mismatch and stop loader retries. If the user explicitly requests the direct-child fallback, re-run the exact child duplicate check and prepare one collection POST preview for separate approval |
| CUSTOM_MANAGE_USER_GROUPS | Manage User Groups | The approved direct criteria POST returns `Person doesnot have the required privilage` or another authorization denial | Classify the result as auth/authz, do not retry the POST, and immediately read the exact child collection to determine whether a row was created. Report the returned message exactly, state the verified child count, preserve the approved payload, and ask for the calling Fusion identity to receive the required Learning user-group criterion create privilege or for an already-authorized identity to be selected |
| CUSTOM_MANAGE_USER_GROUPS | Manage User Groups | Reconcile submission or result is uncertain | Stop; retain sanitized action and ESS identifiers when returned, resolve current group reconciliation fields through a declared read, and do not submit the action again without a completed monitoring contract and new approval |
| CUSTOM_MANAGE_LEARNING_AUDIENCE_CRITERIA | Manage Learning Audience Criteria | A later authorized mutation has an uncertain result | Stop; preserve sanitized request identifiers and partial results; reconcile through a declared read before any approved retry |
| CUSTOM_MANAGE_USER_GROUPS | Manage User Groups | A later authorized mutation has an uncertain result | Stop; preserve sanitized request identifiers and partial results; reconcile through a declared read before any approved retry |

## Error Classifications

| Task Code | Task Name | Result Category | When Used | Next Action |
|---|---|---|---|---|
| CUSTOM_MANAGE_LEARNING_AUDIENCE_CRITERIA | Manage Learning Audience Criteria | Input validation | Required criteria fields, authority or syntax are unresolved | Complete the source contract and recompile; do not execute an incomplete plan |
| CUSTOM_MANAGE_USER_GROUPS | Manage User Groups | Input validation | Required root or child fields are missing, a create-only or response-only field is misused, a documented enum is invalid, or an LOV-backed value remains unverified | Correct the specific field or obtain the authoritative LOV contract; then revalidate the unchanged operation intent |
| CUSTOM_MANAGE_USER_GROUPS | Manage User Groups | Missing information | A required user-suppliable value or evidence cannot be resolved from the current input and permitted lookups | Ask for the exact missing information, preserve the current task state and resume point, and continue after the reply; if the user cannot provide it, return MISSING rather than FAILED |
| CUSTOM_MANAGE_USER_GROUPS | Manage User Groups | Identity or relationship mismatch | Parent identity, child role or criteriaId is absent, ambiguous or mapped to the sibling relation | Resolve the exact group and exact managerCriteria or participantCriteria item; do not switch roles or infer a relation identifier |
| CUSTOM_MANAGE_USER_GROUPS | Manage User Groups | Participant person identity | A supplied Username cannot be mapped exactly once to a non-null PersonId, or an ID-only person reference is invalid, mismatched or unverified | Ask for corrected Username/ID or missing authoritative evidence and rerun the corresponding read-only resolver; distinguish invalid input from denied or incomplete reads |
| CUSTOM_MANAGE_USER_GROUPS | Manage User Groups | Duplicate criteria | Another existing or proposed row under the same exact parent and role has the final sourceType/sourceId; PATCH excludes only itself | Ask the user to skip/correct the affected row, then rerun source resolution and the complete duplicate check without silently changing existing rows |
| CUSTOM_MANAGE_USER_GROUPS | Manage User Groups | Authorization | A direct criteria POST reaches the exact composite child collection but Fusion rejects the calling person for insufficient privilege | Do not retry or change the payload. Verify the child collection by GET, report whether the mutation occurred, and require the appropriate Learning user-group criterion create privilege or an explicitly selected authorized identity before a newly approved retry |
| CUSTOM_MANAGE_USER_GROUPS | Manage User Groups | Transport or Fusion API | A selected read returns an HTTP or Fusion error | Report the method, relative resource path, status, redacted response summary and ECID when available; do not expose the source host or retry a mutation |
| CUSTOM_MANAGE_LEARNING_AUDIENCE_CRITERIA | Manage Learning Audience Criteria | Catalog mismatch | CSV import/export is requested despite catalog N flags | Stop CSV routing until documented support is established |
| CUSTOM_MANAGE_USER_GROUPS | Manage User Groups | Catalog mismatch | CSV import/export is requested despite catalog N flags | Stop CSV routing until documented support is established |

## Refusal Rules

| Task Code | Task Name | Situation | What Must Not Happen |
|---|---|---|---|
| CUSTOM_MANAGE_LEARNING_AUDIENCE_CRITERIA | Manage Learning Audience Criteria | Registry readiness is incomplete | Do not substitute browser execution, SQL writes, guessed REST requests or another import route |
| CUSTOM_MANAGE_USER_GROUPS | Manage User Groups | Registry readiness is incomplete | Do not substitute browser execution, SQL writes, guessed REST requests or another import route |
| CUSTOM_MANAGE_USER_GROUPS | Manage User Groups | A create or update of learningOrganizations, managerCriteria or participantCriteria is requested | Do not send a direct root mutation, a criterion PATCH without a resolved criteriaId, or any direct child create outside the documented registration-mismatch fallback. Ordinary mutations remain on core.data-loader; the fallback is limited to a separately approved collection POST for one resolved existing-parent criterion |
| CUSTOM_MANAGE_USER_GROUPS | Manage User Groups | A REST child is absent from the live Data Loader template | Do not add a worksheet or DAT section from /describe alone; require live loader component metadata before treating the child as loadable |
| CUSTOM_MANAGE_USER_GROUPS | Manage User Groups | managerPersonList or participantPersonList collection creation is requested | Do not synthesize a collection POST; the supplied /describe contract advertises collection GET only |
| CUSTOM_MANAGE_USER_GROUPS | Manage User Groups | Required information is unresolved but can be supplied by the user | Do not guess, abandon completed work, or return a terminal blocker before asking for the exact missing information and recording the resume point |
| CUSTOM_MANAGE_LEARNING_AUDIENCE_CRITERIA | Manage Learning Audience Criteria | Rule graph succeeds after future completion | Do not report a created or changed criteria definition from validation success; the invoking runbook must execute and verify separately |
| CUSTOM_MANAGE_USER_GROUPS | Manage User Groups | Rule graph succeeds after future completion | Do not report a created or changed group from validation success; the invoking runbook must execute and verify separately |
