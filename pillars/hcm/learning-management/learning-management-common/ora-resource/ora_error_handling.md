# Common execution boundary and errors

Source: FDD GB-10–GB-16, repository error discipline and selected provider contracts.
Passing these task nodes returns validation evidence only, not a Fusion write or
success claim. The invoking routed workflow still owns exact preview, immediate
approval (or Data Loader's authoritative gate), execution and verification.
