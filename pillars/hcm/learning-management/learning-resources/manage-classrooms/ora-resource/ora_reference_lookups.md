## Lookup Execution Rules

| Situation | What Happens |
|---|---|
| A required lookup path is TBD | Stop only the operation that requires that lookup; do not invent a service path |
| Classroom count or bulk intent is missing | Stop before route-specific lookups; ask how many classrooms the user wants to create or whether the request is bulk |
| Count is exactly 1 | Run validate_classroom_rest_contract and use the REST field names only; do not preflight Data Loader unless the user later approves a route change |
| Count is greater than 1 or Bulk is selected | Run validate_classroom_resource_contract and require Excel or DAT; do not issue one REST POST per row |
| An ordinary create has no explicit classroom number | Run resolve_existing_classroom_by_keyword for informational same-title candidates; do not manufacture or request a classroom number solely for duplicate checking |
| A caller proposes an unfiltered learningClassrooms collection GET | Refuse the request; use resolve_existing_classroom_by_number when a stable number is retained and resolve_existing_classroom_by_keyword for informational same-title candidates |
| The stable-number finder returns HTTP 400 or an incompatible response | Classify the hard duplicate check as a lookup-contract failure and block rows that retain the supplied number; do not reinterpret the result as zero matches |
| The keyword finder returns HTTP 400 or an incompatible response | Record that informational title collision inspection was unavailable, warn in the proposal, and continue without claiming zero same-title matches |
| A lookup returns 401 or 403 | Classify as authentication or authorization failure, not no-match |
| An ad hoc address is supplied | Block this Data Loader route; an existing HCM Location is required |
| No eligible location is returned | Preserve the classroom row, route the manual Locations Setup dependency, and repeat this lookup after provider completion; never trust provider output without read-back |
| A paged lookup has hasMore true | Continue with the next offset until an exact match is found or all applicable pages are evaluated; never treat the first page as complete |
| A user supplies both an ID and a code or number | Confirm that both resolve to the same record; conflicting keys block |
| An optional lookup has no documented executable contract | Offer Skip; if the value is retained, keep the row blocked rather than trusting free text |
