All calls in this file are read-only. Learning Catalog never mutates Worker,
Instructor, Training Supplier, lookup, attachment, or DFF dependency resources.

## Lookup Execution Rules

| Situation | What Happens |
|---|---|
| A collection returns an item | Follow its returned item link; never construct an opaque item hash |
| A create or update mutation is requested | Run resolve_course_loader_registration before preview and execute the supported mutation through core.data-loader; do not substitute Direct REST automatically |
| Existing activities are returned | Use them as membership and assignment-impact evidence only |
| courseDefaultInstructors is supplied | Preserve the approved request representation; do not derive it from lookup results or courseDefaultInstructorDetails |
| Facilitator is supplied | Resolve ORA_WLF_FACILITATOR_TYPE first and route its number according to the enabled meaning |
| A row adds or replaces a child | Stop only that row while authoritative eligibility and exclusivity evidence is unavailable |
| Copy is executed | Read the returned identity and verify Draft status; do not assume the copy action selected it |
| Lookup evidence changes after preview | Invalidate the affected approval and rebuild its preview |
