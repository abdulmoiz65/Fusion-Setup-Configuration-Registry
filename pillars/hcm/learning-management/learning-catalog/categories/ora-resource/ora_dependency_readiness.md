# Categories Dependency Readiness

## Required Dependency Order

| Sequence | Dependency | What Must Happen |
|---|---|---|
| 1 | Profile-option triggers and current values | Determine whether unified listing/CAP administration or search design applies; read every applicable current effective option value through the Application Profile Option Foundation capability |
| 2 | Profile prerequisites, decisions, and readback | Record correct options as satisfied and omit them from the user dialog; require applicable CAP readiness; bind each proposed change to exact approval and verify readback |
| 3 | Environment, Redwood feature, and access | Require ORA_WLF_CATG_TOP_REDWOOD_ENABLED at Site Y, then confirm Learning administrator view/manage privilege, related Category/Topic privileges, HCM data-role access, and manager or all-items access |
| 4 | Category identity and field values | Resolve one Category subtype plus current Active and visibility values; resolve an existing Category when required |
| 5 | Parent state and manager safety | Read current parent, manager set, Topic relationships, last-modified evidence, and a normalized fingerprint |
| 6 | Child references and capability | Resolve each Topic, person, membership source, asset, and DFF; verify the exact registered child-write capability before proposing it as executable |
| 7 | Preview and approval | Produce an immutable versioned proposal with stable row IDs, every applicable profile-option change, and an exact fingerprint |
| 8 | Parent-first execution and verification | Reread profile and Category state, execute each approved parent once, then eligible children, and read back every attempt independently |

## Dependency Classification

| Result Category | When Used | Can Run Lookup/Create? |
|---|---|---|
| Ready | Every dependency applicable to the selected parent and child rows is exact and current | Read-only lookups may run; mutation still requires exact approval |
| Satisfied | An applicable profile option is already correctly populated and read evidence is current | Record it as satisfied and omit it from the user dialog |
| Decision Required | A triggered profile option needs the user's search preference or approval of an exact change | No mutation until the decision is included in the exact proposal |
| Child Row Blocked | A child reference, capability, or row-specific rule is unresolved | No for that child; independent valid parents and siblings may continue |
| Parent Row Blocked | Parent identity, title, access, subtype, manager safety, or approval is unresolved | No for that parent or any of its children |
| Operation Blocked | The requested operation is excluded or its registered contract is not confirmed | No for that operation |
| Not Required | A conditional dependency does not apply | No lookup needed |
