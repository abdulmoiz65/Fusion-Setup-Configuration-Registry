# Official Communities Dependency Readiness

## Required Dependency Order

| Sequence | Dependency | What Must Happen |
|---|---|---|
| 1 | Target and profile-option discovery | Match the supplied Describe to the target and read the effective value of each applicable FDD profile option through the Application Profile Option Foundation route |
| 2 | Conditional external prerequisites | When unified listing or CAP-based administration applies, require applicable Catalog Administration Profile readiness before proposing Site Y; never implement CAP setup here |
| 3 | Access and parent-value readiness | Verify the current community-management surface, manager or all-items scope, operation privileges, exact Official Community subtype, Active status, summary rule, visibility, and required DFFs |
| 4 | Current parent state | Resolve one exact parent and refresh manager, catalog, membership-criteria, rating, media, related-material, translation, DFF, and where-used evidence needed by the request |
| 5 | Requested child capability and references | Require an exact registered write contract and authoritative identities only for selected child rows |
| 6 | Proposal and approval | Omit satisfied profile options from the dialog; freeze every proposed profile change plus exact parent/child selection and fingerprints, obtain approval, and re-read before one submission |
| 7 | Profile and operation verification | Read back every approved configured and effective profile value before its dependent community operation, then verify each attempted community result |

## Dependency Classification

| Result Category | When Used | Can Run Lookup/Create? |
|---|---|---|
| Ready | All dependencies applicable to the selected parent and child rows are exact | Read-only lookups may run; mutation still requires approval |
| Child Row Blocked | A reference or capability applies only to selected optional child rows | No for those rows; an independently valid parent and unrelated children may continue |
| Parent Operation Blocked | Applicable profile read/change, CAP prerequisite, community-management surface, access, subtype/status, summary rule, required DFF, parent contract, or approval is unresolved | No for the parent or its dependent children |
| Not Required | A conditional dependency does not apply | No lookup needed |
