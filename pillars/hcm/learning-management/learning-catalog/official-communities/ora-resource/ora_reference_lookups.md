All calls in this file are read-only. Never use a display label as a write
identifier, construct an opaque item hash, or borrow a resolver for an
undocumented membership, assignment, skill, qualification, or moderation
operation.

## Lookup Execution Rules

| Situation | What Happens |
|---|---|
| A parent collection returns an item | Verify the exact subtype and follow the returned item link; never construct an opaque item hash |
| A create or update mutation is requested | Run resolve_official_community_loader_registration before preview and execute the supported mutation through core.data-loader; do not substitute Direct REST automatically |
| A profile-option trigger does not apply | Do not query it as a decision dependency or display it in the user dialog |
| An applicable profile option is already correctly populated | Record it as a satisfied dependency and omit it from the user dialog |
| Unified listing or CAP-based administration applies | Require external applicable CAP readiness first; this skill neither creates nor validates CAPs and does not invent a CAP provider skill ID |
| ORA_WLF_COMMUNITIES_REDWOOD_ENABLED is present | Verify its current effective value and the community-management surface without hard-coding the required value |
| ORA_WLF_COMMUNITIES_REDWOOD_ENABLED is absent | Do not propose a value or manufacture a replacement; require evidence for the current release's supported control and management surface |
| Catalog search behavior is being designed or tuned | Ask for broader recall, balanced matching, or tighter precision only when a change decision is needed; preserve the current value otherwise |
| A profile-value change is proposed | Bind the exact option, level, old value, new value, and dependent effect to approval; after one approved write, reread configured and effective values before community work |
| A title search returns likely duplicates | Show exact accessible candidates and require user selection; a similar title alone does not block create |
| Open visibility is proposed | Require current enabled lookup evidence and disclose the default; otherwise ask for a supported explicit value |
| Current state is read | Fetch only children applicable to the request and fingerprint the exact fields and relationships used by the proposal |
| A required person, learning selector, membership, group, assignment, skill, qualification, or moderation resolver is absent | Stop only its dependent row and report the missing authoritative contract; never substitute another resource |
| Lookup or current-state evidence changes after preview | Invalidate the affected approval, skip the action, and rebuild its proposal |
