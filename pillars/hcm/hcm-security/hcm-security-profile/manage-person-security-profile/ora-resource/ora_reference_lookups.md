# Person Security Profile Reference Lookups

Use the internal `hcm.hcm-security.hcm-security-common.manage-common-lookups` skill for
lookup-code resolution. Execute every read-only HCM REST lookup in this file
through `core.fusion-api.rest-api-client`; do not issue a direct REST request.
Resolve `{fusion_environment_host}` and `{version}` at runtime. When a
profile-reference resolver returns no match, block the import and ask the user
to provide the correct value.

## Lookup Execution Rules

| Situation | What Happens |
|---|---|
| No work-structure criterion is selected | Do not run either lookup; continue to design enforcement. |
| No enabled similar profile exists | Continue to design enforcement without an AOR recommendation. |
| One or more enabled similar profiles exist | Show each matching profile Name and the exact shared criterion set. Retrieve the current AOR scope candidates before design enforcement. |
| AOR scope candidates are required | Use hcm.hcm-security.hcm-security-common.manage-common-lookups with lookupType ORA_PER_PRSN_SEC_AOR_SCOPES. Do not call the Common Lookups REST endpoint directly from this task. |
| Exactly one AOR scope matches the complete criterion set | Show its ScopeOfResponsibility and ScopeOfResponsibilityMeaning as the AOR recommendation. |
| No or multiple AOR scopes match the complete criterion set | Show no automatic AOR scope recommendation; do not invent a fallback scope. |
| A Person Security Profile FSM package is generated | Resolve the current target-environment template-only layout first. Include every CSV member from its ordered manifest in the ZIP. Generate every parent or child row only from its member, header, field-mapping, and parent-link outputs; when a member has no applicable rows, retain its exact template header as a header-only CSV. Use template-derived ViewInstanceName and GroupingKey values when present; otherwise use the documented member-specific ViewInstanceName fallback and a distinct uppercase 32-character hexadecimal GUID without separators as GroupingKey for every new row. Retain ASM_SETUP_CSV_METADATA.xml byte-for-byte without any change. |
