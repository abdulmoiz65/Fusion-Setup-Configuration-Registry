# Organization Security Profile Reference Lookups

Use `core.fusion-api.rest-api-client` for every standard HCM REST LOV lookup in
this file; do not issue a direct REST request. Resolve the Organization Tree
and Department Tree before preparing the Organization Security Profile CSV
package. Use unfiltered LOV collections for browsing only; automatic selection
requires the documented resolver and an explicit, unique input value.

## Lookup Execution Rules

Every live lookup is a REST GET operation and is pre-approved by this task's execution policy; no separate user approval is required.

| Situation | What Happens |
|---|---|
| A live REST GET lookup is planned | Send the documented read-only GET when its resolver conditions are met; no separate user approval is required. |
| A request includes more than one selected security criterion | Resolve the documented values for every selected criterion. Do not treat selected hierarchy, classification, or organization-list criteria as alternatives. |
| A Department Tree is supplied | Use hcmTreesLOV with finder=findByWord;TreeStructureCode=PER_DEPT_TREE_STRUCTURE and comma-delimited finder attributes; do not use Manage Common Lookups for the concrete tree identity |
| A Department Tree lookup is sent | Pass finder=findByWord;TreeStructureCode=PER_DEPT_TREE_STRUCTURE,SearchTerms={term},FilterAttributes=TreeName as one finder expression. Do not pass TreeStructureCode as a standalone query parameter. |
| A Department Tree node is resolved | Include TreeCode, SysEffectiveDate, FilterAttributes=DepartmentName, and SearchTerms={DepartmentName} in the finder expression. Start at offset=0, follow pages while hasMore=true, then require one exact distinct DepartmentName and OrganizationId match. |
| departmentTreeNodesLOV returns a page | Start at offset=0. When hasMore=true, request the next offset after the returned page; do not infer absence or ambiguity from a partial page. |
| An organization-hierarchy CSV uses a Department Tree | Require the selected Department resolver to provide nonblank TopOrganizationName and TopOrganizationId before the package preview; do not derive either from a display-only selection. |
| An organization-hierarchy CSV uses a Department Tree | Map OrgHierTreeCode exactly from resolve_department_tree_from_hcm_trees_lov TreeCode, with TreeName from the same resolver and OrgHierTreeStructCode=PER_DEPT_TREE_STRUCTURE. Do not leave OrgHierTreeCode blank or use the tree display name in its place. |
| The request says department from the user's assignment | Use TopOrgSelection=U in the parent profile row. This selection source is independent of IncludeTopOrganizationFlag, which controls whether the top organization itself is included. |
| An Organization Tree code is supplied | Use hcmTreesLOV PrimaryKey with TreeCode, then require PER_ORG_TREE_STRUCTURE and active status; do not use Manage Common Lookups for the concrete tree identity |
| An Organization Tree name is supplied | Use hcmTreesLOV finder=findByWord;TreeStructureCode=PER_ORG_TREE_STRUCTURE,SearchTerms={term},FilterAttributes=TreeCode TreeName; then require one exact TreeName |
| Tree candidates are requested | Use the recognizable supplied code or name fragment. After the security model is selected, a browse-only request may use the bounded model seed Organization or Department; empty or wildcard-only supplied SearchTerms are not a tree browse mechanism. |
| An hcmTreesLOV request is sent | Do not send fields. Map the returned response locally to the documented fields because the endpoint rejects the requested projection in this environment. |
| Organization LOV candidates are requested | Require OrganizationSearchTerm and return at most five matching candidates for browsing only; do not select a single result without caller-provided selection context. |
| An automatic tree, node, or top-organization selection is requested | Use the corresponding resolver with an explicit identifier or name; stop on zero or multiple distinct logical matches |
| A tree-node or top-organization match is selected | Require the result to be effective on the requested date before filling values |
| organizationTreeNodesLOV returns a page | Start at offset=0. When hasMore=true, request the next offset after the returned page; do not infer absence or ambiguity from a partial page. |
| organizationTreeNodesLOV repeats an exact node row | Treat raw duplicates with the same OrganizationId and OrganizationName as one logical identity. Only multiple distinct logical identities are ambiguous. |
| A named top organization is selected for hierarchy security | Resolve it through organizationTreeNodesLOV using the resolved TreeVersionId. Do not treat organizationsLOV as proof that it belongs to the selected tree. |
| A selected Organization Tree needs a top-organization choice | Use browse_organization_tree_nodes_from_lov to present effective, distinct node candidates from its TreeVersionId, then require an explicit selection. |
| A hierarchy profile CSV requires top-organization classification | Resolve the selected hierarchy node through organizationsLOV using exact name, active status, and effective date; require its ID to match the hierarchy-node ID. |
| The organization tree changes | Re-resolve the selected top organization against the replacement tree's TreeVersionId before generating the CSV package. |
| A CSV package is about to be prepared | Show a pre-import resolution preview containing the tree code, name, version, structure, status, top-organization name and ID, classification code and name, effective date, raw exact-row count, and distinct logical-match count. This is lookup preflight only, not post-import REST verification. |
| An FSM task CSV export is used as a package baseline | Inspect ASM_SETUP_CSV_METADATA.xml through verify_fsm_task_csv_metadata. Treat COMPLETED_WARNINGS as requiring warning review, not as successful baseline evidence. |
| An Organization Security Profile CSV package is prepared | Use resolve_organization_security_profile_csv_context and generate rows only through its template-derived member, header, mapping, and linkage outputs. Use template-derived ViewInstanceName and GroupingKey values when available; otherwise use OrgSecurityProfileMigration with the Org Security profile name for PER_ORG_SECURITY_PROFILES.csv, OrgSecurityProfileOrgMigration with Org Security profile name,Organization Name,Organization Classification Name for ORA_PER_ORG_SEC_PROFILE_ORGS.csv, and OrgSecurityProfileClassMigration with Org Security profile name,Classification Name for ORA_PER_ORG_SEC_PROFILE_CLASSES.csv. Retain ASM_SETUP_CSV_METADATA.xml byte-for-byte unchanged. |
| A lookup endpoint is selected | Use the standard /hcmRestApi/resources/11.13.18.05 LOV resource. Do not retry the older /hcmRestApi/rest/rv: route as a fallback. |
