# Position Security Profile CSV Dependency Readiness

The official task template contains three CSV objects and one ASM metadata file. Preserve `ASM_SETUP_CSV_METADATA.xml` byte-for-byte from the downloaded template package. The ASM metadata identifies the PositionSecurityProfileMigration batch and the object XML nodes that determine the object-specific ViewInstanceName; GroupingKey is the exact parent profile Name.

## Required Dependency Order

| Sequence | Dependency | What Must Happen |
|---|---|---|
| 1 | Official task template | Export and retain the current task template with PER_POSITION_SECURITY_PROFILES.csv, ORA_PER_POS_SEC_PROFILE_POSITIONS.csv, ORA_POSITION_SECURITY_PROFILE_AOR_SCOPE.csv, and unchanged ASM_SETUP_CSV_METADATA.xml |
| 2 | Existing profile identity | For an update, resolve the existing PositionSecurityProfileId before preparing the parent or child CSV rows |
| 3 | Profile identity and proposed Name availability | For a rename, retrieve the current profile by ID and require its Name to equal the supplied old Name. Then require zero exact matches for the proposed new Name. An unchanged proposed Name follows the update route. |
| 4 | Security lookup values | Resolve each supplied responsibility type, scope of responsibility, hierarchy type, PosHierarchyTreeStructCode, PosHierarchyContent, top-position selection, YES_NO, and INCLUDE_EXCLUDE code through Manage Common Lookups |
| 5 | Position identity | When PositionName or TopPositionName is supplied instead of its identifier, resolve the unique PositionId through positionsLov before using the position attribute |
| 6 | Position tree identity | When PositionTreeName is supplied instead of PosHierarchyTreeCode, resolve the unique TreeCode through hcmTreesLOV before using the hierarchy tree attribute |
| 7 | Organization security profile identity | When BusinessUnitSecurityProfileName or DepartmentSecurityProfileName is supplied without its identifier, resolve the corresponding security profile ID through organizationSecurityProfilesLOV before using the profile attribute |
| 8 | CSV context | Resolve one ViewInstanceName and one GroupingKey for the profile package before creating any parent or child CSV row |
| 9 | Parent profile row | Use the resolved security lookup values, existing identity when updating, and CSV context in PER_POSITION_SECURITY_PROFILES.csv |
| 10 | Child rows | Copy the exact resolved CSV context and parent profile identity into each applicable position-list or AOR-scope child row |
| 11 | Immutable import | Build the CSV ZIP from the current template, obtain approval of the exact preview, submit one task-level import through core.data-loader, and verify its process log |

## Dependency Classification

| Result Category | When Used | Can Run Lookup/Create? |
|---|---|---|
| Satisfied | The official template package is present and its ASM metadata is unchanged | No |
| Lookup | A supplied security-profile code must be validated through its designated Manage Common Lookups lookupType | Yes |
| Lookup | ViewInstanceName or GroupingKey must be resolved from an approved source | Yes |
| Verify | A child CSV row is added and must match the parent CSV context | No |
| Blocked | The Fusion template metadata is missing or altered, or a row has a missing or inconsistent migration view or grouping key | No |
