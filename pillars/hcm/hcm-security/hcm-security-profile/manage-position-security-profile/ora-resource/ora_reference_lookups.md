# Position Security Profile Reference Lookups

Execute every documented Fusion REST call in this file through
`core.fusion-api.rest-api-client`; do not issue a direct REST request. All GET
paths below are read-only lookups described by the developer-supplied Position
Security Profiles REST describe response. The
`get_position_security_configuration` POST is an explicitly named
configuration-retrieval lookup; it is distinct from any profile create, update,
or import operation.
Replace `{fusion_environment_host}` and `{version}` at runtime with the live
Fusion environment host and active REST API version.

## Lookup Execution Rules

| Situation | What Happens |
|---|---|
| An existing profile is identified | Use only the GET item operation declared by the describe response; do not mutate the profile during lookup |
| Configuration settings are needed | Send a read-only POST to getConfigInformation with Content-Type: application/vnd.oracle.adf.action+json. Do not treat the lookup as approval for a create, update, or delete operation. |
| Position configuration is returned | Use PositionDelegationEnabled only to determine whether hierarchy delegation is available with position hierarchy content; use PositionHierarchyFlag and PositionTreeFlag to determine whether the customer uses the corresponding hierarchy configuration. Do not infer an unavailable configuration. |
