## Lookup Execution Rules

| Situation | What Happens |
|---|---|
| REST capability evaluation | Run only after the environment release gate permits capability evaluation. Use core.data-loader to confirm one exact usable current timeLayoutSetsV2 registration and metadata workbook. Never infer capability from the static task manifest, a prior workbook, or a release label. |
| Read-only lookup | Use approved REST access and retain sanitized evidence and match count. |
| Default totals action | Send {} with Content-Type application/vnd.oracle.adf.action+json as a standalone read-semantic POST; do not include it in an ADF batch or retry an unusable response. |
| Default fields action | Send exactly the selected consumer-set code and Project Team Membership flag as a standalone read-semantic POST. Link every returned field row to the new Time Entry Layout, preserve the returned template ID, name, label, and description, and set DisplaySequence from 1 in response-row order; do not retry an unusable response. |
| Button Set and Button resolution | Persist `webClockButtons.ButtonSetId` from `timeCardFieldsLOV.TimeCardFieldId`. Use only `TimeCardFieldAlternateNameId` in the dependent `webClockButtonsLOV?q=ButtonSetId=<alternate ID>` request. Persist the exact resolved `ButtonId`, `ButtonName`, `EventCode`, and `EventMeaning` in the Web Clock button row. |
| Opaque identity needed | Follow returned canonical link; do not construct it. |
| Time Layout Set criteria search | Retrieve every collection page before comparing. Evaluate every supplied business attribute, including supported child attributes obtained through returned canonical or child links. A supplied Name uses case-insensitive contains matching; every other supplied attribute uses normalized exact business-value comparison. |
| Create duplicate decision | Search exact Name, then partial Name. Only when neither name search finds a candidate, search with every supplied non-Name attribute. If a candidate meets every applicable condition, present it and ask whether to use it or create a new layout. |
| Zero or multiple matching candidates | State when no candidate meets all supplied conditions. Show all matching candidates and request selection when multiple candidates meet them; stop before preview or import until selection is complete. |
| Common Lookup needed | Route through Time and Labor Common Manage Common Lookups and pass lookupType ORA_HXT_LAYOUT_SET_BUTTON_SEQ unchanged to manage-lookups. |
