## Lookup Execution Rules

| Situation | What Happens |
|---|---|
| REST capability evaluation | Run only after the environment release gate permits capability evaluation. Use core.data-loader to confirm one exact usable current timeConsumerSets registration and metadata workbook. Never infer capability from the static task manifest, a prior workbook, or a release label. |
| Direct read-only lookup | Use repository-approved authentication and the selected shared REST client; retain only sanitized request evidence, match count, and mapped values. |
| Criteria search and duplicate check | Retrieve every page before comparing. For search and update, require every supplied parameter to match, with a case-insensitive contains comparison for supplied Name. Before preparing or submitting a create, check exact Name, then partial Name, then—only when neither matches—compare every applicable user-supplied parent and configuration parameter against existing records and retrieve complete candidate details as needed. A case difference must not hide a name match. |
| Existing Consumer Set update | Resolve the selected candidate through search_time_consumer_sets_by_criteria before preparing an update; retain the returned identity privately and use the complete current record as the preservation source for unchanged parent values and configurations. |
| Create duplicate decision | When the exact-name, partial-name, or equivalent-parameter check finds a candidate, show the existing Consumer Set's business values and wait for the user's choice to use it or create a new Consumer Set. Do not prepare, submit, or create anything until the user chooses. |
| Time Category lookup | Use the documented timeCategoriesLOV collection and retain the single exact TcatName match with its returned TcatId; do not use a sample ID, static consumer value, or partial match. |
| Detail lookup returns 401 or 403 | Classify as authentication or authorization failure; do not treat the selected configuration as absent. |
| An opaque returned key is needed later | Retain it privately; do not construct or expose it from a name, consumer code, or payload sample. |
