## Lookup Execution Rules

| Situation | What Happens |
|---|---|
| A source row supplies a Time Category | Resolve its name or search term through resolve_time_category using the shared Fusion REST client. Use TcatCd for the FSM source row, not TcatId. A separate Time Categories export is not required solely for this lookup; the fresh Time Allocations export remains required for FSM preparation. |
| The data-source response has ImplementationType FORMAT_VALUE_SET | Do not call ValuesList. Pass AttributeType, ValueDataType, Precision, Scale, and all non-null minimum and maximum fields to input validation. |
| The data-source response has ImplementationType DEPENDENT_VALUE_SET, INDEPENDENT_VALUE_SET, TABLE_VALUE_SET, or VIEW_OBJECT | Use find_time_attribute_value when the user supplies a value or search term. |
| The data-source response has another or blank ImplementationType | Stop before preview and report the unsupported or missing ImplementationType; do not infer a value contract. |
| A ValuesList page has hasMore true | Increment offset by the returned limit and continue until hasMore is false; do not treat a partial page as the complete result set. |
| ValuesList returns multiple rows | Present the returned fields for all matches and prompt for one Code; duplicate Value labels remain separate choices. |
