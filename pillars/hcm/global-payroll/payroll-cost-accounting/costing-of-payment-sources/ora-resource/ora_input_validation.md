# Costing of Payment Sources Search and HDL Input Validation

Search is an independent read-only operation and also the discovery phase of a
requested HDL Create/Update/End Date. Validate search inputs before asking for HDL keys,
accounts, an archive, or upload approval. A selected search row does not by
itself satisfy the later HDL template contract.

Apply the CostInfoV3 mappings below directly to the requested business choices.
