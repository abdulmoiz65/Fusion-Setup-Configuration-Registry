# Payroll Components Reference Lookups

## Read-Only Boundary

All Fusion paths in this file are relative to the authenticated target host.
Product REST is GET-only for this task. Complete pagination before declaring a
complete set or no match. Match numeric IDs exactly and business labels
case-insensitively after trimming. Never select the first row silently.

Use `Accept: application/json` and `REST-Framework-Version: 9` for collection
and LOV reads. Current response `self` and child links are authoritative when
present. If they are absent, instantiate only a route template explicitly
registered below, using an operation-local `DeductionTypeId` revalidated
against the component code and LDG in the same request. Never accept a
user-supplied or cached ID for that substitution, and never synthesize any
other path. Numeric IDs and links remain operation-local internal values.

## Lookup Execution Rules

| Situation | What Happens |
|---|---|
| An omitted required choice has 20 or fewer eligible values | Present the complete sorted business-label list and require a selection. |
| An omitted required choice has more than 20 eligible values | Ask for a business search term and present at most 20 sorted contains matches per page. |
| A filtered search has zero matches | Keep collecting and invite another term; do not declare global NOT_FOUND until the full source-backed set was searched. |
| A user supplies an exact unique business label | Resolve it through the declared lookup; never replace it with a cached ID. |
| A request value is inserted into a finder or ADF q expression | Escape a single quote as two single quotes and URL-encode the value; never concatenate an unescaped value. |
| A lookup or link was resolved for another operation or environment | Discard it and resolve again. |
| A current parent response omits self or child links | Use only the registered expanded overview or direct child-collection route with the same-operation verified parent identity; never invent another path. |
| An overview-only reference review returns a present empty direct array or present empty items array in DeductionContextUsageRest | Report zero current references; do not treat the empty collection as missing. |
| A read-only reference review returns one or more child rows | Resolve every context and journey to its business label, normalize Sequence, and report Display in Overview as Yes or No; never display ContextId, raw T, C, or D usage codes, or raw NavigationUse. A Calculation Card Reference label identifies only the family unless another registered resolver supplies card details. |
| Reference Child Create duplicate proof or reconciliation is required | Use the completely paginated child-collection route even when an expanded overview was already read. |
| Pagination or returned keys are incomplete | Return CATALOG_MISMATCH, stop task validation, and do not reach the core approval stage. |
