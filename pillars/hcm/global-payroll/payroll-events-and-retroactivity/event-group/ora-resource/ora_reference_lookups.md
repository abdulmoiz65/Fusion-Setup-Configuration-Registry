| A display name must map to a code or ID | Resolve exactly one value; do not put an unresolved display value in a code or ID field. |
| Request path, requested fields, or match rule is TBD | Stop before claiming lookup or production-load readiness. |
| A resolved reference is reused in the same preparation | Reconfirm LDG compatibility and effective-date compatibility where the selected component is dated; do not carry it to a different load by assumption. |
