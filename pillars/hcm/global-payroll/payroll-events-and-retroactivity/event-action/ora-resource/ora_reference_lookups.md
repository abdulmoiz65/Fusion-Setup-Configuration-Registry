## Lookup Execution Rules

| Situation | What Happens |
|---|---|
| A source provides a valid confirmed code or ID | Reuse it in the operation after target applicability is established; do not repeat name resolution without need. |
| A source supplies only a display name | Resolve exactly one target code or ID using the approved contract; never put an unresolved name in an ID or code column. |
| A lookup path, request fields, or authority is TBD | Stop the affected branch as authoring incomplete; no browser, REST, APEX, or repository shortcut is implied. The current compiler may still mark the whole task incomplete. |
| A source review defines an unlisted REST resource | Require target describe and GET authorization through the routed read-only step before relying on it; merged source does not prove pod deployment. |
| HCM Groups LOV returns only GroupName and GrpId | Do not equate either field to an HDL group code; code-only Criteria remains blocked until an authoritative code mapping and target column are confirmed. |
| A lookup returns zero or multiple matches | Report the field and supplied value; stop without choosing a match. |
| A resolved name is needed for display | Reuse a returned denormalized name if available; otherwise use an approved lookup or report that display name is unresolved. |

## Sources and Remaining Lookup Gaps

- Oracle HCM REST [Legislative Data Groups LOV](https://docs.oracle.com/en/cloud/saas/human-resources/farws/op-legislativedatagroupslov-get.html) documents Name, LegislativeDataGroupId, and LegislationCode.
- Oracle HCM REST [HCM Groups LOV](https://docs.oracle.com/en/cloud/saas/human-resources/farws/op-hcmgroupslov-get.html) documents GroupName and GrpId, but no group code or LDG scope field.
- Oracle HDL [Event Action loading overview](https://docs.oracle.com/en/cloud/saas/human-resources/fahbo/overview-of-loading-event-actions-and-event-action-groups.html) publishes five EventActionTypeCode values; it does not document a target type-code REST LOV.
- [OraReview Event Action REST](https://orareview.oraclecorp.com/178810242/diff/178921315/178921339) defines the unlisted payrollEventActions resource and its children. Its [view object](https://orareview.oraclecorp.com/178810242/diff/178921315/178921344) exposes EventActionId, BaseName, EventActionTypeId, effective dates, and LDG scope.
- [OraReview Event Group REST](https://orareview.oraclecorp.com/178217686) establishes the group resource; the later [merged Event Group resource definition](https://orareview.oraclecorp.com/178810242/diff/178921315/178921338) includes groupActions. Check target deployment before use.
- Remaining unresolved contracts: target EventActionTypeCode-to-EventActionTypeId authority; HCM Group code-to-GrpId mapping and accepted Criteria HDL column; target confirmation that BaseEventGroupName is the HDL EventGroupCode. The first two retain explicit TBD blockers; the last is a runtime metadata gate.
