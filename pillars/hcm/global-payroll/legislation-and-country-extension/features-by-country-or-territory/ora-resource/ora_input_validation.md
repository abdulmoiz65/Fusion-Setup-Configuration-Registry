# Features by Country or Territory Input Validation

Validate runbook-supplied inputs and output shape for Search, Create (Add), Update, Delete, and UPSERT. The invoking runbook declares preparation, final pre-approval validation, or verification; this file does not execute a loader. FBCT.VALIDATE_INPUT initially checks supplied shape and availability of the inputs needed by the declared resolvers. Lookup output and evidence requirements apply after the declared read completes and dependencies evaluate; they are not prerequisites for entering FBCT.RESOLVE_REFERENCES. Business decisions belong to ora_design_enforcement.md, default and preservation semantics to ora_defaulting_rules.md, and all lookup mechanics to ora_reference_lookups.md.
