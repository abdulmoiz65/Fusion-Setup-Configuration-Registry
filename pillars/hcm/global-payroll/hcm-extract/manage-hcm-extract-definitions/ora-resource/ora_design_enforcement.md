# Manage HCM Extract Definitions Design Enforcement

These rules enforce source and payload boundaries before a Data Loader source artifact can be previewed or handed off for an approved live operation.

## Enforcement Order

| Sequence | Step | What Must Happen |
|---|---|---|
| 1 | Preserve task boundary | Confirm the source applies only to Manage HCM Extract Definitions |
| 2 | Preserve business-object boundary | Use only task-supported Extracts Data Loader business objects, including second-level post-create objects only in their declared phase |
| 3 | Preserve definition-only scope | Do not generate child objects unless user input supplies them or registered metadata marks them mandatory |
| 4 | Preserve preview freshness | Revalidate after source, schema, operation, or business object changes |
| 5 | Preserve approval binding | Bind approval to the exact preview, validation result, and artifact fingerprint |
