# Manage HCM Extract Definitions Input Validation

These rules validate HDL/Data Loader source readiness for Manage HCM Extract Definitions when the target business object is supported by this task.

## Required Groups

| Requirement Group | Accepted Fields | If Missing | How to Resolve | Applies When | Resolver |
|---|---|---|---|---|---|
| Task identity | Setup task name Manage HCM Extract Definitions; setup task code PER_MANAGE_EXTRACT_DEFINITION | Stop before preview | Confirm the selected setup task exactly matches Manage HCM Extract Definitions | Always | |
| Operation intent | Extract definition creation; extract block/data group creation; extract data group filter criteria creation; extract record creation; extract data element creation; extract delivery option creation; second-level post-create formula actions; existing-artifact import | Stop before preview | Ask whether the user is creating from current inputs or importing a reviewed prebuilt Data Loader source artifact only when intent is unclear | Always | |
| Minimal scratch definition input | Extract Definition Name; Extract Type; Start Date | Stop before source generation | Ask only for the missing definition name, extract type, or start date | Operation intent is extract definition creation | |
| Existing source artifact | User-supplied Data Loader source artifact for Extract Definitions | Stop before validation | Ask for the reviewed Data Loader source artifact path or content | Operation intent is existing-artifact import | |
| Data Loader business object | Extract Definitions; Extract Data Groups; Extract Records; Extract Attributes; Extract Delivery Options; Extract Generate All Formulas and Extract Compile All Formulas as second-level post-create objects | Stop before validation | Use only the registered Data Loader business object needed for the requested extract definition, block/data group, record, data element, delivery option, or post-create formula action operation | Always | resolve_extract_definitions_metadata; resolve_extract_data_groups_metadata; resolve_extract_records_metadata; resolve_extract_data_elements_metadata; resolve_extract_delivery_options_metadata; resolve_extract_generate_all_formulas_metadata; resolve_extract_compile_all_formulas_metadata |

| Conditional extract fields | Consumer; Legislative Data Group; legislative context; type-specific required fields | Stop before preview | Resolve mandatory and conditional fields from registered metadata, task-local rules, or validated lookup results | Metadata indicates the selected extract type requires extra values | resolve_extract_definitions_metadata |
| Approval binding facts | Task identity; operation; source artifact; business object; validation result; preview fingerprint | Stop before live upload or initiation | Build an approval envelope bound to the exact current preview and artifact fingerprint | Before any Fusion side effect | |

| Second-level post-create operation | DefinitionName; successful first-level load status | Stop before source generation | Generate Extract Generate All Formulas and Extract Compile All Formulas only after first-level load success and created `ExtractDefinitionId` resolution | Operation intent is second-level post-create formula actions | resolve_created_extract_definition_id; resolve_extract_generate_all_formulas_metadata; resolve_extract_compile_all_formulas_metadata |

## Dependency-Aware Validation

| Applies When | Result | Next Action | Resolver |
|---|---|---|---|
| Task name or task code does not match Manage HCM Extract Definitions and PER_MANAGE_EXTRACT_DEFINITION | Blocked | Refuse task execution and reroute to the correct setup task | |
| Business object is not one of the task-supported Data Loader objects | Blocked | Refuse Data Loader validation, packaging, upload, and initiation | resolve_extract_definitions_metadata; resolve_extract_data_groups_metadata; resolve_extract_records_metadata; resolve_extract_data_elements_metadata; resolve_extract_delivery_options_metadata; resolve_extract_generate_all_formulas_metadata; resolve_extract_compile_all_formulas_metadata |
| Scratch creation includes sections or attributes not returned by live metadata for the selected business object | Blocked | Regenerate from live metadata before preview | resolve_extract_definitions_metadata; resolve_extract_data_groups_metadata; resolve_extract_records_metadata; resolve_extract_data_elements_metadata; resolve_extract_delivery_options_metadata; resolve_extract_generate_all_formulas_metadata; resolve_extract_compile_all_formulas_metadata |
| DAT source is used and filename stem, METADATA discriminator, or data-row discriminator differ | Blocked | Align DAT filename stem, METADATA discriminator, and data rows to the registered top-level discriminator | resolve_extract_definitions_metadata |
| Source, schema, operation, or business object changes after validation | Stale | Revalidate before preview or approval | resolve_extract_definitions_metadata |
| Preview has changed since approval was granted | Stale | Regenerate preview and request fresh approval for the exact preview and fingerprint | |
| Live creation request includes multiple DAT sources but upload preview is not bound to one combined ZIP | Stale | Regenerate the upload artifact as one ZIP containing all validated DAT files, then preview that artifact | |
| Second-level post-create source is generated before first-level load success or without a resolved `ExtractDefinitionId` | Blocked | Wait for first-level load success, resolve the created extract definition by `DefinitionName`, then generate the second-level DAT set | resolve_created_extract_definition_id; resolve_extract_generate_all_formulas_metadata; resolve_extract_compile_all_formulas_metadata |
