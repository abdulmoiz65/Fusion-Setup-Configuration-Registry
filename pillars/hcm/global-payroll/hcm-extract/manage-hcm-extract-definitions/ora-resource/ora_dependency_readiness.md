# Manage HCM Extract Definitions Dependency Readiness

These rules keep Data Loader source generation and import readiness bound to the registered Extract Definitions business object and the current task metadata.

## Required Dependency Order

| Sequence | Dependency | What Must Happen |
|---|---|---|
| 1 | Task identity | Confirm Manage HCM Extract Definitions and PER_MANAGE_EXTRACT_DEFINITION |
| 2 | Operation route | Select scratch extract definition creation, extract block/data group creation, extract record creation, extract data element creation, extract delivery option creation, second-level post-create action generation, or existing-artifact import |
| 3 | Data Loader metadata | Resolve the registered Extracts Data Loader metadata before generating, validating, packaging, uploading, or initiating |
| 4 | Lookup values | Resolve Extract Type and any required Consumer, block user entity, DBI, record type, process code, data element DBI, delivery option metadata, or type-specific lookup values through task-declared LOV resolvers |
| 5 | Source artifact | Validate source artifact shape, discriminator, fields, required values, DateStart format, resolved lookup codes, child-row semantic readiness, and schema compatibility |
| 6 | Upload readiness | Verify the upload ZIP path/name, fingerprint, uploader envelope shape, and parser-compatible JSON before requesting approval |
| 7 | Preview and approval | Show normalized preview and require approval bound to the exact upload-ready artifact fingerprint |

## Dependency Classification

| Result Category | When Used | Can Run Lookup/Create? |
|---|---|---|
| Satisfied | Required value or artifact is present and validated against current metadata | No |
| Lookup | A documented read-only resolver can fill a required value | Yes, lookup only |
| Verify | A current user selection, preview, or approval must be checked | No |
| Blocked | Mandatory or conditional dependency is missing, stale, ambiguous, or undocumented | No |
| Create with Approval | A live Data Loader operation is requested after validation, preview, and current approval | No, hand off only to the declared Data Loader importer |
