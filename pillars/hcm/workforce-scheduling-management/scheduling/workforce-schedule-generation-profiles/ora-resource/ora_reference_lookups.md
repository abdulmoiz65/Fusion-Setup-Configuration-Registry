## Lookup Execution Rules

| Situation | What Happens |
|---|---|
| Exact match is found | Use the returned identifier or code. |
| No exact match or multiple matches | Show ranked candidates; do not select the nearest match automatically. |
| A Common Lookup code is required | Invoke Workforce Scheduling - Common - Manage Common Lookups with the resolver's documented lookupType only. Retain provider-returned eligible LookupCode values and Meaning as evidence; the provider owns lookup resolution and Common Lookup behavior. |
| A request contract is TBD | Block the applicable operation until a source-proved contract is added. |
