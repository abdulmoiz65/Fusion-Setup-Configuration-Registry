## Lookup Execution Rules

| Situation | What Happens |
|---|---|
| Read-only lookup | Use repository-approved authentication and the shared REST client; record the target, method, relative path, normalized inputs, requested fields, result count, exact match, and redacted request identifier |
| Active workflow context | Inspect the active task-run context before treating a Shift request as standalone. Only a retained parent task whose applicable resources explicitly name Enterprise Shifts as a prerequisite is a dependent workflow. After verified Shift completion, prompt to resume that one named parent. With no retained parent, return the standalone Shift summary and no resume prompt. Do not treat a general business-use statement as a dependency. |
| Finder parameter | For findByNameOrCategory, construct one finder value in the form findByNameOrCategory;pKeyword=<raw Shift Name> and pass it as the finder query parameter. The shared REST client URL-encodes the complete value exactly once. Do not send pKeyword as a separate query parameter and do not pre-encode its value. |
| Category meaning supplied | Use the meaning only to locate candidates; persist and pass the exact LookupCode after one exact result |
| Shift category lookup | Invoke hcm.workforce-scheduling-management.workforce-scheduling-common.manage-common-lookups with lookupType ORA_HTS_ENT_SHIFTS_CATEGORY only. Retain only its verified enabled provider-returned LookupCode for Enterprise Shifts; do not send LookupCode or Meaning as provider input. |
| Authentication or authorization failure | Stop; a 401 or 403 is not evidence that the shift or category is absent |
| Approved asynchronous request accepted | Immediately start the task-authorized Data Loader status request. If it reports in progress, automatically issue follow-up status requests to a terminal result. Do not require separate user status approval. Do not report final success before the documented read-back comparison passes. |
| Final verification fails | Preserve the terminal status and sanitized diagnostic or comparison result. Do not retry upload, initiation, create, update, import, or load automatically. |
