# Manage Positions Input Validation

## Purpose

Defines required inputs, conditional requirements, field checks, and validation routing for Manage Positions.

## Table of Contents

- Required Groups
- Dependency-Aware Validation
- Field Validation
- Synthetic Examples
- Task Nodes

Shared reuse: `core.data-loader` owns immutable ZIP preview, approval, import, and load-status behavior; this resource owns only Manage Positions input rules.

## Dependency-Aware Validation

| Applies When | Result | Next Action | Resolver |
|---|---|---|---|
| The current positions contract is missing or unusable | Unsupported | Stop until the resolver mapping is restored | inspect_positions_contract |
| An existing Position does not resolve exactly once | Missing | Provide one exact PositionCode or PositionName | find_manage_positions |
| A create PositionName, or supplied PositionCode, matches an existing Position | Invalid | Stop the duplicate create | find_manage_positions |
| A Business Unit is unresolved, inactive, or ambiguous | Invalid | Correct the Business Unit | resolve_position_business_unit |
| A Department is unresolved, inactive, ineffective, or ambiguous | Invalid | Correct the Department or effective date | resolve_position_department |
| A Job is unresolved, inactive, ineffective, or ambiguous | Invalid | Correct the Job or effective date | resolve_position_job |
| A supplied Location is unresolved, inactive, ineffective, or ambiguous | Invalid | Correct the Location or effective date | resolve_position_location |
| A supplied lookup, foreign reference, context, or segment is unresolved or ambiguous | Invalid | Provide one exact supported value or complete business key | resolve_position_field_value |
| A requested child target resolves to zero or multiple rows | Invalid | Provide one complete child key; collection reads may return zero or all bounded matches | read_position_section_rows |
| Delete mode is absent or ambiguous | Invalid | Choose zap or effective-split; never infer purge intent from the word delete |  |
| The selected effective-split row is absent, ambiguous, or marked FirstSplitFlag=true, or no immediately preceding row exists | Invalid | Choose one exact non-first EffectiveStartDate | resolve_position_delete_history |
| Delegate Position evidence does not match its own Business Unit | Invalid | Resolve the delegate Position and its Business Unit together as of the target date | resolve_delegate_position |
| Funding Position evidence does not match its own Business Unit | Invalid | Resolve the funding Position and its Business Unit together as of the target date | resolve_funding_position |
| GradeCode and GradeSetCode do not resolve together exactly once on the target date | Invalid | Correct the valid Grade business key or effective date | resolve_valid_grade |
| Final dependency evidence is absent, unresolved, ambiguous, ineffective, or differs from the prepared content | Invalid | Correct the evidence or content and rerun the applicable dependency rules |  |
| A final serialized edit row differs from its fresh current-row evidence, omits an existing-row key, contains a key for a new row, or would create an overlapping effective range | Invalid | Rebuild the edit source and repeat the final serialized edit review | read_position_section_rows |
| Final section row counts differ from the complete source snapshot | Invalid | Restore missing rows, remove invented rows, or repeat the paginated source read | read_position_section_rows |

## Synthetic Examples

These test-only examples use synthetic values. The canonical expected outcome is a bounded, reviewable loader artifact or a fail-closed validation result; they are not execution payloads.

| Example | Request | Expected Result |
|---|---|---|
| Supported zap | Delete synthetic Position POS-EX-001 with mode zap | One Position DELETE row; no MERGE, children, or split directive |
| Supported split | Delete synthetic POS-EX-001 split beginning 2026/06/01 with mode effective-split | One bounded MERGE from the predecessor start through the selected end and SET PURGE_FUTURE_CHANGES Y |
| Negative first split | Delete the first effective split | Invalid; stop before authoring |
| Ambiguous mode | Delete POS-EX-001 without a delete mode | Invalid; request zap or effective-split |
| Recovery | History page is incomplete | Stop, refresh every PositionHistoryDef page, and rebuild only after exact evidence is available |
