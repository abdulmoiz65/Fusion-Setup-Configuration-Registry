## Lookup Execution Rules

| Situation | What Happens |
|---|---|
| A general field declares a lookup type | Use common/manage-common-lookups only when no EFF segment-specific contract applies. |
| A supplied Worker Union EFF segment declares a value set | Use its describe-declared contract; show the display value and write the typed stored value. |
| Associated Bargaining Units must resolve | Use only the resolved EFF segment value set. |
| An Associated Bargaining Units value has no match | Ask whether to create it. Only after agreement, invoke hcm.global-human-resources.global-human-resources-common.manage-common-lookups with LookupType `BARGAINING_UNIT_CODE` and the supplied value as LookupCode; follow that task through verified creation, then re-resolve the segment. If that task stops or fails, preserve its result and stop. Do not prepare the Worker Union preview first. |
| Worker Union details are requested | Follow every returned EFF context link, show Not configured for an empty context, and never construct a child path. |
| A lookup requires authentication | Use core.auth.fusion-oauth-authentication. |
| A read or mutation precheck runs | Execute applicable reference_lookup nodes through core.fusion-api.rest-api-client before source preparation; do not use core.data-loader, core.data-loader.task-rest, or ora_rest_execution.md for the read. |
| An existing date-effective target or reference is resolved as of a requested date | Accept the row when EffectiveStartDate ≤ requested date ≤ EffectiveEndDate; do not require equal start dates. |
| A Worker Union EFF context or segment is requested or supplied | Resolve it from the current ORA_PER_UNION polymorphic describe. For an existing Worker Union, read the exact parent and envelope without `onlyData=true` and follow the matching returned child link from `links` or `@context.links`. |
| Multiple Worker Union EFF rows are requested | Resolve every requested context and segment before returning resolved; do not pause between rows. |
| Worker Union EFF values are supplied | Resolve every value-set-backed segment and validate every supplied Additional Information code before returning valid. |
| An exact target or reference is required | Accept exactly one eligible result; stop on zero or multiple results. |
| A delete-effective-split target resolves exactly once | Return delete_resolved and run Worker Union history before EFF resolution. |
| A collection is requested | Use bounded limit and offset pagination and follow hasMore or the next page only to the declared bound. |
| Worker Union history is requested | Execute the history finder once and evaluate its returned items; do not apply generic collection pagination. |
| An eligible delete row is presented | Show Union name, status, and effective period; state that complete deletion is unsupported and offer date-effective deletion of this row. Keep FirstSplitFlag and internal identifiers hidden. |
