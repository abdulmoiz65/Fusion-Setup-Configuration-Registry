For an individual create, collect only Name, Template Type, the applicable Campaign Purpose or Email Type, and Template. Generate the technical FSM parent and dependent values from those selections. Resolve the selected Basic, Blank, or MultiColumn row from the mapping above, copy its complete DesignMetadata and the listed metadata fields, replace only the parent MessageDesignCode, and preserve Subject as optional. The mapped SHA-256 identifies the curated literal baseline and must match the selected documented metadata; a fresh target export is not required to select or validate that default. The editor value is ORA_ADVANCED. These defaults generate the entire dependent CSV payload only when the user does not provide dependent CSV files. They do not replace supplied dependent files: supplied partial, invalid, or incompatible files block preview. Exported cross-environment parent rows are preserved exactly. When a complete cross-environment package contains both existing and new templates, no default selects the scope: the user must choose Replace existing templates or Import only new templates.
