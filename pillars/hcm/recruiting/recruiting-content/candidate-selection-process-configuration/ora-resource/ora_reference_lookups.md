## Lookup Execution Rules

| Situation | What Happens |
|---|---|
| Export baseline is absent, invalid, stale, or lacks a required dictionary | Stop before uniqueness or custom identity resolution; do not substitute a non-export source |
| Process-code comparison finds a case-insensitive match that raw-exact comparison does not | Treat it as a process-code uniqueness conflict; disclose both counts and raw values |
| Custom phase or state collision check compares a Name | Outer-trim both names and reject an exact case-sensitive export match; do not case-fold or apply a Unicode rewrite |
| Candidate-status lookup compares a Name | Outer-trim both names and require an exact case-sensitive match; do not case-fold or apply a Unicode rewrite |
| CSP_PROCESS_CODE is omitted | Outer-trim Name, uppercase it, and replace every whitespace character with `_` before uniqueness validation |
| CSP_SUBPROCESS_CODE is needed | Generate it only after the fresh export proves the exact CSW_ plus 32-uppercase-hexadecimal pattern; check every generated value against input-list and export collisions |
| SettingCode or SettingItemCode is needed | Generate it only after the user-authorized successful custom-phase package proves its exact prefix and 32-uppercase-hexadecimal pattern and the fresh export supplies the raw collision dictionary; check every generated value against input-list and export collisions |
| PHASE_DEFINITION_CODE or numeric STATE_DEFINITION_CODE is supplied | Treat it as an Oracle-generated raw numeric string; reject scientific notation or any client derivation |
| A seeded phase or state is referenced | Use OFFER, HR, REJECTED_EMPLOYER, or WITHDRAWN_BY_CANDIDATE verbatim |
| A translation source language is supplied or omitted | Use only the custom-package `US` profile; do not invoke a live language lookup or invent a different language |
| A 401 or 403 occurs in an approved lookup workflow | Classify as authentication or authorization failure, not no-match; stop without retrying a write |
