# WhatsApp Notification Template Library Dependency Readiness

Resolve only the documented read-only dependencies. Fusion template, language, category, and token values use live lookups; active user session language uses the named local session source. Dependency readiness does not authorize a Data Loader operation.

## Required Dependency Order

| Sequence | Dependency | What Must Happen |
|---|---|---|
| 1 | Request input | Safely extract any readable user-provided format, preserve source locators, and atomically validate every normalized structured record or derive one complete natural-language proposal before any write handoff |
| 2 | Structured template-name existence | Resolve each unique structured template name across all Fusion result pages; classify an exact existing name as translation and a zero-match name as requiring base-language selection; preserve ORA_DRAFT update behavior only for explicitly base-only input |
| 3 | Structured languages | Resolve every supplied structured Language to a supported Fusion LanguageCode and Description |
| 4 | Base-language selection | For every automatically classified zero-match name group, require exactly one resolved LanguageCode or Description to match the active user session language; select that row as the base and defer the other languages as translations |
| 5 | Base-template category values | Resolve the Meta WhatsApp and Recruiting content category inputs for each selected base-template create or explicit Draft update |
| 6 | Base-template content tokens | For natural-language proposals and structured input, validate every token against the resolved Recruiting content category |
| 7 | Translation language, base template, category, and content tokens | For existing-name groups or explicit translation-only input, resolve the supported language, exactly one existing base template, and exactly one Recruiting content category, then validate every translation token against that category |
| 8 | Mixed-batch base completion | Return selected base creates and explicit Draft updates first; translations remain deferred until the owning workflow verifies successful completion of all related base Data Loader requests |

## Dependency Classification

| Result Category | When Used | Can Run Lookup/Create? |
|---|---|---|
| Satisfied | Every required dependency and mandatory token-authority validation for the selected branch returned its documented successful outcome | Lookup only; return validated mappings to the owning setup-task workflow |
| Lookup | A documented live read-only resolver has complete source values | Yes for the documented read-only lookup; no create operation |
| Blocked | A required source value, resolver contract, no-match result, or many-match result prevents a unique dependency | No; disclose the missing or ambiguous dependency and stop |
