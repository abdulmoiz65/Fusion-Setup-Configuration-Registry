# Recruiting Content Library Dependency Readiness

## Required Dependency Order

| Sequence | Dependency | What Must Happen |
|---|---|---|
| 1 | Task capability | Use only the supported Recruiting Content Library CSV task flow. |
| 2 | Active lookup values | Resolve DescriptionTypeCode through the documented category/description-type contract across every page of active values; resolve every other required lookup-coded value through the Applications Common Lookups skill and require an exact active LookupCode match. |
| 3 | Translation language values | When translations are supplied, resolve Language and SourceLang through the documented Languages LOV resolver and require exact LanguageCode matches. |
| 4 | Recruiting Booster availability | Before a Booster-only description type is created or updated by CSV import, resolve the documented feature flag and require Recruiting Booster to be enabled. This does not apply to export. |
| 5 | Optional target references | When supplied, resolve MessageDesignCode and WabaTemplateName through their documented read-only resolvers. |
| 6 | Task access | Confirm the required recruiting administration privilege is assigned. |
| 7 | Export baseline | Use a full task-native export for v1 baseline discovery and locate the requested DescriptionCode with related version and translation rows. |
| 8 | Import artifact selection | A reviewed full task-native export may be re-imported. When a reduced package is used, preserve archive structure and all non-data files unchanged and retain the requested DescriptionCode records with related version and translation records. |
| 9 | Import artifact | Review the immutable, task-native full-export or reduced CSV artifact before an import. Independently verify completeness before approving a package whose export completed with a Description.xml batch-size warning. |
| 10 | Execution approval | Obtain the selected workflow's exact target-environment approval immediately before a mutating import. |
| 11 | Result review | Review the task import status and all errors or warnings before calling an import complete. |
| 12 | Comparison review | After a successful import, compare the CSV File Package with Data in this environment and resolve any failed objects, configuration-only data, or mismatches. |

## Dependency Classification

| Result Category | When Used | Can Run Lookup/Create? |
|---|---|---|
| Satisfied | The required evidence is present and valid for the request. | No |
| Verify | The requirement must be confirmed through the documented manual or workflow gate. | No |
| Blocked | Required evidence, access, artifact, approval, or result disposition is missing. | No |
