# Error Handling — Parent, Cookie Consent, Languages, Filters, and Settings

| Situation | Required behavior |
| --- | --- |
| Parent, Languages, Cookie Consent, or requested Filters registration is missing, has the wrong context, or enables an unrelated child | Stop before source generation and correct/publish the registration. |
| Registration evidence came from a task-local or ad hoc `dataLoaderBusinessObjects` request rather than the existing core Data Loader metadata resolver | Stop as a workflow-routing defect. Re-run registration/template resolution through the core resolver; do not advise restore, publish, delete, or otherwise change the registration until that resolver returns no exact discriminator. |
| Preflight or archive generation attempts to use a prior project DAT, attribute-details workbook, or registration JSON | Stop before source generation. Fetch a fresh registration, starter DAT, and attribute-details schema through the core Data Loader resolver, then persist those responses as new run evidence. |
| Parent DAT omits `SiteNumber` | Stop. Retain it in DAT, blank it in the default combined parent row, and keep it excluded from REST. |
| Parent `SiteNumber` is mandatory on create | Stop. It is Fusion-generated. |
| Child lacks String `SiteNumber`, `ParentId=SiteNumber`, or the published child contract required by the active operation | Stop and correct/publish the registration. |
| Generic live metadata reports `SiteId`, `SiteNumber`, or `RestAction` as mandatory | Continue. This is not a parent create-input failure: keep generated `SiteId` and `SiteNumber` blank, and supply `RestAction=POST`. Validate required caller inputs only against explicit `MandatoryOnCreate`. |
| Starter DAT has only `SiteId`, `SiteNumber`, `RestAction`, and `SiteCode`, while matching live attribute-details expose the published parent create fields | Continue. Classify the DAT as a routing skeleton, construct the full parent header from the live attribute-details schema, and retain the starter DAT only for registered sections and technical fields. Do not request a registration republish. |
| Default combined archive lacks the selected language set, contains a duplicate language, omits `DefaultLang`, has a populated parent or child `SiteNumber`, generated ID, nonblank Cookie Consent business field, invalid Filter mapping, a blank child `SiteCode` where the header contains that field, or mismatched cardinality | Stop and regenerate the archive. A same-load generated value must not be invented; child `SiteCode` is a required routing value, not a generated value. |
| Any data row is missing its exact `MERGE|<section>|` prefix, has a blank/different second cell, or has no preceding matching `METADATA|<section>|` line | Stop before preview. Rebuild the source from section-name/header/value maps; do not submit an archive with `MERGE||...`. |
| Combined load creates the parent but fails any child | Record partial success. Do not resubmit the combined archive or construct an alternate recovery archive. |
| Editor cannot load Languages, or read-back differs from the approved unique language set or lacks `DefaultLang` | Record the inconsistent parent state and stop; do not add another child automatically. |
| PATCH target has zero or multiple Cookie Consent rows, a blank/mismatched `CookieId`, or no String `SiteNumber` | Stop; do not prepare a PATCH archive. |
| PATCH URL or `SiteCode`-to-`CookieId` Object User Key is missing or differs from the registration contract | Stop and correct/publish the registration. |
| PATCH source has a parent row, no business-field change, duplicate or invalid business fields, a technical-field target, `SourceRef*`, or mismatched cardinality | Stop and regenerate the child-only archive. Rebuild from the sanitized header field map; do not remove or add a delimiter by hand. |
| Cookie Consent request supplies one text value for an ambiguous collective target such as “custom labels”, “all labels”, or “cookie text” | Stop before preview. Ask for explicit field/value pairs; never fan out one value into multiple Cookie Consent fields or enable related flags implicitly. |
| Effective Cookie Consent state violates an active UI dependency (enabled consent lacks popup/accept/policy text; enabled Decline lacks its label; policy-only consent lacks its link label; enabled Preferences lacks its labels/category text; or enabled Custom category lacks enabled Preferences, label, or description) | Stop before preview. Require the missing values in the same PATCH or restore a coherent effective state; do not send a technically shaped but unusable editor configuration. |
| Existing-site operation has no exact parent, a requested Language operation uses an inactive/not site-enabled language as required, or Site Editor Copy Link lacks a valid active-target-environment `restBaseUrl`/language tag/SiteNumber | Stop before archive/result. Derive `/hcmUI` from the same `restBaseUrl` used by login, site creation, and Data Loader when it exists; request a base URL only when the active target environment has no valid configured `restBaseUrl`. Do not guess a host, pod, or route prefix. |
| Language add lacks a published `languages` child POST contract, or default/status update lacks an updateable parent field and published PATCH URL | Stop before archive generation. The web-client endpoint alone is insufficient; correct/publish the Data Loader registration and retrieve a fresh template. |
| Filters registration excludes `ObjectCtxId`, lacks `ObjectId`, lacks a requested standard business field, has a nonblank PATCH URL as its only mutation route, or an existing request duplicates the exact type/value pair | Stop before archive generation. Correct the registration for the first four cases; return an idempotent no-op for the duplicate case. Do not substitute `ObjectId` for `ObjectCtxId`, or vice versa. |
| A requested Filter value is absent from its live type-specific LOV, a display-name search has zero or multiple exact matches, a by-ID confirmation does not return the selected ID, or a Job Category is not active | Stop before preview and archive generation. Present safe live LOV choices where available and require a specific user selection; do not guess an ID/code or use a saved lookup result. |
| Generic Job Function or Recruiting Type LOV returns empty | Require a redacted request receipt proving one `finder=findByLookupType;LookupType=<type>` query parameter with `onlyData=true`, `limit=1000`, `Ora-Irc-Language: en`, and `Accept-Language: en`. If that receipt is absent or the request shape differs, classify it as a lookup-request defect; do not treat its response as availability evidence. A single fresh, correctly shaped request returning zero rows is evidence of unavailable values. |
| Language add, default-language change, activation, or inactivation does not verify by read-back, or changes an unrequested parent/child value | Record failure and do not retry without a new approved archive and known recoverable cause. |
| PATCH fails or post-load verification differs | Record the failure; do not retry without a new approved archive and known recoverable cause. |
| Settings request names an arbitrary key, duplicate key, invalid boolean/enum/order token, mode-incompatible option, or missing required text/URL | Stop before preview. Return the friendly catalog/current state and require a valid named choice. |
| Settings registration lacks `SettingId`, `SettingKey`, `SettingValue`, parent `SiteNumber` routing, a usable POST/PATCH route, or excludes `SettingId` from its DAT/key mapping | Stop before archive generation and correct/publish the registration. Do not substitute a synthetic ID or infer an arbitrary key. |
| Settings POST/PATCH would include a parent row, other child row, delete/key rename, or `/globalSettings` mutation | Stop as out of scope. Prepare only the requested persisted-parent Settings child archive. |
| Settings read-back does not match requested values or changes the parent/unrelated children | Record failure; do not retry without a new approved archive and known recoverable cause. |
