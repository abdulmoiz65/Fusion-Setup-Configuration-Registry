# Oracle Public Documentation Reference

## Purpose and use

Use this resource when a user asks what a Career Sites feature does, how to configure it in Fusion, why it behaves a certain way, or where they can read the Oracle guidance themselves. Lead with a concise, tenant-specific answer when known, then provide the most relevant official Oracle documentation link below.

These are public functional references, not a Data Loader implementation contract. Do not derive registration attributes, REST payload shape, generated identifiers, parent/child routing, or approval requirements from them. For those decisions, continue to use the fresh live registration, live LOVs, global capability result, and verified Site Editor behavior required by this skill.

## Response rules

1. Match the link to the user's actual question; do not send the whole catalog unless they ask for it.
2. State whether the answer describes documented product behavior, the current tenant's persisted configuration, or an editor default. These are different kinds of evidence.
3. If the documentation and current tenant behavior differ, report the observed tenant behavior and flag the difference. Do not change a Data Loader archive merely to conform to a public-doc example.
4. Do not claim a field, option, or capability is available just because it appears in documentation. Confirm it through the live UI/LOV/global capability or registration workflow when the user asks to act on it.
