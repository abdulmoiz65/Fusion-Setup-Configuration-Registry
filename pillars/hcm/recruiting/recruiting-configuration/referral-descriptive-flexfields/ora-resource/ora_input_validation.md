# Referral Descriptive Flexfields Input Validation

For copy, update, and disable, ask only for Segment Name when missing, then validate a fresh exact-task export for this request; if unavailable or empty, use the qualified Global fallback proposal instead of stopping; label older evidence UNVERIFIED. For new create, use a validated matching package or export fresh when absent. Follow the required-values table, confirmation, optional-values table, confirmation sequence in ../SKILL.md.

Validate only requests for Referral Descriptive Flexfields under Recruiting Configuration. This contract supports inspection, change planning, guided approved configuration, and verification for the exact Referral DFF identity.

## Dependency-Aware Validation

| Applies When | Result | Next Action | Resolver |
|---|---|---|---|
| No exact task, DFF, protected context, or required existing segment is found | MISSING | Return the missing identity and stop | |
| More than one task, DFF, context, or segment matches | AMBIGUOUS | Present the conflicting identities and stop | |
| The request targets another task, another DFF, another context, context creation, or rename or deletion of EMPLOYEE_REFERRAL | UNSUPPORTED | Reject the request and return the supported boundary | |
| The request asks to delete a segment | UNSUPPORTED | State that delete is not supported but this Referral DFF workflow supports disabling a segment—not deleting it outright; offer `PlanDisable` for the exact identified segment | |
| A required Inspect/list or unnamed-copy segment CSV export is unavailable, incomplete, corrupt, or cannot be extracted | BLOCKED | Report the export stage and exact blocker, then stop; do not debug the pod URL or fall back to direct REST or DFF APIs | |
| A Global PlanCreate export fails, times out, or contains headers without usable rows | FALLBACK_CONTRACT_REQUIRED | Validate the exact historical archive-derived contract and collect complete confirmation of the proposed Global segment. Disclose that duplicate, column, sequence, and target value-set current-state checks are unavailable before archive preview | |
| A failed/header-only export is followed by Inspect/list, Verify, or EMPLOYEE_REFERRAL scope | BLOCKED | Require a valid populated current-definition package; do not use the Global structural contract as current-state or protected-context evidence | |
| An Inspect result contains Agency Referral or another unsupported context's segment rows | INVALID | Discard the mismatched context rows; retain Global rows and rows whose verified context code is EMPLOYEE_REFERRAL and displayed context name is Employee Referral | |
| An existing value set is not identified by an exact displayed code or name, or a new value set lacks one of its required UI fields | MISSING | Ask for the exact existing selection or the next missing new-value-set field; never ask for or infer an internal identifier | |
| PlanCreate lacks a segment name | Collect interactively | Ask for the name before any other configuration input | |
| PlanCreate, PlanUpdate, or copy has a name but lacks required design values | Collect interactively | Use this request's fresh export for copy/update, or the matching package route for create. Present all required values in one table for confirmation, then optional defaults | |
| PlanCreate reaches FSM archive preparation with blank ShortPrompt or missing, nonpositive, or conflicting SequenceNumber | Collect interactively | Confirm corrected transport-required values, rebuild the archive, invalidate any prior approval, and show a new checksum preview | |
| PlanUpdate omits an existing property | Preserve | Carry forward the latest authoritative value without applying an implicit default | |
| A copy or duplicate request does not identify a source segment | Collect interactively | Show all existing supported segments from the fresh CSV export, grouped by Global and exact Employee Referral context, then ask the requester to select one | |
| A suggested copy name, code, API name, or prompt is unavailable, invalid, duplicated, or declined | Collect interactively | Propose a valid field-specific candidate and ask for confirmation; never silently truncate, alter, or reuse an identifier | |
| A new-segment request has not completed the interactive suggestion-led intake | Collect interactively | Present the next applicable prompt with two or three relevant choices and a recommended safe choice first; never move to preview or validation based only on silent defaults | |
| A proposed state-changing import or deployment lacks a current approved preview | MISSING | Return to readiness and core.data-loader approval review; a read-only task CSV export does not require mutation approval | |
| The final FSM archive can't be built or validated from an established contract | BLOCKED | Report the artifact-preparation gap and stop; do not invent filenames, headers, metadata, CSV members, or ZIP structure | |
