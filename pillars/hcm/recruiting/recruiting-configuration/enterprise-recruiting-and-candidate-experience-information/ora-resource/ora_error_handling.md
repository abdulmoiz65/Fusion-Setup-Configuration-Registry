# Error Handling

## Error Situations

| Situation | What Should Happen |
|---|---|
| No reusable export matches a section read, or its provenance is missing, ambiguous, unreadable, mismatched, or superseded | Return `refresh_required`, obtain a fresh task export through `shared.setup-export.task-level-export`, and resume reporting only after successful completion. |
| A section read explicitly requests current, live, fresh, refresh, re-export, or latest values | Do not use cached evidence; obtain a fresh task export before reporting. |
| A cached export is used for a section report | Label it as cached evidence and disclose environment, task code, ProcessId, completion timestamp, and artifact path or checksum. |
| A requested Interview Intelligence setting code or mandatory child reset code is absent or duplicated | Stop the complete change before ZIP creation; report the code and require a current valid export. Do not append, select a guessed row, or submit a partial reset. |
| An Interview Intelligence checkbox or words value is invalid | Stop and report the field, supplied value, and accepted contract without changing the package. |
| The exact same-target Recruiting Booster item GET is absent, disabled, mismatched, malformed, or cross-environment | Stop before modifying or importing any Interview Intelligence setting and report the missing top-level prerequisite. |
| The Recruiting Booster lookup remains HTTP 401 or 403 after the core REST client's one token refresh | Stop as auth/authz; verify the target-matching standard scope, OAuth client assignment, identity, and read privilege before a new login. |
| The Recruiting Booster lookup returns another HTTP, transport, timeout, or payload failure | Stop under the applicable failure class; do not substitute caller-provided, UI-only, BOSS-only, or repository-catalog evidence. |
| Interview Intelligence calendar integration readiness fails | Stop before modifying or importing loop scheduling and report that Microsoft Graph or Google Calendar availability is required. |
| Interview Companion is disabled in the final state | Disclose every mandatory child reset selected by II.ENFORCE_DESIGN, including old and new values and any conflicting child request overridden by the reset. |
| Real-time streaming is disabled in the final state while Interview Companion remains enabled | Disclose the mandatory Words per Agent Invocation reset selected by II.ENFORCE_DESIGN, including its old value, new blank value, and any conflicting words request overridden by the reset. |
| The complete final Interview Intelligence change set, including mandatory child resets, equals the exported values after II.ENFORCE_DESIGN | Report no change and do not create or submit an import ZIP. |
| Interview Intelligence package validation changes metadata or unrelated data | Reject the package and rebuild it from the current mutation export. |
| A validated Interview Intelligence package is ready | Show the target environment, task code, changed codes with old and new values, unchanged-file summary, ZIP members, and SHA-256, then hand it to core.data-loader; core.data-loader owns the final approval and submission. |
| An import is accepted | Report Processing with the ProcessId and provide the safe status-check action; do not report success from acceptance alone. |
| An import reaches a verified successful final process state | Obtain a fresh post-import export, verify requested Interview Intelligence values, mandatory child resets, and preserved unrelated data against it, and only then report the modification complete. |
| An import fails, times out, or has an uncertain outcome | Retrieve the available process status and ProcessLog, stop before retry, and do not resubmit without a corrected immutable package and a new core.data-loader approval. |
| A Microsoft Graph, Google Workspace, or Zoom modification is requested | Return `FSM_REQUIRED`; do not edit either CSV, create a ZIP, invoke Data Loader, or describe the integration as enabled. |
| A Microsoft Graph field is unavailable from CSV | Report it as unavailable from the export and direct the user to FSM; do not derive Enable Calendar Integration, Application ID, Tenant ID, or Application Password from another row. |
| Google enablement is requested | Explain that FSM must activate or verify the required privacy-policy content, complete authorization, save the configuration, and validate the integration. |
| A Zoom Client ID or Client Secret row is read | Report only whether the row is populated; never print or persist its StringValue. |
| Advanced Recruiting is disabled for an Events request | Stop before Events export, input validation, downstream setup-data validation, or import; report that Advanced Recruiting must be enabled. |
| Events Advanced Recruiting readiness is unavailable, unauthorized, unsupported, or indeterminate | Stop the complete Events request and report the observed readiness failure class; do not substitute cached, caller-provided, UI-only, or cross-environment evidence. |
| ORA_IRC_EVENTS_APPLIED_METRICS_DAYS or ORA_IRC_EVENTS_HIRED_METRICS_DAYS is missing or blank | Stop the complete Events request and ask for both mandatory values as whole numbers from 1 through 999. |
| An Events value is not a whole number | Stop the complete Events request and ask for a valid whole number from 1 through 999; reject decimals, signs, characters, and mixed text and numbers. |
| An Events value is below the minimum | Stop the complete Events request and ask for a valid whole number from 1 through 999; zero and negative values are invalid. |
| An Events value is above the maximum | Stop the complete Events request and ask for a valid whole number from 1 through 999; values greater than 999 are invalid. |
| One Events setting is valid and the other is missing or invalid | Reject the complete pair; do not save, export, invoke downstream setup-data validation, or import either Events setting. |
| The configured Site-level ORA_IRC_CANDIDATE_AUTHENTICITY_AGENT_ENABLED value is N, blank, or missing | Stop before Candidate Authenticity input validation or import and tell the user that Candidate Authenticity must be enabled before its settings can be updated. Do not update the profile option as a side effect. |
| The Candidate Authenticity Site-level profile-option value is unavailable or cannot be read | Stop before Candidate Authenticity input validation or import, report the lookup failure class without exposing sensitive data, and tell the user that Candidate Authenticity must be enabled before its settings can be updated. |
| Endpoint URL, Access Token URL, or Scope is missing or blank | Identify every invalid field, ask the user to provide a valid nonblank value, and reject the complete three-setting request. Do not create or import any Candidate Authenticity setting row. |
| An unsupported Candidate Authenticity setting is supplied | Reject the complete request. Do not silently omit the unsupported setting and continue with a partial package. |
| Candidate Authenticity Client ID or Client Secret is supplied | Reject the input using a generic protected-credential refusal. Do not read back, retain, log, preview, diagnose, output, or place the supplied value in an import artifact; direct credential maintenance to the FSM setup UI. |
| A Candidate Experience preview or modification has no current-workflow fresh export | Stop before preview or CSV generation, request a fresh task export, and rerun exact setting-code resolution. |
| A supplied Candidate Experience field has no exact fresh-export setting-code row or has duplicate rows | Stop only the affected field, identify the field and documented code, explain the evidence gap, and do not guess, substitute, append, or select a row. Other independently valid fields may continue. |
| A Candidate Experience Boolean value is not Y or N | Stop only the affected field and request Y or N. |
| Number of days to remain signed in is blank, is not a whole number, or is outside 0 through 90 | Stop only the affected field and request a whole number from 0 through 90. |
| Apply validation to candidates is not Ex-Workers or All Candidates | Stop only the affected field and request one of the two documented values. |
| Search Configuration URL exceeds 1,000 characters | Stop only the affected field and request blank or text containing at most 1,000 characters. |
| A Candidate Experience application-count tag is blank or nonnumeric | Stop only the affected field and request numeric input. Do not add an undocumented whole-number or range restriction. |
| A Candidate Experience preview uses another column set or order | Rebuild the preview with Field, Current Value, Proposed Value, and Change Status in that order. |
| A Candidate Experience final ZIP omits, renames, replaces, or adds a data CSV; lacks the exact case-sensitive `<BusinessObjectShortName>.csv` for a metadata object marked `MigrateFlag=Y`; violates `NodeSequence`; or changes ASM_SETUP_CSV_METADATA.xml | Stop before preview or import. Rebuild the package from the same fresh full export; do not use a one-CSV or otherwise scoped archive. |
| A Candidate Experience final ZIP changes a non-target CSV, or changes ORA_IRC_SETTING_VALUE.Code, SettingValueId, headers, column order, serialization outside an approved changed StringValue cell, or an unrelated ORA_IRC_SETTING.csv row | Stop before preview or import. Restore the fresh-export contents and change only validated target StringValue cells. |
| A Configure Active Candidate Filter read, preview, or modification has no fresh current full-task export | Stop before producing section output, use the existing shared current-export workflow, and rerun exact mapping. Do not use another export or update route. |
| A requested Configure Active Candidate Filter field has no exact mapping or duplicate mappings | Stop only the affected field, identify it by user-facing label, explain whether mapping evidence is missing or duplicated, and retain other independently valid fields. Do not expose or guess the internal setting identity. |
| Enable Candidate Activity or an event-specific activity value is not Enabled or Disabled | Stop only the affected field and request Enabled or Disabled. Do not accept or display an internal Boolean value as user input. |
| Activity Timeframe current value or proposed meaning has zero or multiple active Common Lookup matches | Stop only Activity Timeframe, explain the user-facing evidence gap, and retain other independently valid fields. Do not display or choose a lookup code. |
| Activity Timeframe Common Lookup resolution fails or permitted active meanings cannot be established | Classify the lookup failure, stop only Activity Timeframe, and do not use direct REST, browser, FSM-save, CSV-import, loader, or Fusion-update fallback behavior. |
| Configure Active Candidate Filter output exposes an internal value | Rebuild the output without Boolean codes, setting codes, identifiers, export filenames, or lookup codes. Display Enabled or Disabled and Activity Timeframe meanings only. |
| Event-specific activity settings are aggregated | Rebuild the list, validation result, or preview with all applicable event-specific activity settings represented separately; do not show an all-event-controls item. |
| A combined Configure Active Candidate Filter preview omits a requested field or uses another column set or order | Rebuild one preview containing every requested field separately with Field, Current Value, Proposed Value, and Change Status in that order. |
| A Configure Active Candidate Filter fallback outside the shared workflow is proposed | Stop the fallback. Continue only through the existing current-export, Common Lookup, validation, combined-preview, approval, and import workflow. |
| An Updates to Candidate Info read, preview, or modification has no fresh current full-task export | Stop before producing section output, use the existing shared current-export workflow, and rerun exact pair mapping. Do not use another export or update route. |
| A requested Updates to Candidate Info Candidate Type and field pair has no exact mapping or duplicate mappings | Stop only the affected pair, identify its exact Candidate Type and field, explain whether mapping evidence is missing or duplicated, and retain every other pair's validation result for the combined preview. Do not guess, substitute, append, or select a row. |
| An Updates to Candidate Info Candidate Type is not an exact documented name, uses an acronym, or is called a population | Stop only the affected pair and request Contingent Worker, Ex-Contingent Worker, Ex-Employee, or Additional Person Types. |
| An Updates to Candidate Info field is not Address, Email, Name, or Phone | Stop only the affected pair and request one of the four documented field names. |
| An Updates to Candidate Info current value or proposed meaning has zero or multiple active Common Lookup matches | Stop only the affected pair, explain the user-facing evidence gap, and retain every other pair's validation result. Do not display or choose a lookup code. |
| Updates to Candidate Info Common Lookup resolution fails or the permitted active meanings cannot be established | Classify the lookup failure, stop only the affected pair, and do not use direct REST, browser, FSM-save, CSV-import, loader, or Fusion-update fallback behavior. |
| Updates to Candidate Info output exposes a lookup code or an unsupported value | Rebuild the output with only None, Hiring App, Candidate Portal, or Hiring App and Candidate Portal, subject to their being active Common Lookup meanings. |
| A combined Updates to Candidate Info preview omits a requested pair, changes a Candidate Type name, or uses another column set or order | Rebuild one preview containing every requested pair with Candidate Type, Field, Current Value, Proposed Value, and Change Status in that order. |
| Any requested Updates to Candidate Info pair is blocked | Preserve every successfully validated and blocked result in the combined preview, but stop before approval or import. Do not import a successfully validated subset. |
| An Updates to Candidate Info fallback outside the shared workflow is proposed | Stop the fallback. Continue only through the existing current-export, Common Lookup, validation, combined-preview, approval, and import workflow. |
| A Candidate Search Archiving read, preview, or modification has no fresh current full-task export | Stop before producing section output, use the existing shared current-export workflow, and rerun exact mapping. Do not use another export or update route. |
| Candidate Search Archiving has no exact mapping or duplicate mappings | Stop only Candidate Search Archiving, explain whether the mapping evidence is missing or duplicated, and do not guess, substitute, append, or select a row. |
| Candidate Search Archiving input is not Enabled or Disabled | Stop the affected field and request Enabled or Disabled. Do not accept a stored code as user-facing input. |
| Candidate Search Archiving output exposes a stored code | Rebuild the output using Enabled or Disabled only; do not display Y or N. |
| A Candidate Search Archiving preview omits the field or uses another column set or order | Rebuild the preview with Field, Current Value, Proposed Value, and Change Status in that order. |
| A Candidate Search Archiving fallback outside the shared workflow is proposed | Stop the fallback. Continue only through the existing current-export, validation, combined-preview, approval, and import workflow. |
| A Candidate Sourcing read, preview, or modification has no fresh current full-task ORA_IRC_SETTING.csv export | Stop before producing section output, use the existing shared current-export workflow, and rerun exact mapping. Do not infer rows, mappings, or current values. |
| A Candidate Sourcing field has no exact authoritative mapping or has duplicate rows | Stop only the affected field, identify its UI label and documented setting code, explain the evidence gap, and retain other exact matches. Do not infer, substitute, append, or select a row. |
| A setting code outside the Candidate Sourcing eight-code allowlist is supplied | Reject the unsupported field or row, report the code, and do not create an import row for it. |
| A Candidate Sourcing Boolean value is not Y or N | Stop only the affected field and request Y or N. |
| A Candidate Sourcing frequency is blank, negative, decimal, contains characters or mixed text and numbers, or is outside 0 through 30 | Stop only the affected field and request a whole number from 0 through 30. |
| Talent Community attributes is not Job Category, Job Function, or Job Function,Job Category | Stop only the affected field and request one of the three exact documented values. |
| Talent Community attributes or Global Talent Community Pool visibility is requested while the final Talent Community state is disabled or indeterminate | Stop the dependent field and ask the user to enable Talent Community in the same request or remove the dependent field. Do not infer the current or final state. |
| Global Talent Community Pool Visible = Y is proposed for CSV import | Do not generate or import that row. Return the documented Candidate Sourcing FSM/ADF UI save action required to enable or create the pool. |
| A Candidate Sourcing request mixes Global Talent Community Pool Visible = Y with CSV-eligible changes | Show both routes separately and stop before silently importing the CSV subset. Require an explicit decision for the split workflow. |
| Candidate Sourcing output uses a setting code as the primary field display | Rebuild the output with the documented UI label in the Field column and retain the code only as traceability evidence. |
| A Campaigns read has no valid matching export, or a preview or modification has no fresh current full-task export | Stop before section output or CSV generation, use the existing shared export workflow, and rerun exact Campaigns mapping. |
| A requested Campaigns field has no exact setting mapping, has duplicate rows, or lacks a current value | Stop the complete Campaigns request, identify every affected field and documented setting code, and do not infer, substitute, append, select a row, or create a partial package. |
| A Campaigns setting code outside the seven-code allowlist is supplied | Reject the complete Campaigns request, report the unsupported code, and request one of the documented UI fields. |
| Campaign Number Generation Method has an unsupported value | Stop and request ORA_IRC_CAMP_GEN_METHOD_AUTO or ORA_IRC_CAMP_GEN_METHOD_MANUAL. |
| Campaign Number Starting Value is blank or contains anything other than digits | Stop and request a nonblank digits-only value. Do not normalize signs, decimals, whitespace, symbols, or mixed text and numbers. |
| A Campaigns Boolean setting is not Y or N | Stop and request Y or N for the affected field. |
| Campaign Email Maximum Retry Count is blank, nonnumeric, or less than 0 | Stop and request a numeric value greater than or equal to 0. Do not invent an upper bound or a whole-number restriction. |
| Recent-campaign exclusion duration has zero or multiple active matches, is inactive, or is not one of the three documented meanings | Stop the complete Campaigns request, show 1 week, 2 weeks, and 1 month as the supported user-facing values, and do not guess or expose a LookupCode. |
| Campaign duration Common Lookup resolution fails | Classify the provider failure and stop the complete Campaigns request. Do not use a direct REST, browser, FSM-save, or another fallback. |
| A Campaigns preview omits a requested field, changes display order, uses another column shape, or exposes a duration LookupCode | Rebuild the complete preview using Field, Current Value, Proposed Value, and Supported Values, with duration meanings only. |
| Any Campaigns field is blocked | Stop before approval or import. Preserve all requested results and do not create or import a successfully validated subset. |
| A Campaigns workflow outside the existing shared route is proposed | Stop the fallback and return to the established export, validation, preview, approval, import, and verification workflow. |
| A Recruiting Management field has no exact setting-code or parent/child mapping in a fresh export of this exact task | Stop only the affected field, disclose its setting code and evidence gap, and do not infer a code, parent, default, persistence behavior, or import route. |
| A Recruiting Management value violates its documented contract | Skip only the affected setting and disclose its setting code, supplied value, concrete validation reason, and accepted values; for the generation method also disclose ORA_IRC_REQ_GEN_METHOD_AUTO and ORA_IRC_REQ_GEN_METHOD_MANUAL. |
| The generation-method lookup returns zero exact accepted LookupCode matches | Return no_match_warning and skip only REQUISITION_NUMBER_GENERATION_METHOD. Do not match by Meaning; preserve other independently valid settings. |
| The generation-method lookup returns more than one exact accepted LookupCode match | Return many_matches_warning and skip only REQUISITION_NUMBER_GENERATION_METHOD. Disclose the ambiguity and preserve other independently valid settings. |
| The supplied generation method is not an accepted code | Return invalid_setting_skipped, disclose both accepted codes, and skip only REQUISITION_NUMBER_GENERATION_METHOD. |
| The generation-method lookup fails authentication or authorization | Report the concrete authentication or authorization condition and skip only REQUISITION_NUMBER_GENERATION_METHOD. Do not reinterpret the provider failure as no match. |
| The generation-method lookup has an HTTP, transport, timeout, or response-shape failure | Report the concrete observed condition and evidence-supported recovery, then skip only REQUISITION_NUMBER_GENERATION_METHOD. Do not use a cached, inferred, or Meaning-based value. |
| A retained ORA_IRC_SETTING.csv child has no exactly matching nonempty parent, has duplicate parents, or has a mismatched parent in ORA_IRC_SETTING_VALUE.csv | Fail local input/archive validation before upload, block the entire preview and import, and list every affected setting code. Do not rely on Fusion row skipping. |
| The FSM ProcessLog reports a missing parent, a skipped child, or fewer SettingMigrationVO rows than requested | Classify the import as partial or failed even when the overall Data Loader result says succeeded or completed with warnings. Report requested and processed setting-row counts, every skipped setting code and reason, and values verified by a fresh post-import export. |
| Only dataset-level loaded and failed counts are available | Do not claim that Recruiting Management setting values were applied. Obtain SettingMigrationVO row evidence, ProcessLog details, and a fresh post-import export. |
| A Recruiting Management import is partial, failed, timed out, or uncertain | Stop without automatic retry and do not reuse the prior approval. Correct the source evidence or archive, produce a new immutable artifact, and require fresh validation, preview, SHA-256, and approval before any new submission. |
| An AI Features read, preview, or modification has no fresh current full-task export | Return fresh_export_required and obtain a fresh task export before resolving or generating any supported scalar row. |
| A supported AI Features field has no exact fresh-export mapping or has duplicate rows | Stop only the affected independent field. If an importance row is affected, block the complete Education, Skill, and Experience importance group. Do not infer, substitute, append, or select a setting row. |
| Enable job application highlights or Enable job application rating is requested for import | Report Not supported and do not generate a setting row because no direct setting code is proven. |
| An AI Features code excluded by the standard migration view is requested | Report Not supported and do not generate or import ORA_IRC_AI_SIMILAR_CANDIDATE, ORA_IRC_AI_EXCLUDED_COUNTRIES_ENABLED, ORA_IRC_AI_JOBS2CANDIDATE_ENABLED, ORA_IRC_AI_JOBS2JOBS_ENABLED, or ORA_IRC_AI_TIME_TO_HIRE_ENABLED. |
| An Education, Skill, or Experience importance value is not decimal syntax | Block the complete three-field importance group, identify every invalid value, and request valid decimal values whose final total equals exactly 1. |
| The final Education, Skill, and Experience importance values cannot all be established or do not total exactly 1 | Block the complete importance group and show the three final evidence-backed values or the missing evidence. Do not adjust, normalize, or default a value silently. |
| Maximum summaries per day is not numeric | Stop only ORA_IRC_AI_MAX_NUMBER_OF_SUMMARIES_PER_DAY and request numeric syntax. Do not add an undocumented minimum, maximum, or whole-number restriction. |
| Enable candidate suggestions on requisitions is not Y or N | Stop only ORA_IRC_AI_MATCHING_ENABLED and request Y or N. |
| Selected countries lacks one exact nonblank fresh-export value | Stop only ORA_IRC_AI_EXCLUDED_COUNTRIES and explain the missing, blank, or duplicate evidence. Do not construct a country list. |
| A Selected countries value is manually constructed, translated, or simplified | Reject the proposed value and retain no row. Use only the exact nonblank representation from the fresh export. |
| Retained Selected countries is presented as enabling the complete hide-suggestions feature | Correct the result and state that ORA_IRC_AI_EXCLUDED_COUNTRIES_ENABLED is unsupported, so preserving the standalone country-list value does not make the complete feature importable. |
| A supported AI Features row uses a different identity or value structure | Stop the row and rebuild it using ORA_IRC_SETTING_CODE/XML Code and ORA_IRC_STRING_VALUE/XML StringValue. |
| Data Purging is proposed through CSV migration | Stop and explain that the source marks this configuration unsupported for the exported content. |
| ACTIVE_DAYS is outside the documented range or ENTITY_NAME does not identify Campaign Email Metrics retention | Stop and request a value within the documented range and the documented entity key. |
| Microsoft Graph, Google Workspace, or Zoom is treated as fully configured by CSV | Stop the CSV-only path and direct the user to complete the documented FSM configuration and validation. |
| Display state is unclear | Ask whether the user wants fields only, exported values, or a pre-import preview before displaying a table. |
| A Print to PDF setting has no exact mapping in the fresh export | Stop only the affected field and explain the missing setting-code evidence. |
| A Document Types row lacks an exact SystemDocumentType or verification-flag header | Stop only the affected row and explain the evidence gap. |
| A GHR Document Types lookup cannot resolve exactly one name for an exported SystemDocumentType | Retain the system code, mark only that Document Type Name as unresolved, and explain that no name was inferred. |
| A Document Types import selector is unresolved, inactive, or already configured | Stop only the affected document type. State the failed eligibility check and do not create an import artifact or row. |
| A Document Types import attempts activation or authors a system-managed category attribute | Stop that field; import forces inactive and category attributes are system-managed. |
| An Offer Boolean setting is not Y or N | Return INVALID_BOOLEAN_VALUE — Enter Y or N for this setting. Stop the affected field and do not generate its CSV row. |
| An Offer day setting is not a whole number equal to or greater than 0, or is blank where blank is not allowed | Return INVALID_DAY_VALUE. For ORA_IRC_INTERNAL_OFFER_AUTO_PROCESS_DAYS, request a whole number equal to or greater than 0. For an end-dating setting, request that value or blank for no end date. |
| A required Offer Site-level profile option is not Y | Return PROFILE_OPTION_PREREQUISITE_NOT_MET. Report the profile option code, current prerequisite failure, affected UI field, and corrective action; do not change the dependent Offer setting or update the profile option as a side effect. |
| An Offer profile-option read fails authentication, authorization, transport, or result-shape validation | Classify and report the lookup failure separately from a prerequisite value other than Y. Do not change the dependent Offer setting. |
| A specific collaborator selection is unknown, disabled, or ambiguous | Return INVALID_COLLABORATOR_SELECTION — Select an enabled collaborator type available in this environment. Reject the complete selection and discard partial resolutions. |
| The ORA_IRC_COLLABORATOR_RESP_TYPE lookup fails authentication, authorization, transport, or result-shape validation | Classify and report the lookup failure; do not ask the customer to provide the lookup list and do not generate a partial StringValue. |
| None is requested but its stored CSV representation is not established by a fresh export or task metadata | Stop CSV generation for ORA_IRC_OFFER_COLLABORATORS_TO_COPY; do not guess a blank or stored value and direct the user to the manual Fusion action. |
| An Offer setting requires REST/API handling or is not supported by the task's approved FSM export/import files | Do not attempt CSV import. Identify the setting and the Enterprise Recruiting and Candidate Experience Information > Offer navigation, require the value to be changed manually in Fusion, and do not report it as updated until confirmed. |
| Include as Potential Duplicates has a value other than ALL or ORA_RECRUITING | Return INVALID_PERSON_TYPE_VALUE — Select All person types or Only person types supported in Recruiting. Show ORA_IRC_OFFER_DUPCHECK_PERSON_TYPES, the rejected value, both allowed values, and the corrective action; do not generate its CSV row. |
| Duplicate Check in Move to HR is supplied for CSV import | Return MANUAL_INTERVENTION_REQUIRED — This setting isn't available in the FSM import file. Do not invent a setting code or import value, and do not route it to the common Profile Option Values skill. |
| Duplicate Check in Move to HR or its Enterprise HCM Information dependency is not confirmed complete | Stop before reporting the Move to HR configuration complete. Direct the user to configure Enterprise HCM Information: Person Creation Duplicate Check and complete Duplicate Check in Move to HR manually. |
| A potential duplicate is found while moving a candidate to HR | Disclose that the application can reach HR - Error During Processing and that a user must decide how to proceed. Do not claim that the candidate completed Move to HR. |
| An Agency Hiring Boolean setting is not Y or N | Return INVALID_BOOLEAN_VALUE — Enter Y or N for this setting. Show the setting code, rejected value, allowed values, and corrective action; do not generate its CSV row. |
| Agent User Category is unknown or unverified | Return MANUAL_INTERVENTION_REQUIRED — Verify Agent User Category in target Security Console before importing. Stop before preview and do not infer a code or create a User Category. |
| Agent Role is unknown or unverified | Return MANUAL_INTERVENTION_REQUIRED — Verify Agent Role in target Security Console before importing. Stop before preview and do not infer a code or create a role. |
| Automated Security Console verification is attempted for Agency Hiring | Stop because the current skill has no approved read-only Security Console lookup route. Require manual verification instead. |

## Error Classifications

| Result Category | When Used | Next Action |
|---|---|---|
| Events readiness blocker | Advanced Recruiting is disabled, unavailable, unauthorized, unsupported, or indeterminate. | Stop before Events export, input validation, downstream setup-data validation, or import and correct the feature readiness issue. |
| Events required value missing | Either mandatory Events setting is missing or blank. | Ask for both Events values, each as a whole number from 1 through 999. |
| Events non-whole value | Either Events setting contains a decimal, sign, character, or mixed text and numbers. | Ask for a whole number from 1 through 999. |
| Events below minimum | Either Events setting resolves to zero or a negative number. | Ask for a whole number from 1 through 999. |
| Events above maximum | Either Events setting is greater than 999. | Ask for a whole number from 1 through 999. |
| Candidate Authenticity readiness blocker | The configured Site-level prerequisite is N, blank, missing, unavailable, or unreadable. | Stop before validation or import and state that Candidate Authenticity must be enabled before its settings can be updated. |
| Candidate Authenticity required value missing | Endpoint URL, Access Token URL, or Scope is missing or blank after readiness succeeds. | Identify every invalid field and ask for a valid nonblank value; reject the complete request. |
| Candidate Authenticity prohibited credential | A Client ID or Client Secret field or value is supplied or reaches any CSV, artifact, preview, log, diagnostic, or output surface. | Reject the complete request, emit only a generic protected-credential refusal, and direct credential maintenance to the FSM setup UI. |
| Candidate Experience fresh export required | No successful fresh target export exists for the current Candidate Experience workflow. | Obtain a fresh task export and rerun exact mapping before preview or CSV generation. |
| Candidate Experience setting-mapping evidence gap | A documented Candidate Experience setting code is missing or duplicated in the fresh export. | Stop only the affected field, disclose its evidence gap, and continue only with other independently valid fields. |
| Candidate Experience field validation | A supplied Candidate Experience value violates its documented Boolean, whole-number range, enum, length, or numeric-input contract. | Stop only the affected field, show its accepted values, and request a valid replacement. |
| Configure Active Candidate Filter fresh export required | No successful fresh current full-task export exists for the section workflow. | Use the existing shared current-export workflow and rerun exact setting resolution. |
| Configure Active Candidate Filter mapping evidence gap | A requested field's documented internal setting identity is missing or duplicated in the fresh export. | Stop only the affected field and disclose the evidence gap without exposing internal codes or identifiers. |
| Configure Active Candidate Filter field validation | A Boolean field is not Enabled or Disabled, or Activity Timeframe is not one active permitted user-facing meaning. | Stop only the affected field, show the permitted user-facing values, and retain other independently valid fields. |
| Configure Active Candidate Filter display-policy blocker | Output exposes an internal value, aggregates event-specific controls, omits a requested field, or violates the required preview shape. | Rebuild the complete user-facing combined preview before approval. |
| Configure Active Candidate Filter workflow blocker | A direct or alternate execution fallback is proposed outside the existing shared workflow. | Stop the fallback and return to the existing current-export, Common Lookup, validation, combined-preview, approval, and import path. |
| Updates to Candidate Info fresh export required | No successful fresh current full-task export exists for the section workflow. | Use the existing shared current-export workflow and rerun exact Candidate Type and field mapping. |
| Updates to Candidate Info mapping evidence gap | A requested Candidate Type and field pair's documented setting identity is missing or duplicated in the fresh export. | Stop only the affected pair, disclose the evidence gap without guessing a row, and preserve all pair results for the combined preview. |
