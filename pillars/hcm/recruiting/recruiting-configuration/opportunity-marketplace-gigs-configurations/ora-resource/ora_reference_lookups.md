## Lookup Execution Rules

| Situation | What Happens |
|---|---|
| A supplied reference has no exact eligible match or has multiple matches | Stop; do not choose a value automatically. |
| EligibilityName is omitted or already assigned | Run list_active_unused_opp_marketplace_eligibility_profiles, show all returned names, and require the user to select one before package generation. |
| No optional availability-context value is supplied | Do not run that optional lookup. |
| The current export is stale, incomplete, or missing its required metadata member | Stop; generate a fresh export before proceeding. |
| A location is supplied | Populate `GeographyElement<N>IdentifierValue` with the resolved display hierarchy values and its matching `GeographyElement<N>LanguageCode` values. For example, `FL, United States` is `United States`/`US`, then `FL`/`US`. Do not use `CountryCode=US` as the element value or `en` as the language code. |
